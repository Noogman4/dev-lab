# NetMon Roots

**NetMon Roots** is an all-in-one Linux network and security toolkit that combines network diagnostics, DNS management, firewall control, VPN support, security monitoring, AI-assisted analysis, and system utilities in a single graphical application.

Designed for Linux users who want to monitor, diagnose, and secure their systems from one central interface.

---

## Features

### Network

* Network diagnostics
* Connection monitoring
* Routing information
* Trace and analysis tools
* Packet Capture support

### Security

* DNS Guard
* DNS-over-TLS (DoT)
* Firewall / UFW management
* WireGuard VPN support
* Kill Switch
* Security Monitoring
* Startup Guard
* Process Guard
* Repository Guard
* Roots Baseline Guard
* ClamAV integration
* Lynis integration
* RKHunter integration

### AI Analysis

* AI-assisted log analysis
* Security report interpretation
* Diagnostic assistance

### Utilities

* Internet Radio
* Theme Studio
* Linux Help
* Cleanup Assistant
* HDD, Link and VPN Slot Management
* Support Package Export

## Installation

Download the latest Debian package from:

**[https://netmonroots.com/downloads.html](https://netmonroots.com/downloads.html)**

or from the GitHub Releases page.

Install the package:

```bash
sudo dpkg -i netmon_1.1.15_all.deb
sudo apt -f install
```

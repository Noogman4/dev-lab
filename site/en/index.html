Core features

NetMon is not a generic SaaS shell, but a Linux toolkit with a real UI.

DNS and resolver control

DNS Guard, DNS-over-TLS, resolver checks, and status rating in one tab.

Firewall and security

UFW, security events, Startup Guard, Process Guard, Repository Guard, and Roots Baseline Guard.

VPN and WireGuard

VPN slots, WireGuard import, and targeted cleanup of NetMon-related leftovers.

Diagnostics and support

Startup logs, structured diagnostics, and support packages as ZIP exports.

Linux help and glossary

Around 700 Linux commands and IT terms, available inside the app and expandable by the user.

Link block and shortcuts

Freely labeled buttons with internal or external links for tools, documents, and fixed destinations.

AI and prompt workflow

API-key based online analysis and copyable prompts for external chats.

Network tools

Trace, connections, port analysis, packet capture, and classic Linux tooling.

Radio and extras

Detachable radio player, favorites, EQ, projectM options, and Theme Studio.

Theme Studio and fun area

Visual customization, small extras, and a dedicated area for winding down inside NetMon.

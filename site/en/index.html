Core features

The key networking and security tools in one place.

Network diagnostics

Trace, MTR, Nmap, connection, and traffic analysis make network problems easier to understand.

DNS Guard and resolvers

DNS profiles, DNS-over-TLS, DNSSEC, and resolver checks put name resolution under control.

Firewall with UFW

Manage rules, logs, security events, and hardening checks from one central interface.

WireGuard and Kill Switch

Import and manage VPN profiles, enable connection protection, and check public IP and exit country.

Security Guards

Process, Startup, Repository, and Roots Baseline Guard detect notable changes in the system.

Malware and security scans

ClamAV, Lynis, and RKHunter provide malware checks, hardening advice, and understandable ratings.

Secure Browser

Separate, hardened Firefox profiles for sensitive research and a better isolated browsing experience.

Chad: AI-assisted analysis

Prepare, analyze, or turn logs, diagnostics, and security notices into clear prompts for follow-up.

Support, backup, and maintenance

Export diagnostics and ZIP support packages, use Timeshift, and speed up maintenance tasks.

Everyday tools

Speedtest, packet capture, Linux Help, disk and link management, plus radio and Theme Studio.

Daybreak scan of 22 November 2026

The focused scan covered selected parts of the NetMon application, including the Secure Browser, diagnostics and the radio entry points. Daybreak scanned the main snapshot eff156b7 using gpt-5.6-sol with xhigh reasoning effort.

Daybreak reported four findings: one high, two medium and one low. As of 27 November 2026, all four are marked Fixed in Daybreak.

  • High · Swap resizing. NetMon runs the installed, root-protected helper when elevated privileges are required. The fix is in main. Commit c76a3a3d
  • Medium · Private destinations in Secure Browser. A filter in the browser's network namespace blocks private and local destinations. The DNS proxy remains reachable. Commit f709d9e9
  • Medium · Overbroad domain rules. New rules match the specified hosts. The inventory flags older subdomain wildcards for review. Commit 181f6561
  • Low · Local paths in support ZIPs. The manifest lists relative paths inside the ZIP. Files with identical names receive distinct archive names. Commit ad7dfe75

The combined beta 4 test commit 086e3a31 on test/mint-audit-fixes contains all four fixes. All 433 focused tests passed. An isolated test using slirp4netns confirmed that publicly addressed IPv4 test endpoints and DNS remained reachable while private test endpoints were blocked. The three browser and support ZIP fixes await integration into main.

Scope and verification

Repository scans with Defense Factory, manual validation, targeted reproductions and regression tests cover privileged paths, imports, network requests, diagnostics, package and release workflows, and website code.

The full test suite, live hosting, external penetration testing and operating-system dependencies were outside this audit's scope.

Accepted residual risks

  • M-03: deletion of a VPN profile under the documented same-user attack assumptions.
  • M-08: unbounded general curl output under a short time limit; automatic IP and country responses are separately capped at 4 KiB.
  • L-01: short statistics tokens; the report documents a random 64-character production token and HTTP 503 without a valid token.

Details, assumptions and fix references remain in the original round 13 PDF.

Release overview

Baseline

This page summarizes the highlights since NetMon 1.1.15.

The last actually published website version was 1.1.15. This page lists the most important changes and additions up to the current local state, grouped by release.

Go to download page Open updates page

Focus

Main work happened in Secure Browser, VPN, security evaluation, and ClamAV.

Between 1.1.15 and the current local state, the biggest changes landed in Secure Browser, slot handling, the security area, packaging, and ClamAV usability.

Highlights since 1.1.15

Secure Browser expanded

New German and English tours, XDG-compliant storage under Documents/NetMon/Secure Browser, more robust icon handling, and cleaned-up legacy paths.

More slots and stronger VPN switching

Link slots were expanded from 15 to 20 and VPN slots from 5 to 10. VPN profile switching and related mappings became more robust, including automatic refresh of public IP and exit country.

Security area restructured

Security subtabs were renamed more compactly, PATH Guard moved into its own tab, and both German and English output were cleaned up across several security areas.

Packaging and release hygiene

The Debian package layout was aligned with standard paths and extended with manual pages, checksums, copyright metadata, and related packaging improvements.

RKHunter deepened

Warnings are now classified, scans are backed by dpkg -V, and manual reference updates are gated much more strictly.

ClamAV and D-Scan improved

D-Scan gained direct path copying, while ClamAV received a fixed runtime display, lighter quick scans, and configurable quick-scan paths.

Linux help with PDF library

Entries can be copied as regular prompts or PDF prompts. Externally generated PDFs can be imported, opened, and deleted again from the lower library context menu.

Version 1.1.16

Release and audit refresh

Release artifacts were rebuilt, website and download references were updated, and the security audit moved to round 6.

Site bundle extended

The site bundle now ships the current round-6 audit files and carries the Secure Browser integration and language keys into the current package and documentation state.

Version 1.1.17

Link and VPN slots expanded

Link slots increased from 15 to 20, VPN slots from 5 to 10, and existing configurations are extended automatically when loaded.

Stronger VPN lifecycle

Profiles can again be deleted directly from selected table rows, assignments are cleaned up consistently, and IP/country displays refresh properly after switches.

Secure Browser and migration cleanup

New guided tour, removed legacy paths like ~/Programme, safer uninstall behaviour, and cleaner browser menu entry names.

Security and language cleanup

PATH Guard moved into its own tab, security subtabs were renamed more compactly, and German/English defaults were unified across multiple security areas.

Package and D-Scan

The Debian package was normalized to standard paths. D-Scan gained Copy path and logs now use full timestamps.

Version 1.1.18

RKHunter classification

RKHunter warnings are now classified as expected change, worth checking, or critical. The analysis includes a short assessment, findings, risk, and concrete recommendations.

More trust evidence

Full RKHunter scans now include dpkg -V. rkhunter --propupd is offered only under explicit security conditions.

Compatibility and installer state

Linux Mint compatibility and dependency improvements were added, together with a Secure Browser Firefox base installer and refreshed radio/test-build paths.

Current local additions

Configurable ClamAV quick scan

ClamAV now includes a Quick scan paths button with a popup for standard folders and custom directories. This makes fast scans predictable and easy to keep small.

No silent full-home fallback

If no valid quick-scan paths are configured, NetMon no longer starts an unexpectedly large fallback scan across the whole home directory.

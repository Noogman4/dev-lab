Current status

Status

NetMon 1.1.15 is the current build.

The version check in the About section works cleanly and automatically points to the download page when a newer website version is available. This page serves as the central place for approvals, test notes, and ongoing maintenance updates.

Go to download page Open documentation

Important note

NetMon is still being checked on multiple Linux systems.

If differences or problems appear on individual distributions, we document them here before issuing a broad approval. This keeps status and known topics visible in one place.

Approvals and tests

Zorin OS approved

The current core functions were tested successfully on Zorin. This includes launch, the diagnostics path, and the revised LUKS mount workflow.

Linux Mint in the test lab

Initial tests on Mint are positive. A broad approval is still pending because more checks are scheduled in the test lab.

Note for Mint tests

Before system changes, mount and unmount checks, or uninstall tests on Mint, a Timeshift backup should be created first.

Resolved issues

LUKS mounting revised

The earlier problem with mounting encrypted LUKS partitions was reworked in version 1.1.14. The mount path now behaves more reliably and follows the tested system behaviour more closely.

Installed build hardened

The package path was additionally hardened so that behaviour differences between the dev lab and the installed system are reduced. LUKS handling and desktop mount tooling were improved in particular.

About version check

The online check for the current version now runs cleanly. If the website offers a newer version, NetMon can forward directly to the download page.

Download and verification

New package

An updated .deb package is provided for version 1.1.15. It includes the latest LUKS-mounting work, the About version-check improvements, and the current recovery baseline.

Hash and signature

Updated SHA256 checksums and a refreshed Minisign signature will be published alongside the package so downloads can be verified before installation.

Recommendation

Please use the verification steps on the download page whenever possible and review this page before test installations.

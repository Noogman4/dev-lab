Approvals and tests

Zorin OS approved

Zorin OS is approved for NetMon 1.1.21. The tested scope includes core functions, startup, diagnostics, Secure Browser, and the VPN, DNS, and killswitch flows.

Linux Mint approved

Linux Mint is approved for NetMon 1.1.21. Core functions and the Secure Browser, VPN, DNS, and killswitch workflows were tested successfully.

Current approval status

Linux Mint and Zorin OS are approved for the current release. Additional Debian-/Ubuntu-based systems will follow after successful cross-checks.

Resolved issues

More robust startup for DNS and killswitch states

Orphaned killswitch states and problematic DNS startup situations are handled more cleanly in version 1.1.21 so NetMon starts and recovers more reliably.

Improved VPN switching and firewall sync

After a successful VPN profile switch, the intended UFW state is now synchronized cleanly with the referenced profiles even when no active killswitch is running.

RKHunter analysis tightened up

Warnings are classified more clearly, cross-checked with dpkg -V, and reference updates are only offered under explicit security conditions.

Linux Help workflow expanded

PDF-linked prompts and the new PDF library close an earlier gap between research, documentation, and direct follow-up work inside NetMon.

Download and verification

New package

An updated .deb package is provided for version 1.1.21. It includes the hardened startup and network paths, more robust VPN/firewall synchronization, and the new Linux Help PDF workflow.

Hash and signature

Updated SHA256 checksums and a refreshed Minisign signature will be published alongside the package so downloads can be verified cleanly before installation.

Recommendation

Please use the verification steps on the download page whenever possible and review this page before tests or upgrades.

Planned

Secure Browser as a standalone app

In the medium term, the Secure Browser is planned as a standalone outtake from NetMon. The core logic is intended to remain familiar, while the user interface would move to PySide instead of Tk so focus, usability, and visual direction can evolve more freely.

NetMonRoots Radio as a separate outtake

NetMonRoots Radio is also planned as a later standalone app. The goal is a slimmer, self-contained application with similar core logic, but a more modern PySide interface and a clearer focus on radio and media workflows.

Time horizon

Both of these projects are intended as medium-term follow-up work. NetMon remains the main application, and these outtakes are planned for later without short-term delivery pressure.

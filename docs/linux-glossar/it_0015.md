# Schleife

## 1. Kurzbeschreibung

Eine Schleife ist eine Ablaufstruktur, die einen zugehörigen Codeblock wiederholt ausführen kann. Die Kurzbeschreibung der Quelle nennt einen mehrfach ausgeführten Block; genauer gehört dazu auch die Regel für Wiederholung und Ende. Ein Block kann bei einer Schleife durchaus kein einziges Mal ausgeführt werden, wenn schon am Anfang kein passender Durchlauf vorliegt.

## 2. Was bedeutet der Begriff?

Schleifen vermeiden, dass dieselben Arbeitsschritte für jedes Element einzeln in den Programmtext geschrieben werden müssen. Ein Programm kann beispielsweise dieselbe Berechnung auf drei Testzahlen anwenden und später unverändert mit einer längeren Eingabe arbeiten.

Dabei gibt es unterschiedliche Formen. Eine Schleife kann nacheinander Elemente einer Datenquelle verarbeiten oder wiederholen, solange eine Bedingung wahr ist. Die Auswahl hängt davon ab, ob die Aufgabe eher „für jedes Element“ oder „solange diese Voraussetzung gilt“ lautet.

## 3. Einfacher Vergleich aus dem Alltag

Beim Ausräumen eines Korbs nimmst du nacheinander jeden Gegenstand heraus und legst ihn an seinen Platz. Die wiederholte Tätigkeit bleibt ähnlich, der aktuelle Gegenstand wechselt. Ist der Korb schon leer, gibt es nichts auszuräumen.

Der Vergleich setzt einen unveränderten, endlichen Vorrat voraus. Ein Programm kann auch eine fortlaufende Datenquelle verarbeiten oder selbst neue Arbeit erzeugen. Es braucht dann eine gesonderte Regel, wann es aufhört oder wie es unterbrochen werden darf.

## 4. Wie funktioniert das?

Pythons `for` fordert nacheinander Elemente eines durchlaufbaren Objekts an und bindet jedes an den Schleifennamen. Wenn keine weiteren Elemente kommen, endet die Schleife normalerweise. Diese Regeln beschreibt die [Referenz zur for-Anweisung](https://docs.python.org/3.13/reference/compound_stmts.html#the-for-statement).

Eine `while`-Schleife prüft vor jedem Durchlauf ihre Bedingung. Ist sie falsch, wird der Block nicht erneut ausgeführt. Verändert der Block den relevanten Zustand nie, kann die Bedingung dauerhaft wahr bleiben. Die [Referenz zur while-Anweisung](https://docs.python.org/3.13/reference/compound_stmts.html#the-while-statement) erklärt auch, dass `break` die Schleife vorzeitig verlassen kann.

Bei ineinander verschachtelten Schleifen läuft der innere Ablauf gewöhnlich für jeden passenden äußeren Durchlauf. Der Aufwand kann dadurch stark steigen. Eine kurze Schreibweise garantiert daher keine kurze Laufzeit.

## 5. Wo begegnet mir das unter Linux?

Ein Python-Skript kann mehrere selbst erstellte Messzeilen auswerten oder eine Liste von Dateinamen anzeigen. Eine Überwachungsanwendung kann wiederholt ihren Zustand aktualisieren. Solche Wiederholungen sollten bei Bedarf Pausen, Abbruch und Fehlerbehandlung berücksichtigen.

Eine endlose schnelle Abfrage kann unnötig Rechenleistung verbrauchen. Umgekehrt macht eine Schleife allein keine parallele Verarbeitung: Die Schritte können vollständig nacheinander laufen. Für das Verständnis eines Skripts lohnt deshalb der Blick auf Datenquelle, Reihenfolge und Ende.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel berechnet dieselbe Summe mit zwei Schleifenarten:

```python
zahlen = [2, 4, 6]
summe_for = 0
for zahl in zahlen:
    summe_for += zahl
index = 0
summe_while = 0
while index < len(zahlen):
    summe_while += zahlen[index]
    index += 1
assert summe_for == summe_while == 12
assert index == 3
print(summe_for, summe_while)
```

Die Ausgabe lautet:

```text
12 12
```

`for` verarbeitet unmittelbar die drei Werte. `while` verwendet dagegen eine Positionsnummer, die am Ende jedes Durchlaufs erhöht wird. Sobald sie drei erreicht, ist die Bedingung falsch. Ohne die Erhöhung wäre dieser zweite Ablauf nicht zuverlässig beendet. Beide Varianten arbeiten ausschließlich mit der selbst angelegten Liste.

## 7. Abgrenzung zu ähnlichen Begriffen

Die Schleife ist die gesamte Wiederholungsstruktur. Ein Durchlauf ist eine einzelne Ausführung ihres Blocks. Eine Bedingung steuert beispielsweise den nächsten `while`-Durchlauf. Eine Entscheidung mit `if` wählt dagegen zunächst einen Block, ohne allein dadurch eine Wiederholung einzurichten.

## 8. Häufige Missverständnisse

Eine Schleife läuft nicht zwingend mindestens einmal. Ein Ändern des Schleifennamens in einer Python-`for`-Schleife ersetzt nicht die Regeln der durchlaufenen Datenquelle. Auch ist das nachträgliche Erweitern oder Verändern derselben Sammlung während ihrer Verarbeitung häufig schwer verständlich und fehleranfällig.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe leere Eingaben, einen einzigen Wert und die Abbruchregel. Bei Bearbeitung echter Dateien kann jeder Durchlauf Änderungen verursachen; beginne daher mit kleinen eigenen Testdaten. Das Beispiel liest keine Verzeichnisse, startet keine Prozesse und verändert keine Systemeinstellungen.

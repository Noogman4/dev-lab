# Operator

## 1. Kurzbeschreibung

Ein Operator ist ein Zeichen oder ein Sprachwort, das festlegt, wie Werte miteinander verknüpft oder verändert betrachtet werden. In Python addiert `+` beispielsweise Zahlen, `==` vergleicht Werte und `and` verbindet Bedingungen. Welche Bedeutung ein Operator genau hat, hängt von der Sprache und von den beteiligten Datentypen ab.

## 2. Was bedeutet der Begriff?

Bei `2 + 3` bestimmt `+` die Operation, also die auszuführende Verknüpfung. Die beiden Zahlen sind die Operanden, auf die sie angewendet wird. Ein einstelliger Operator benötigt nur einen Operanden: Das Minus in `-zahl` bildet beispielsweise den negativen Wert. Ein zweistelliger Operator verbindet zwei Operanden.

Das Zeichen allein beschreibt noch nicht alle Regeln. In Python verknüpft `+` zwei Strings zu einem Text, während es zwei Integer addiert. Bei ungeeigneten Typkombinationen kann die Auswertung fehlschlagen. Deshalb gehören zu einem Operator stets die Regeln der betreffenden Sprache und des verwendeten Typs.

## 3. Einfacher Vergleich aus dem Alltag

Auf einem Taschenrechner sagt die Plustaste, dass zwei eingegebene Zahlen addiert werden sollen. Eine Taste für Multiplikation verlangt mit denselben Zahlen eine andere Rechnung. Die Zahlen allein legen also noch kein Ergebnis fest.

Die Grenze des Vergleichs: Ein Programmieroperator kann auch Texte, Sammlungen oder selbst definierte Objekte verarbeiten. Außerdem können Sprachregeln bestimmen, dass ein Teil einer Verknüpfung gar nicht ausgewertet wird. Ein einfaches Bild mit zwei bereits eingetippten Zahlen zeigt diese Unterschiede nicht.

## 4. Wie funktioniert das?

Die Operatorrangfolge legt fest, welche Bestandteile eines Ausdrucks enger zusammengehören. In Python bindet die Multiplikation stärker als die Addition. Deshalb wird `2 + 3 * 4` anders gruppiert als `(2 + 3) * 4`. Die [offizielle Rangfolgetabelle](https://docs.python.org/3.13/reference/expressions.html#operator-precedence) dokumentiert auch Vergleiche und logische Operatoren.

Bei `and` und `or` gibt es eine Kurzschlussauswertung: Der rechte Ausdruck wird nur ausgewertet, wenn er für das Ergebnis erforderlich ist. Außerdem liefern diese beiden Python-Operatoren bei allgemeinen Objekten einen Operanden zurück, nicht immer einen Boolean. `not` liefert dagegen einen Boolean. Diese Einzelheiten beschreibt die [Referenz zu booleschen Operationen](https://docs.python.org/3.13/reference/expressions.html#boolean-operations).

## 5. Wo begegnet mir das unter Linux?

In einem Python-Auswertungsskript können Operatoren Zähler addieren, Grenzwerte vergleichen oder mehrere Voraussetzungen verbinden. Eine grafische Anwendung kann anhand eines solchen Ergebnisses entscheiden, ob sie einen Hinweis zeigt. Dafür muss kein externer Terminalbefehl ausgeführt werden.

Auch Shells und andere Werkzeuge verwenden besondere Zeichen. Ihre Schreibweisen sind jedoch eigene Schnittstellen. Ein Zeichen wie `|` kann in einer Shell Prozesse verbinden, während es in Python andere Operationen bezeichnet. Kopiere deshalb nicht eine vertraut aussehende Schreibweise zwischen Sprachen, ohne deren Bedeutung nachzulesen.

## 6. Konkretes Beispiel Schritt für Schritt

Dieses vollständige Python-3-Beispiel verwendet kleine Zahlen und zwei feste Texte:

```python
summe = 2 + 3
produkt_zuerst = 2 + 3 * 4
klammern_zuerst = (2 + 3) * 4
text = "Net" + "Mon"
passend = summe == 5 and text == "NetMon"
assert (summe, produkt_zuerst, klammern_zuerst) == (5, 14, 20)
assert passend is True
print(summe, produkt_zuerst, klammern_zuerst)
print(text)
print(passend)
```

Die Ausgabe lautet:

```text
5 14 20
NetMon
True
```

Zuerst werden die Zahlen verknüpft. Die zwei zusammengesetzten Rechnungen zeigen die Wirkung der Klammern. Danach fügt derselbe Operator `+` zwei Texte zusammen. In der letzten Zuweisung liefern zwei Vergleiche Wahrheitswerte, die `and` verbindet. Beide sind hier wahr, also ist auch die Verknüpfung wahr.

## 7. Abgrenzung zu ähnlichen Begriffen

Die Operation ist der Vorgang, der Operator seine sprachliche Kennzeichnung. Ein Operand ist ein beteiligter Wert oder der ihn liefernde Ausdruck. Der gesamte Ausdruck umfasst Operatoren und Operanden. Eine Funktion kann ähnliche Aufgaben übernehmen, besitzt aber eine andere Aufrufschreibweise.

## 8. Häufige Missverständnisse

`=` und `==` erfüllen in Python unterschiedliche Aufgaben: Zuweisung und Vergleich. Auch `is` und `==` sind nicht austauschbar; Identität ist etwas anderes als Wertgleichheit. Gleiche Zeichen in unterschiedlichen Programmiersprachen garantieren keine gleiche Bedeutung oder Rangfolge.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Verwende Klammern, wenn sie eine Bedingung verständlicher machen. Prüfe Grenzfälle und beteiligte Typen. Ein logisch falsch gewählter Operator kann trotz gültiger Syntax falsche Entscheidungen verursachen. Das Beispiel verändert nur selbst erzeugte Werte im Speicher und gibt Text aus; es bearbeitet keine Dateien oder Systemeinstellungen.

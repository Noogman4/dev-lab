# Bedingung

## 1. Kurzbeschreibung

Eine Bedingung ist eine überprüfbare Voraussetzung für eine Entscheidung im Programm. Sie wird ausgewertet und als wahr oder falsch beurteilt. Davon kann abhängen, ob ein bestimmter Codeblock ausgeführt wird. Das Quellbeispiel verwendet den Vergleich `alter >= 18`; ein vollständiges Python-`if` benötigt zusätzlich einen Doppelpunkt und einen eingerückten Block.

## 2. Was bedeutet der Begriff?

Eine Bedingung formuliert eine Frage an den aktuellen Zustand. „Ist das Alter mindestens achtzehn?“ ist eine andere Frage als „Ist es größer als achtzehn?“. Ein einzelnes Zeichen kann daher beeinflussen, wie ein Grenzfall behandelt wird.

In Python muss der geprüfte Ausdruck nicht bereits vom Typ `bool` sein. Auch andere Objekte besitzen eine Wahrheitswertbeurteilung. Null und leere Sammlungen gelten beispielsweise als falsch. Diese Regeln beschreibt die [Referenz zur Wahrheitswertprüfung](https://docs.python.org/3.13/library/stdtypes.html#truth-value-testing). Eine fachliche Bedeutung wie „Eingabe gültig“ ergibt sich daraus noch nicht.

## 3. Einfacher Vergleich aus dem Alltag

Eine Garderobe kann einen Hinweis tragen: „Nur mit Abholschein aushändigen.“ Der vorhandene Abholschein ist dann eine Voraussetzung für die Handlung. Ohne ihn wird ein anderer Ablauf benötigt.

Der Vergleich hat Grenzen: Ein Mensch kann nachfragen, ob ein Schein echt oder verloren ist. Ein Programm berücksichtigt solche Fälle nur, wenn sie beschrieben wurden. Eine technisch wahre Bedingung ist kein selbstständiger Nachweis, dass alle fachlichen oder rechtlichen Voraussetzungen erfüllt sind.

## 4. Wie funktioniert das?

Pythons `if` wählt anhand der Bedingung einen Block. Mit `elif` lassen sich weitere Fälle prüfen; `else` beschreibt den verbleibenden Fall. In einer solchen Kette wird der erste passende Block ausgewählt. Die [Referenz zur if-Anweisung](https://docs.python.org/3.13/reference/compound_stmts.html#the-if-statement) erklärt diese Reihenfolge.

Mehrere voneinander getrennte `if`-Anweisungen sind dagegen mehrere Entscheidungen. Es können dann auch mehrere Blöcke laufen. Außerdem wird eine Bedingung nicht dauerhaft überwacht, nur weil sie einmal im Code steht. Ändert sich später der Zustand, braucht es eine erneute Auswertung.

## 5. Wo begegnet mir das unter Linux?

Ein Hilfsprogramm kann prüfen, ob eine Auswahl vorhanden ist, bevor es eine Detailansicht öffnet. Ein Auswertungsskript kann einen selbst erfassten Zähler mit einer Warnschwelle vergleichen. Wichtig ist jeweils, ob die Eingabe zuverlässig vorliegt und was der Vergleich genau aussagt.

Das Vorhandensein eines Dateinamens als Text beweist beispielsweise noch nicht, dass eine entsprechende Datei lesbar ist. Bedingung, Informationsquelle und beabsichtigte Aussage müssen zusammenpassen. Die Schreibweise eines Python-Vergleichs ist zudem nicht automatisch die einer Shell-Bedingung.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel prüft die Grenze mit erfundenen Alterswerten:

```python
ergebnisse = []
for alter in [17, 18, 19]:
    if alter >= 18:
        meldung = "mindestens 18"
    else:
        meldung = "unter 18"
    ergebnisse.append(meldung)
assert ergebnisse == ["unter 18", "mindestens 18", "mindestens 18"]
for meldung in ergebnisse:
    print(meldung)
```

Die Ausgabe lautet:

```text
unter 18
mindestens 18
mindestens 18
```

Der Vergleich schließt den Wert achtzehn ein. Die Schleife stellt dieselbe Frage für drei Werte; sie ändert nicht die Bedeutung der Bedingung. Die Zusicherung prüft ausdrücklich den Wert unterhalb, genau an und oberhalb der Grenze.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Vergleich ist eine mögliche Form einer Bedingung. Ein Boolean ist ein Wahrheitswert. Die `if`-Anweisung ist die Ablaufstruktur, die den geprüften Wert verwendet. Eine Bedingung kann auch eine Schleife steuern; sie gehört nicht ausschließlich zu Verzweigungen.

## 8. Häufige Missverständnisse

Wahr bedeutet hier „gemäß den verwendeten Regeln erfüllt“, nicht automatisch „inhaltlich richtig“. Ein nichtleerer Text mit dem Inhalt `False` gilt in Python bei einer einfachen Wahrheitswertprüfung als wahr. Auch die Reihenfolge mehrerer Fälle kann das Ergebnis verändern.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe Grenzen und unbekannte Eingaben gesondert. Das Altersbeispiel ist eine reine Vergleichsübung, keine Identitäts- oder Berechtigungsprüfung. Es verwendet keine realen Personendaten und verändert keine Konten. Bei tatsächlichen Schutzentscheidungen wären weitere verlässliche Informationen erforderlich.

# Tutorial

## 1. Kurzbeschreibung

Ein Tutorial ist eine Lernanleitung, die dich durch ein ausgewähltes Beispiel begleitet. Dabei entsteht meist ein sichtbares Ergebnis. Der Ablauf hilft dir, eine neue Fähigkeit in kleinen Schritten aufzubauen.

## 2. Was bedeutet der Begriff?

Die [Diátaxis-Leitlinien für Tutorials](https://diataxis.fr/tutorials/) stellen die Erfahrung des Lernenden in den Mittelpunkt. Eine erste Lektion kann einen sicheren, vorgegebenen Weg zeigen, auch wenn erfahrene Personen später mehrere Wege kennen. Das Ziel sollte benennen, was man nach der Lektion selbst tun kann.

## 3. Einfacher Vergleich aus dem Alltag

Eine Fahrstunde beginnt oft mit einer einfachen Übungsstrecke. Der Lernende erlebt das Zusammenspiel von Lenkung und Pedalen ohne jede mögliche Verkehrssituation. Ein Softwaretutorial schränkt sein Beispiel ähnlich ein. Es sollte dabei erklären, welche Teile bewusst vereinfacht sind.

## 4. Wie funktioniert das?

Ein Tutorial beginnt mit einem geeigneten Startpunkt. Nach jedem Lernschritt sollte eine Beobachtung zeigen, ob das Geschehen verständlich ist. Ein kleines Fehlerbeispiel kann helfen, Ursache und Wirkung zu erkennen. Lange Listen alternativer Methoden können den ersten Ablauf schwerer nachvollziehbar machen.

Das [erste Tk-Beispiel von TkDocs](https://tkdocs.com/tutorial/firstexample.html) zeigt einen kleinen Umrechner mit Eingabe und Ergebnis. Solche Übungen machen eine Oberfläche sichtbar und verbinden sie mit einem konkreten Ereignis.

## 5. Wo begegnet mir das unter Linux?

Unter Linux kann ein GUI-Tutorial eine grafische Sitzung und bestimmte Bibliotheken voraussetzen. Ein Leser auf einem Server ohne Display braucht andere Bedingungen. Die Lernanleitung sollte diese Voraussetzungen vor dem ersten Schritt nennen.

## 6. Konkretes Beispiel Schritt für Schritt

Gedankenbeispiel für eine Lektion mit einer kleinen Oberfläche.

1. Der Lernende öffnet ein leeres Fenster und erkennt dessen Titel als erste Erfolgskontrolle.
2. Er fügt ein Feld und eine Schaltfläche hinzu, damit die Bestandteile sichtbar werden.
3. Bei einem Klick würde eine kurze Aktion den eingegebenen Testtext neben dem Feld anzeigen.
4. Zum Verständnis verändert der Lernende eine Beschriftung und beschreibt, warum sich die angezeigte Ausgabe erst nach seiner Aktion ändert.

Die Lektion braucht weder echte Nutzerdaten noch eine vollständige Anwendung.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein [How-to](it_0288.md) hilft bei einem vorhandenen Arbeitsziel, etwa ein Fenster an einer bestimmten Position zu öffnen. Ein Tutorial nutzt eine Aufgabe, um Grundfertigkeiten zu vermitteln. Eine Referenz kann anschließend alle Optionen der Fensterfunktion erklären.

## 8. Häufige Missverständnisse

Mehr Features machen eine erste Lektion nicht automatisch besser. Ein kopiertes Ergebnis beweist wenig über das Verständnis, wenn der Lernende keine beobachtbare Änderung vorhersagen oder erklären kann.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Nenne die Voraussetzungen und zeige erwartete Zwischenergebnisse. Grenze die Übung auf eine überschaubare Umgebung ein. Verweise für weitere Optionen auf eine passende Referenz.

# Instanz

## 1. Kurzbeschreibung

Eine Instanz ist ein konkretes Objekt einer bestimmten Klasse. Der Ausdruck betont die Zugehörigkeit: Dieses Objekt ist ein Exemplar dieses Typs. Das Quellbeispiel `window = Window()` passt zu einer gewöhnlichen Python-Klasse. Dabei sind der Klassenname, der Aufruf und die anschließend an einen Namen gebundene Instanz unterschiedliche Bestandteile.

## 2. Was bedeutet der Begriff?

Mehrere Instanzen derselben Klasse können unterschiedliche Zustände besitzen. Zwei Fensterbeschreibungen könnten beispielsweise geöffnet oder geschlossen sein, ohne ihren Typ zu wechseln. Gemeinsame Regeln bedeuten nicht automatisch gemeinsame Daten für sämtliche Eigenschaften.

Die [Python-Einführung zu Klassenobjekten](https://docs.python.org/3.13/tutorial/classes.html#class-objects) beschreibt die übliche Instanziierung durch einen Klassenaufruf. Für die hier verwendeten gewöhnlichen eigenen Klassen entsteht ein neues Objekt, das anschließend initialisiert wird. Spezielle Konstruktionen können andere Erzeugungsregeln besitzen; der Begriff Instanz garantiert nicht jede denkbare Implementierung eines Aufrufs.

## 3. Einfacher Vergleich aus dem Alltag

Ein Formulartyp legt Felder fest, und jedes ausgefüllte Formular ist ein eigenes Exemplar. Zwei Formulare können denselben Aufbau und dennoch unterschiedliche Angaben besitzen. Die Beschreibung des Formulartyps ist nicht selbst jedes einzelne ausgefüllte Blatt.

Die Grenze des Vergleichs: Eine Instanz kann Verhalten und Beziehungen zu anderen Objekten besitzen. Sie muss weder ein sichtbarer Gegenstand noch ein veränderlicher Behälter sein. Außerdem können bestimmte Daten über die Klasse gemeinsam zugänglich sein; nicht jede erreichbare Eigenschaft gehört ausschließlich zu einem Exemplar.

## 4. Wie funktioniert das?

Ein gewöhnlicher Klassenaufruf stellt ein Objekt bereit und führt die vorgesehene Initialisierung aus. In Python setzt `__init__` häufig die Anfangsattribute. Der erste Parameter einer solchen Instanzmethode heißt üblicherweise `self` und bezeichnet die betreffende Instanz.

Mit `isinstance(objekt, Klasse)` lässt sich die Zugehörigkeit prüfen. Dabei werden auch Instanzen von Unterklassen berücksichtigt, wie die [offizielle isinstance-Referenz](https://docs.python.org/3.13/library/functions.html#isinstance) erläutert. Eine exakte Typidentität und eine Zugehörigkeit einschließlich Untertypen sind deshalb verschiedene Prüfziele.

Ein zusätzlicher Variablenname erzeugt nicht allein eine neue Instanz. Bei `zweiter_name = erster_name` können beide denselben vorhandenen Gegenstand erreichen. Erst die tatsächliche Erzeugungsoperation und ihre Regeln beantworten, ob ein weiteres Objekt entstanden ist.

## 5. Wo begegnet mir das unter Linux?

Python-Anwendungen können einzelne Aufträge, Verbindungsbeschreibungen oder Ansichtsmodelle als Instanzen eigener Klassen verwalten. Das erleichtert die Zuordnung des Zustands zu einer konkreten Aufgabe. Ob dabei eine echte Netzwerkverbindung entsteht, entscheidet die jeweilige Klasse.

Eine Klasse mit dem Namen `Window` kann eine reale GUI vertreten oder nur Daten tragen. Der Name beweist weder eine geöffnete Oberfläche noch deren Betriebsbereitschaft. Das folgende Beispiel verwendet ausdrücklich nur einen kleinen gespeicherten Zustand.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel erzeugt zwei getrennte Dateninstanzen und einen zusätzlichen Verweis:

```python
class Window:
    def __init__(self):
        self.offen = False

links = Window()
rechts = Window()
weiterer_name = links
links.offen = True
assert isinstance(links, Window)
assert isinstance(rechts, Window)
assert links is not rechts
assert weiterer_name is links
assert weiterer_name.offen is True
assert rechts.offen is False
print(links.offen, rechts.offen)
```

Die Ausgabe lautet:

```text
True False
```

Die zwei Klassenaufrufe erzeugen zwei Instanzen. Die Zuweisung an `weiterer_name` erzeugt dagegen nur eine weitere Bindung. Die Zustandsänderung betrifft das linke Objekt und bleibt für dessen zweiten Namen sichtbar. Der Zustand des rechten Objekts bleibt unabhängig.

## 7. Abgrenzung zu ähnlichen Begriffen

Die Klasse beschreibt die Art und ihre Regeln. Die Instanz ist das konkrete Exemplar. Objekt ist der allgemeinere Sprachbegriff. Ein Attribut beschreibt einen zugänglichen Bestandteil. Eine Referenz kann dieselbe Instanz über mehrere Wege erreichbar machen.

## 8. Häufige Missverständnisse

Nicht jede neue Variable bedeutet eine neue Instanz. Eine Klasse und ihre Instanzen sind nicht dieselbe Identität. Gemeinsam verwendete Klassenattribute dürfen nicht unbemerkt als ausschließlich lokale Instanzdaten behandelt werden. Eine Typprüfung allein beweist außerdem noch keinen fachlich gültigen Zustand.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe Anfangszustand, Zuständigkeit und gemeinsam verwendete Daten. Wähle Typprüfungen nach dem tatsächlichen Ziel. Das Beispiel verwaltet ausschließlich eigene Python-Instanzen und öffnet weder Fenster noch Verbindungen oder Dateien.

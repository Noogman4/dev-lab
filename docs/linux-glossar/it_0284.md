# Markdown

## 1. Kurzbeschreibung

Markdown zeichnet Text mit Zeichen wie Raute, Stern und Backtick aus. So lässt sich ein Dokument als Klartext lesen und zugleich als gegliederte Seite darstellen. Die genauen Regeln hängen vom gewählten Markdown-Dialekt und Darstellungsprogramm ab.

## 2. Was bedeutet der Begriff?

Die [CommonMark-Spezifikation](https://spec.commonmark.org/0.31.2/) beschreibt unter anderem Überschriften, Absätze und Codeblöcke. `# Überschrift` ist ein Beispiel für eine Überschrift der ersten Ebene. Das Leerzeichen nach der Raute ist Teil dieser Schreibweise. [GitHub Flavored Markdown](https://github.github.com/gfm/) ergänzt Regeln für Funktionen wie Tabellen.

## 3. Einfacher Vergleich aus dem Alltag

Eine handgeschriebene Gliederung kann Überschriften mit Unterstreichung und Listen mit Spiegelstrichen kenntlich machen. Markdown nutzt vergleichbare Zeichen mit formalen Regeln. Ein Programm behandelt deshalb einige Zeichen abhängig von Position und Kontext anders, als es ein Mensch beim ersten Lesen erwarten würde.

## 4. Wie funktioniert das?

Der Parser erkennt zuerst Strukturen wie Absätze, Listen und Codeblöcke. Innerhalb eines Absatzes kann er Links oder kurzen Code unterscheiden. Ein eingezäunter Codeblock beginnt und endet häufig mit drei Backticks. Ein optionaler Sprachname kann einer Darstellung bei der farblichen Hervorhebung helfen.

Eine Leerzeile oder Einrückung kann die Struktur verändern. Auch Browser- und Readerfunktionen beeinflussen die Ausgabe. Der für eine Oberfläche erlaubte Umfang kann kleiner sein als die allgemeine Markdown-Spezifikation.

## 5. Wo begegnet mir das unter Linux?

Unter Linux wird Markdown häufig für Projektdokumentation, Notizen und Änderungsprotokolle genutzt. Du kannst es in jedem Texteditor bearbeiten. Für die letzte Kontrolle ist die Zieloberfläche interessant, weil sie eventuell nur ausgewählte Erweiterungen kennt.

## 6. Konkretes Beispiel Schritt für Schritt

Gedankenbeispiel. Dieser kurze Quelltext wird hier als Text gezeigt.

```text
# Notizen

Eine Liste mit zwei Ideen.

- Einkauf planen
- Termin notieren
```

1. In einer passenden Darstellung wird die erste Zeile zur Hauptüberschrift.
2. Die nächste Textzeile wird ein eigener Absatz.
3. Die zwei Zeilen mit Bindestrich und Leerzeichen werden Listeneinträge. Eine zusätzliche Einrückung könnte ihre Beziehung verändern.

## 7. Abgrenzung zu ähnlichen Begriffen

HTML beschreibt Strukturen mit Tags. Markdown verwendet eine leichter lesbare Kurzschreibweise, aus der ein Werkzeug HTML oder eine andere Darstellung erzeugen kann. Eine Textdatei ohne Auszeichnung bleibt direkt lesbar, trägt aber weniger Hinweise zur Gliederung.

## 8. Häufige Missverständnisse

Ein Markdown-Link führt nur dann zum richtigen Ziel, wenn Pfad oder Adresse stimmen. Ein Renderer, der eine Tabelle darstellt, sagt nichts darüber aus, ob ein anderer Reader dieselbe Erweiterung unterstützt.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Halte Überschriftenebenen und Listen konsistent. Betrachte Codebeispiele als Dokumentinhalt. Prüfe vor dem Einsatz in einem Reader die dort vorgesehenen Regeln für Links und Inhalte.

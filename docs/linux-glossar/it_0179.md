# CSS

## 1. Kurzbeschreibung

CSS ist eine Sprache zur Beschreibung der Darstellung strukturierter Dokumente, vor allem im Web. Sie kann Farben, Schrift, Abstände und Layout beeinflussen. Regeln wählen Elemente aus und weisen Eigenschaften Werte zu. Welche Darstellung tatsächlich entsteht, hängt zusätzlich von Kaskade, Dokumentstruktur und den Fähigkeiten der verwendeten Umgebung ab.

## 2. Was bedeutet der Begriff?

Der Name steht für „Cascading Style Sheets“. Die [W3C-Beschreibung der Kaskade und Vererbung](https://www.w3.org/TR/css-cascade-5/) erklärt, wie mehrere Deklarationen zusammenwirken. Das Katalogbeispiel mit Farben und Abständen ist richtig, beschreibt aber nur einen Teil der Möglichkeiten.

Eine Deklaration verbindet eine Eigenschaft wie `color` mit einem Wert. Ein Selektor beschreibt, auf welche Elemente eine Regel zutrifft. Die [Selektorspezifikation](https://www.w3.org/TR/selectors-4/) erläutert dieses Musterkonzept. Die Quelle behandelt auch weiterentwickelte Selektoren; der folgende Einstieg verwendet nur einen einfachen Elementselektor.

## 3. Einfacher Vergleich aus dem Alltag

Ein Gestaltungshandbuch legt fest, wie Überschriften, Hinweise und Schalter eines gemeinsamen Systems aussehen sollen. Allgemeine Regeln können durch passend eingeordnete speziellere Vorgaben ergänzt werden. So muss nicht jedes einzelne Element unabhängig gestaltet werden.

Die Grenze: CSS entscheidet nach definierten Regeln, nicht nach Geschmack. Ein später hingeschriebener Wunsch überschreibt nicht zwangsläufig jede frühere Vorgabe. Auch verändert eine andere Farbe nicht automatisch die semantische Rolle eines Elements oder die fachliche Funktion einer Anwendung.

## 4. Wie funktioniert das?

Ein Selektor wird gegen die Dokumentstruktur geprüft. Passende Deklarationen gelangen in die Auswahl für bestimmte Eigenschaften. Die Kaskade berücksichtigt unter anderem Herkunft, Wichtigkeit, Schichten, Spezifität und Reihenfolge nach den geltenden Regeln.

Daher ist „die letzte Regel gewinnt“ nur unter passenden Vergleichsbedingungen richtig. Vererbung ist eine weitere Frage: Manche Eigenschaften können von übergeordneten Elementen übernommen werden, andere nicht auf dieselbe Weise. Ein Abstand am Elternteil wird nicht automatisch zur identischen Abstandsvorgabe jedes Kindes.

Aus den wirksamen Eigenschaften entsteht zusammen mit Layoutregeln und Umgebung die Darstellung. Fenstergröße, verfügbare Schrift und weitere Bedingungen können das Ergebnis beeinflussen. Eine CSS-Datei allein ist deshalb kein vollständiger Nachweis einer bestimmten Bildschirmansicht.

## 5. Wo begegnet mir das unter Linux?

Browser unter Linux verarbeiten CSS als Teil der Webdarstellung. Auch eingebettete Webansichten können es verwenden. Eine native Desktopanwendung kann dagegen andere Gestaltungsmechanismen besitzen; ein ähnliches Erscheinungsbild beweist keine identische Technik.

Für eine reale Oberfläche müssen außerdem Lesbarkeit und verschiedene Bedien- und Größenbedingungen betrachtet werden. Aus einem einzelnen Farbwert folgt noch keine nachgewiesene gute Zugänglichkeit. Solche Prüfungen werden im folgenden Textbeispiel nicht durchgeführt.

## 6. Konkretes Beispiel Schritt für Schritt

Diese Regeln sind ein nicht ausgeführtes Gedankenbeispiel. Sie werden hier als Text angezeigt und nicht auf das Glossar oder eine Webseite angewendet.

```text
button {
  color: navy;
  padding: 0.5rem 1rem;
}

button {
  color: darkgreen;
}
```

Beide Selektoren beziehen sich auf Button-Elemente. Unter der Annahme gleicher Herkunft, Schicht und Wichtigkeit sowie ohne weitere konkurrierende Vorgaben würde die spätere Farbangabe die frühere ersetzen. Die Abstandsangabe bleibt eine eigenständige Deklaration; sie wird nicht allein deshalb gelöscht, weil später erneut eine Farbe festgelegt wird.

Das Beispiel erklärt die Zuordnung einzelner Eigenschaften, nicht eine komplette Gestaltung. Die [Einheit rem](https://www.w3.org/TR/css-values-4/#font-relative-lengths) bezieht sich auf die Schriftgröße des Wurzelelements. Es wird keine tatsächliche Pixelgröße, Farbwiedergabe oder Kontrastmessung behauptet. Ein Browser hat diese Regeln hier nicht gerendert.

## 7. Abgrenzung zu ähnlichen Begriffen

HTML beschreibt Struktur und Semantik. CSS beschreibt Darstellung. JavaScript kann programmatisches Verhalten ergänzen. Ein Theme ist eine übergeordnete Gestaltungsidee, die mit unterschiedlichen Techniken umgesetzt werden kann. CSS kann außerdem Zustände und Animationen darstellen; die Trennung der Aufgaben ist deshalb keine vollständige Beschreibung jeder Interaktion.

## 8. Häufige Missverständnisse

Ein Selektor benennt nicht zwingend genau ein Element. Eine Regel ersetzt auch nicht immer sämtliche Eigenschaften einer früheren Regel. Sichtbare Gleichheit bedeutet keine gleiche Semantik. Schließlich ist eine Darstellung in einer einzelnen Fenstergröße kein Beweis für alle anderen Größen oder Browser.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe bei Konflikten Auswahl und Kaskade statt wahllos immer speziellere Regeln zu ergänzen. Teste reale Oberflächen in den vorgesehenen Umgebungen. Dieser Eintrag verändert keine Stylesheets, Anwendung, Browserprofile oder Reader-Darstellung und bindet keine externen Inhalte ein.

# Array

## 1. Kurzbeschreibung

Ein Array ist eine Datenstruktur für mehrere Elemente, auf die über Positionen zugegriffen wird. Viele Sprachen verwenden Arrays mit einem gemeinsamen Elementtyp; Länge und Änderbarkeit hängen von der konkreten Sprache oder Bibliothek ab. Die Quellbeschreibung „geordnete Sammlung“ ist deshalb eine erste Orientierung, grenzt Arrays aber noch nicht zuverlässig von anderen Sammlungen ab.

## 2. Was bedeutet der Begriff?

Ein Index bezeichnet die Position eines Elements. In vielen verbreiteten Sprachen beginnt die Zählung bei null. Die Reihenfolge gehört zur Struktur: Das erste Element ist nicht automatisch das kleinste, und ein Array sortiert seine Werte nicht allein durch das Anlegen.

Der Begriff umfasst unterschiedliche konkrete Typen. Rust-Arrays besitzen beispielsweise eine feste Länge und Elemente desselben Typs. Das erläutert das [offizielle Rust-Buch zum Array-Typ](https://doc.rust-lang.org/book/ch03-02-data-types.html#the-array-type). Daraus folgt keine universelle Regel, dass jedes Objekt namens Array in jeder Sprache dieselben Eigenschaften besitzt.

## 3. Einfacher Vergleich aus dem Alltag

Ein nummeriertes Regal bietet mehrere fest unterscheidbare Plätze. Du kannst gezielt nachsehen, was auf Platz zwei liegt, ohne zuerst alle Inhalte nach Namen zu durchsuchen. Die Nummer beschreibt den Platz, nicht die Bedeutung seines Inhalts.

Die Grenze des Vergleichs: Ein echtes Regal sagt wenig über den technischen Elementtyp oder die Speicherverwaltung aus. Manche Array-Varianten können wachsen, andere nicht. Auch muss ein Programm Zugriffe außerhalb des gültigen Bereichs nach den Regeln seiner Sprache behandeln; das Regalbild ist kein vollständiges Sicherheitsmodell.

## 4. Wie funktioniert das?

Eine Implementierung ordnet Elementen Positionen und eine geeignete Darstellung zu. Bei vielen Arrays ermöglichen feste Elementdarstellungen eine kompakte Ablage. Welche Garantien zu Layout, Größen und Zugriff gelten, muss jedoch die konkrete Schnittstelle festlegen.

Python bietet im Standardmodul `array` typgebundene Folgen grundlegender Werte. Ein Typcode bei der Erstellung bestimmt, welche Darstellung verwendet wird. Diese Arrays sind veränderlich und können unter anderem erweitert werden. Die [offizielle array-Dokumentation](https://docs.python.org/3.13/library/array.html) unterscheidet sie ausdrücklich von gewöhnlichen Listen und weist auf plattformabhängige Darstellungsdetails hin.

Die Aussage der Quelle, ein Array sei in vielen Sprachen eine Liste mit festen oder dynamischen Elementen, wird daher präzisiert: Array und Liste sind keine allgemein austauschbaren Typbezeichnungen. Feste oder dynamische Länge ist eine gesonderte Eigenschaft.

## 5. Wo begegnet mir das unter Linux?

Programme können viele gleichartig dargestellte Messwerte oder Bilddaten in Arrays verarbeiten. Eine Bibliothek kann dafür einen eigenen Array-Typ mit zusätzlichen Regeln anbieten. Das Vorhandensein von eckigen Klammern im Quelltext reicht nicht, um diesen Typ sicher zu erkennen.

Bei Dateiformaten und Schnittstellen sind Elementgröße, Zahlbereich und gegebenenfalls Byte-Reihenfolge wichtig. Ein Array unverändert als Bytes weiterzugeben ist deshalb nicht automatisch ein portabler Datenaustausch. Die Empfängerseite muss die vereinbarte Darstellung verstehen.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verwendet ausschließlich kleine eigene Integerwerte:

```python
from array import array

werte = array("i", [2, 4, 6])
assert werte[0] == 2
werte[1] = 5
werte.append(8)
assert werte.typecode == "i"
assert len(werte) == 4
assert list(werte) == [2, 5, 6, 8]
print(list(werte))
```

Die Ausgabe lautet:

```text
[2, 5, 6, 8]
```

Der Typcode `i` wählt die entsprechende vorzeichenbehaftete Integerdarstellung des Moduls. Der zweite Wert wird ersetzt und anschließend ein weiterer angehängt. Gerade das Anhängen zeigt eine Eigenschaft dieses Python-Typs; es ist keine Behauptung über die feste Länge eines Rust-Arrays.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine Python-Liste kann Referenzen auf unterschiedliche Objektarten enthalten. Das hier verwendete Array beschränkt die Elementdarstellung. Eine mathematische Menge verfolgt einen anderen Zweck als eine Folge mit Positionen. Ein mehrdimensionaler Bibliothekstyp kann zusätzliche Form- und Rechenregeln besitzen, die das Standardmodul nicht automatisch bereitstellt.

## 8. Häufige Missverständnisse

Array bedeutet nicht automatisch feste Länge, unveränderliche Werte oder sortierte Reihenfolge. Auch ist ein Index nicht dasselbe wie eine gespeicherte Kennung. Die Eigenschaften einer bestimmten Bibliothek dürfen nicht ungeprüft auf alle anderen Array-Typen übertragen werden.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Lies die Typ- und Größenregeln der verwendeten Schnittstelle. Prüfe leere Daten, gültige Indexgrenzen und den Wertebereich. Das Beispiel verändert nur sein eigenes Array im Speicher. Die Rust-Eigenschaften wurden anhand der Primärquelle geprüft; Rust-Code wurde hier nicht ausgeführt.

# Glossar

## 1. Kurzbeschreibung

Ein Glossar erklärt Begriffe für einen bestimmten Themenbereich oder eine bestimmte Leserschaft. Ein guter Eintrag hilft dir, ein Wort im vorgesehenen Zusammenhang zu verstehen und verwandte Begriffe zu finden.

## 2. Was bedeutet der Begriff?

Ein Glossar ordnet eine Benennung einer verständlichen Bedeutung zu. Es kann Abkürzungen, Varianten und Querverweise ergänzen. Die [SKOS-Referenz des W3C](https://www.w3.org/TR/skos-reference/) beschreibt für formalisierte Begriffssysteme unter anderem bevorzugte und alternative Benennungen. Ein Glossar braucht dieses Datenmodell nur dann, wenn es zu seinen Anforderungen passt.

## 3. Einfacher Vergleich aus dem Alltag

In einer Bibliothek helfen Katalogeinträge beim Finden der richtigen Bücher. Ein Glossar führt statt zu Büchern zunächst zu Erklärungen. Derselbe Ausdruck kann in zwei Fachgebieten etwas anderes bedeuten. Deshalb braucht die Erklärung ihren jeweiligen Kontext.

## 4. Wie funktioniert das?

Eine einfache Struktur umfasst Begriff, kurze Definition und bei Bedarf ein Beispiel. Beziehungen erklären, wie Begriffe zusammenhängen. Ein Synonym kann zur gleichen Erklärung führen. Ein verwandter Begriff bekommt typischerweise eine eigene Definition.

Die [Sphinx-Referenz zum Glossar](https://www.sphinx-doc.org/en/master/usage/restructuredtext/directives.html#directive-glossary) zeigt eine konkrete Darstellung als Definitionsliste. Dokumentformate und Softwareprojekte können das anders lösen. Für die Suche kann ein separater Index Begriffe und Dateien zuordnen. Eine stabile Kennung hält Zuordnungen auch dann nachvollziehbar, wenn eine Anzeigeform angepasst wird.

## 5. Wo begegnet mir das unter Linux?

Unter Linux treffen Einsteiger auf Fachwörter in Manpages, Installationsdialogen und Ausgaben. Ein Glossar erklärt allgemeine Konzepte wie Paketierung. Die Handbuchseite eines Programms beantwortet eher Fragen zu dessen konkreten Argumenten.

## 6. Konkretes Beispiel Schritt für Schritt

Gedankenbeispiel. Eine Anwendung zeigt den Begriff „Zwischenspeicher“ in einer Hilfe an.

1. Die Erklärung nennt den Zweck und beschreibt, warum ein Zwischenspeicher erneuert werden kann.
2. „Cache“ wird als alternative Benennung für die Suche erfasst.
3. Ein Querverweis auf „Konfiguration“ erklärt, dass Einstellungen in einer anderen Dateiklasse liegen können.
4. Die Begriffserklärung erhält eine stabile Kennung, damit andere Seiten sie eindeutig verlinken können.

Nun kann eine Person vom Dialog zur Erklärung und von dort zu einem passenden verwandten Thema wechseln.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Wörterbuch behandelt Wörter einer Sprache breit. Ein Glossar wählt die für einen Kontext benötigten Begriffe aus. Eine Referenz beschreibt eine konkrete Programmschnittstelle oder Konfigurationsoption im Detail.

## 8. Häufige Missverständnisse

Eine alphabetische Liste allein erklärt noch keine Begriffe. Viele Querverweise helfen nur, wenn ihr Zusammenhang erkennbar ist. Umgekehrt braucht ein Glossar keine starre Reihenfolge, falls Suche oder Navigation die Einträge gut erschließen.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Formuliere Definitionen so, dass sie nicht im Kreis aufeinander verweisen. Prüfe Linkziele, Varianten und die Konsistenz zwischen Suchindex und Text. Benenne den Anwendungsbereich, wenn ein Begriff außerhalb davon anders verwendet wird.

## 10. Verwandte Begriffe

# Boolean

## 1. Kurzbeschreibung

Ein Boolean ist ein Wahrheitswert mit zwei möglichen Zuständen: wahr und falsch. In Python heißen die beiden Werte `True` und `False`, mit großem Anfangsbuchstaben. Sie beantworten beispielsweise die Frage, ob ein Vergleich zutrifft. Das Quellbeispiel `is_admin = False` bindet einen Namen an einen solchen Wert; es verändert keine tatsächlichen Benutzerrechte.

## 2. Was bedeutet der Begriff?

Ein Wahrheitswert beschreibt das Ergebnis einer logisch formulierten Frage. „Ist die Anzahl größer als null?“ kann wahr oder falsch sein. Das ist von Unsicherheit zu trennen: Ein unbekannter oder noch nicht geprüfter Zustand wird nicht allein dadurch richtig modelliert, dass man ihn als `False` behandelt.

Pythons Typ `bool` hat genau die zwei konstanten Instanzen `True` und `False`. Außerdem ist er dort ein Untertyp von `int`. Das ist eine Python-Eigenschaft, keine allgemeine Definition aller booleschen Typen. Die [Dokumentation zum Typ bool](https://docs.python.org/3.13/library/stdtypes.html#boolean-type-bool) erläutert beide Punkte. Groß- und Kleinschreibung richten sich nach der jeweiligen Sprache; die kleingeschriebenen Wörter aus anderen Formaten sind keine entsprechenden Python-Schlüsselwerte.

## 3. Einfacher Vergleich aus dem Alltag

Eine Kontrolllampe kann anzeigen, ob eine Tür geschlossen ist. Leuchtet sie nach einer zuverlässig ausgeführten Prüfung, entspricht das einer beantworteten Ja/Nein-Frage.

Der Vergleich endet bei nicht erfassten Zuständen: Ein defekter Sensor ist nicht einfach eine offene Tür. Genauso sollte ein Programm „Prüfung fehlgeschlagen“ oder „noch unbekannt“ bei Bedarf getrennt speichern. Ein einzelner Boolean reicht nur dann aus, wenn die Aufgabe tatsächlich mit zwei Zuständen vollständig beschrieben ist.

## 4. Wie funktioniert das?

Vergleiche wie `anzahl > 0` liefern bei den hier verwendeten eingebauten Zahlen einen Boolean. Logische Verknüpfungen verbinden Bedingungen: `and` verlangt bei zwei booleschen Werten beide, `or` mindestens einen wahren Wert; `not` kehrt den Wahrheitswert um.

Python kann außerdem viele andere Objekte in einem Bedingungskontext beurteilen. Null und leere Strings oder Listen gelten dabei als falsch; ein nichtleerer String gilt als wahr. Diese Regeln stehen unter [Wahrheitswertprüfung](https://docs.python.org/3.13/library/stdtypes.html#truth-value-testing). Damit ist der Text `"False"` ein besonders wichtiger Stolperstein: Er ist nichtleer und wird bei dieser Prüfung als wahr behandelt.

`and` und `or` werten ihren rechten Teil nur aus, wenn er benötigt wird. Bei beliebigen Objekten liefern sie zudem einen ihrer Operanden zurück, nicht zwingend einen Boolean. Die [Sprachreferenz zu booleschen Operationen](https://docs.python.org/3.13/reference/expressions.html#boolean-operations) beschreibt diese Kurzschlussauswertung. Im Lernbeispiel werden für die Verknüpfung bewusst echte Booleans verwendet.

## 5. Wo begegnet mir das unter Linux?

Ein Programm kann damit festhalten, ob eine Ansicht aktiviert ist oder ob ein festgelegter Grenzwert überschritten wurde. Für die Anzeige könnte ein Wahrheitswert beispielsweise bestimmen, ob ein Hinweis eingeblendet wird.

Ein gespeicherter Name wie `is_admin` ist jedoch keine Berechtigungsprüfung des Betriebssystems. Das Programm muss verlässliche Informationen erheben und die tatsächlich vorgesehene Schnittstelle verwenden. Auch eine unbekannte Netzwerkverbindung sollte nicht vorschnell als „sicher“ oder „unsicher“ bezeichnet werden, wenn das zugrunde liegende Prüfergebnis fehlt.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verwendet eine erfundene Rollenangabe und eine erfundene Auswahl. Es prüft keine realen Konten:

```python
is_admin = False
auswahl_vorhanden = True
freigabe = is_admin and auswahl_vorhanden
hinweis_noetig = not is_admin
assert type(is_admin) is bool
assert freigabe is False
assert hinweis_noetig is True
assert bool("False") is True
assert bool("") is False
print(freigabe)
print(hinweis_noetig)
print(bool("False"), bool(""))
```

Die Ausgabe lautet:

```text
False
True
True False
```

Die Verknüpfung ergibt falsch, weil die erste Bedingung nicht erfüllt ist. Die Negation ergibt wahr. Die letzte Zeile zeigt den Unterschied zwischen einem nichtleeren und einem leeren Text. Sie übersetzt gerade nicht die Wörter „wahr“ und „falsch“ in ihre Bedeutung.

## 7. Abgrenzung zu ähnlichen Begriffen

`False`, `0` und der leere String können sich in Bedingungen ähnlich verhalten, sind aber nicht derselbe Wert mit demselben Typ. `None` steht in Python häufig für das Fehlen eines Ergebnisses. Eine Zeichenkette kann das Wort `False` enthalten, ohne dadurch ein Boolean zu sein.

## 8. Häufige Missverständnisse

Ein falsches Ergebnis ist kein automatischer Programmfehler. Umgekehrt ist eine erfolgreich ausgeführte Prüfung nicht automatisch wahr. Auch sollten `and` und `or` nicht mit den zeichenweise beziehungsweise bitweise arbeitenden Operatoren anderer Aufgaben verwechselt werden; für logische Bedingungen sind die logischen Wörter die verständliche Wahl.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Formuliere Namen als klar beantwortbare Fragen. Dokumentiere, was „unbekannt“ bedeutet. Wenn eine Textkonfiguration Wahrheitswerte enthält, lege erlaubte Schreibweisen und die Behandlung ungültiger Eingaben ausdrücklich fest; `bool(text)` ist dafür kein allgemeiner Übersetzer. Das Beispiel ändert ausschließlich lokale Python-Bindungen und besitzt keine sicherheitsrelevante Wirkung.

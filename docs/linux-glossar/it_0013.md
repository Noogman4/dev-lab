# Operand

## 1. Kurzbeschreibung

Ein Operand ist ein Wert oder ein Teilausdruck, auf den ein Operator angewendet wird. Bei `2 + 3` sind `2` und `3` die Operanden des Plusoperators. Der Operator legt die Verknüpfung fest; die Operanden liefern die dafür verwendeten Daten. Auch Texte und zusammengesetzte Ausdrücke können diese Rolle übernehmen.

## 2. Was bedeutet der Begriff?

Die Bezeichnung beschreibt eine Rolle innerhalb eines Ausdrucks, keinen eigenen Datentyp. Die Zahl `2` ist ein Integer und zugleich im genannten Ausdruck ein Operand. Bei `anzahl + 3` liefert dagegen der Name `anzahl` den linken Wert. Bei `(2 + 3) * 4` ist die Summe der linke Operand der Multiplikation.

Einstellige Operatoren benötigen einen Operanden, etwa das Minus in `-anzahl`. Zweistellige Operatoren benötigen zwei. Wie viele Werte erwartet werden und welche Typen geeignet sind, gehört zur Definition des Operators in der jeweiligen Sprache.

## 3. Einfacher Vergleich aus dem Alltag

Beim Vergleich zweier Koffer auf einer Waage sind die Koffer die beteiligten Gegenstände, das Vergleichen ist die Tätigkeit. Nimmst du andere Koffer, kann sich das Ergebnis ändern, obwohl du dieselbe Tätigkeit ausführst.

Die Grenze des Vergleichs: Ein Programmausdruck kann seine Operanden erst berechnen oder durch Funktionsaufrufe gewinnen. Die „Gegenstände“ stehen nicht immer schon fertig bereit. Außerdem kann ein Operator mit den beteiligten Datentypen unvereinbar sein, selbst wenn die Schreibweise plausibel aussieht.

## 4. Wie funktioniert das?

Python wertet die benötigten Teilausdrücke aus und wendet anschließend die passende Operation auf deren Werte an. Bei gewöhnlichen arithmetischen Ausdrücken werden die Bestandteile in der festgelegten Reihenfolge ausgewertet. Die [Sprachreferenz zur Auswertungsreihenfolge](https://docs.python.org/3.13/reference/expressions.html#evaluation-order) trennt dies von der Rangfolge, die die Gruppierung bestimmt.

Beide Operandentypen sind wichtig. Python kann zwei Zahlen multiplizieren, aber auch eine Folge mit einer ganzen Zahl wiederholen. Zwei beliebige Texte lassen sich dagegen nicht miteinander multiplizieren. Die zulässigen Kombinationen beschreibt die [Referenz zu binären Rechenoperationen](https://docs.python.org/3.13/reference/expressions.html#binary-arithmetic-operations).

Die Reihenfolge der Operanden kann ebenfalls entscheidend sein. Subtraktion und Division liefern bei vertauschten Eingaben gewöhnlich andere Ergebnisse. Dass die Addition gewöhnlicher Zahlen vertauschbar ist, erlaubt keine entsprechende Annahme für alle Operatoren und Datentypen.

## 5. Wo begegnet mir das unter Linux?

Ein Auswertungsskript kann zwei selbst erfasste Zählerstände voneinander abziehen. Der spätere und der frühere Stand übernehmen dabei unterschiedliche Rollen. Werden sie vertauscht, entsteht ein negatives Ergebnis, obwohl der Operator korrekt geschrieben wurde.

Das Wort kann auch in Werkzeughandbüchern auftauchen. Dort bezeichnet es teilweise übergebene Daten wie Dateinamen im Unterschied zu Optionen. Diese befehlsspezifische Verwendung sollte nicht mit der genauen Grammatik eines Python-Ausdrucks gleichgesetzt werden. Entscheidend bleibt die Dokumentation des konkreten Werkzeugs.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verwendet nur kleine feste Werte:

```python
links = 2
rechts = 3
summe = links + rechts
differenz = rechts - links
umgekehrt = links - rechts
wiederholung = "ab" * rechts
assert summe == 5
assert (differenz, umgekehrt) == (1, -1)
assert wiederholung == "ababab"
print(summe)
print(differenz, umgekehrt)
print(wiederholung)
```

Die Ausgabe lautet:

```text
5
1 -1
ababab
```

Bei der Addition liefern zwei Namen die Operandenwerte. Die Subtraktionen zeigen, dass ihre Anordnung das Ergebnis verändert. Zuletzt sind ein String und ein Integer die Operanden einer Wiederholung. Derselbe Oberbegriff deckt also unterschiedliche Arten von Daten ab.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Operator bezeichnet die Verknüpfung. Ein Operand liefert einen ihrer Werte. Ein Ergebnis entsteht durch die Auswertung. In einem größeren Ausdruck kann dieses Ergebnis wiederum Operand einer weiteren Operation sein. Ein Funktionsargument ist dagegen eine Eingabe bei einem Funktionsaufruf; die Begriffe beschreiben verschiedene sprachliche Zusammenhänge.

## 8. Häufige Missverständnisse

Ein Operand muss weder eine direkt hingeschriebene Zahl noch eine Variable sein. Auch gibt es keinen Datentyp namens „Operand“, den alle Sprachen bereitstellen müssten. Eine Fehlermeldung über ungeeignete Operandentypen betrifft die konkrete Kombination aus Operation und Werten.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe bei unerwarteten Ergebnissen beide Seiten, ihre Reihenfolge und ihre Typen. Eine falsche Einheit wie Bytes statt Kilobytes bleibt trotz geeigneter Zahlentypen ein fachlicher Fehler. Das Beispiel erzeugt keine externen Daten und benötigt keine privilegierten Zugriffe.

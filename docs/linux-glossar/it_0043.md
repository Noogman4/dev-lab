# Stack

## 1. Kurzbeschreibung

Ein Stack ist ein Stapelspeicher nach dem Prinzip „Last In, First Out“, kurz LIFO: Das zuletzt abgelegte Element wird zuerst entnommen. Neue Elemente kommen an die Spitze. Der Begriff beschreibt zunächst die Zugriffsregel, nicht eine bestimmte Klasse, Programmiersprache oder physische Speicherregion.

## 2. Was bedeutet der Begriff?

Ein Stack unterstützt typischerweise Ablegen, Entnehmen und Nachsehen an der Spitze. Häufig heißen diese Operationen `push`, `pop` und `peek`; die konkreten Namen unterscheiden sich zwischen Schnittstellen. Die Entnahme entfernt das oberste Element, das bloße Nachsehen nicht.

Eine Liste kann als Stack verwendet werden, wenn das Programm sie entsprechend behandelt. Das [offizielle Python-Tutorial](https://docs.python.org/3.13/tutorial/datastructures.html#using-lists-as-stacks) zeigt dafür `append` und `pop` am Listenende. Die Liste erlaubt zwar weitere Operationen, doch deren beliebige Verwendung wäre nicht mehr ausschließlich die vereinbarte Stapeldisziplin.

## 3. Einfacher Vergleich aus dem Alltag

Auf einem Tellerstapel liegt der zuletzt aufgelegte Teller oben. Wenn du stets von oben entnimmst, kommt dieser zuerst wieder heraus. Du musst nicht wissen, an welcher Position jeder ältere Teller ursprünglich abgelegt wurde.

Die Grenze des Vergleichs: Ein Datenstack kann Texte, Zahlen oder komplexe Objekte enthalten. Er benötigt außerdem eine Regel für den leeren Zustand und gegebenenfalls eine Kapazitätsgrenze. Ein Programm kann solche Zustände nicht durch vorsichtiges Ausprobieren mit den Händen erkennen.

## 4. Wie funktioniert das?

Beim Ablegen wächst der Stapel um ein Element. Beim Entnehmen wird die aktuelle Spitze zurückgegeben und entfernt. Nach mehreren Entnahmen erscheinen zuvor verdeckte Elemente wieder. Voraussetzung für eine Entnahme ist ein vorhandenes Element oder eine ausdrücklich vereinbarte Behandlung des leeren Falls.

Python bietet zusätzlich `queue.LifoQueue` als eigene LIFO-Struktur. Bei einer festgelegten Kapazität kann das Einfügen warten, bis Platz frei wird. Die [offizielle Referenz zu LifoQueue](https://docs.python.org/3.13/library/queue.html#queue.LifoQueue) beschreibt diese Grenze. Solches Warteverhalten ist keine allgemeine Eigenschaft jedes Stacks; es gehört zur gewählten Schnittstelle.

## 5. Wo begegnet mir das unter Linux?

Programme können noch zu bearbeitende Schritte auf einem Stapel verwalten. Auch verschachtelte Funktionsaufrufe werden häufig anhand eines Aufrufstapels erklärt. Die spezielle technische Verwaltung von Aufrufen ist jedoch nicht mit einer selbst angelegten Python-Liste gleichzusetzen.

Eine Rückgängig-Funktion kann Stapelideen verwenden. Sie benötigt zusätzlich passende Informationen, um eine Aktion wirklich rückgängig zu machen. Das bloße Entfernen eines gespeicherten Texts macht eine bereits veränderte Datei nicht automatisch wieder unverändert.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel prüft Reihenfolge, Nachsehen und leere Entnahme mit eigenen Texten:

```python
stapel = []
for wert in ["A", "B", "C"]:
    stapel.append(wert)
assert stapel[-1] == "C"
assert len(stapel) == 3
entnommen = [stapel.pop(), stapel.pop(), stapel.pop()]
assert entnommen == ["C", "B", "A"]
assert stapel == []
leer_erkannt = False
try:
    stapel.pop()
except IndexError:
    leer_erkannt = True
assert leer_erkannt
print(entnommen)
```

Die Ausgabe lautet:

```text
['C', 'B', 'A']
```

Die drei Elemente werden in der Reihenfolge A, B, C abgelegt und in umgekehrter Reihenfolge entnommen. Der Zugriff auf die Spitze verändert vorher nichts. Die absichtlich zusätzliche Entnahme zeigt den Fehlerfall dieser Listenimplementierung. Andere Stack-Schnittstellen können dafür andere Rückmeldungen vorsehen.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine gewöhnliche Liste stellt auch freie Positionszugriffe bereit. Ein Stack beschränkt den vorgesehenen Ablauf auf die Spitze. Eine Warteschlange folgt dagegen üblicherweise der Ankunftsreihenfolge. Eine Prioritätsstruktur wählt nach einer anderen Regel und ist deshalb nicht allein aufgrund einer Entnahmeoperation ein Stack.

## 8. Häufige Missverständnisse

LIFO bedeutet nicht alphabetisch oder numerisch absteigend. Ein Stack sortiert seine Elemente nicht nach Wert. Auch sind Datentyp, Kapazität und Warteverhalten nicht durch den Namen allein festgelegt. Ein leerer Stack enthält kein automatisch verfügbares Standardelement.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Lege den Umgang mit leerem Zustand und voller Kapazität fest. Prüfe bei gemeinsam verwendeten Strukturen die Anforderungen an koordinierte Zugriffe. Das Beispiel verwendet ausschließlich eine lokale Liste; blockierende LifoQueue- und reale Aufrufstapelabläufe wurden nicht praktisch getestet.

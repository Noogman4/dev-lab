# Ausdruck

## 1. Kurzbeschreibung

Ein Ausdruck ist ein Stück Programmcode, das ausgewertet wird und dabei einen Wert liefert. `2 + 3` ergibt beispielsweise die Zahl `5`. Auch ein einzelner Name, ein Vergleich oder ein Funktionsaufruf kann ein Ausdruck sein. Welche Schreibweisen erlaubt sind, bestimmt die jeweilige Programmiersprache.

## 2. Was bedeutet der Begriff?

„Auswerten“ bedeutet, die Bedeutung des Ausdrucks anhand seiner Bestandteile und der Sprachregeln zu bestimmen. Dabei können Namen nachgeschlagen, Werte verknüpft oder Funktionen aufgerufen werden. Das Ergebnis kann eine Zahl, ein Text, ein Wahrheitswert oder ein anderes Objekt sein.

Ein Ausdruck muss nicht erfolgreich enden: Eine Division durch null löst in Python einen Fehler aus. Außerdem kann die Auswertung sichtbare Aktionen auslösen. Der Aufruf `print('Hallo')` gibt Text aus und liefert in Python zugleich den besonderen Wert `None`. „Liefert einen Wert“ bedeutet daher nicht „zeigt diesen Wert automatisch an“ oder „verändert garantiert nichts“.

## 3. Einfacher Vergleich aus dem Alltag

Auf einem Einkaufszettel steht die Rechnung „zwei Packungen zu je drei Euro“. Setzt du Anzahl und Preis ein, erhältst du einen Gesamtbetrag. Das ähnelt einem Ausdruck mit Eingaben und Ergebnis.

Die Grenze des Vergleichs: Ein Programmausdruck kann viel mehr als eine Rechnung sein. Er kann einen Text zusammenstellen oder eine Funktion aufrufen. Zudem gelten technische Regeln für Zahlenbereiche, Typen und Auswertungsreihenfolge, die auf dem Einkaufszettel nicht sichtbar werden.

## 4. Wie funktioniert das?

Operatoren sind Zeichen oder Wörter für Verknüpfungen, etwa `+`, `*` oder `and`. Ihre Bindungsstärke legt fest, welche Teile zusammengehören. So bedeutet `2 + 3 * 4` eine Addition, deren rechter Bestandteil zuerst als Produkt berechnet wird. Klammern können diese Gruppierung ändern. Das ist von der Reihenfolge zu unterscheiden, in der einzelne Teilausdrücke ausgewertet werden; beide Regeln erläutert die [Python-Referenz zur Auswertung und Operatorrangfolge](https://docs.python.org/3.13/reference/expressions.html#evaluation-order).

Nicht immer werden alle möglichen Bestandteile ausgewertet. Bei Pythons `and` genügt ein falscher linker Operand, um den rechten auszulassen. Diese Kurzschlussauswertung ist in der [Referenz zu booleschen Operationen](https://docs.python.org/3.13/reference/expressions.html#boolean-operations) beschrieben. Sie kann unter anderem verhindern, dass ein unnötiger Funktionsaufruf stattfindet.

## 5. Wo begegnet mir das unter Linux?

In Python-Skripten kannst du aus Messwerten Summen berechnen oder Meldungen zusammensetzen. Ein Überwachungsprogramm kann beispielsweise zwei selbst erfasste Zählerstände vergleichen. Der Vergleich ergibt einen Wert, den eine nachfolgende Entscheidung verwendet.

Manche Terminalprogramme besitzen eigene Ausdruckssprachen. Deren Syntax ist nicht automatisch Python. Wenn eine Dokumentation von einem Ausdruck spricht, prüfe deshalb zuerst, welches Programm oder welche Sprache ihn auswertet. Dieselben Zeichen können in einer Shell, in Python und in einer Suchsprache verschiedene Bedeutungen haben.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel zeigt Berechnung, Vergleich und ausdrückliche Ausgabe:

```python
summe = 2 + 3
vergleich = summe > 4
ohne_klammern = 2 + 3 * 4
mit_klammern = (2 + 3) * 4
assert summe == 5
assert vergleich is True
assert (ohne_klammern, mit_klammern) == (14, 20)
print(summe)
print(vergleich)
print(ohne_klammern, mit_klammern)
```

Die Ausgabe lautet:

```text
5
True
14 20
```

Die rechten Seiten der Zuweisungen werden ausgewertet, ihre Ergebnisse an Namen gebunden. `summe > 4` liefert einen Boolean. Die letzten beiden Rechnungen zeigen, dass Klammern das Ergebnis ändern können. Die Ausgabe entsteht erst durch die Aufrufe von `print`; die Berechnung einer Zahl allein verlangt keine Bildschirmausgabe.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Wert ist das Ergebnis oder ein bereits vorhandenes Objekt; der Ausdruck ist der Code, der es liefert oder bezeichnet. Eine Anweisung kann einen Ausdruck enthalten. Python kennt zudem Ausdrucksanweisungen, bei denen ein Ausdruck allein steht. In einem Skript wird dessen Ergebnis normalerweise nicht automatisch angezeigt; der interaktive Interpreter behandelt das anders, wie die [Referenz zu Ausdrucksanweisungen](https://docs.python.org/3.13/reference/simple_stmts.html#expression-statements) erklärt.

## 8. Häufige Missverständnisse

`=` und `==` sind in Python verschieden: Das erste gehört hier zur Zuweisung, das zweite vergleicht Werte. Auch ein Text wie `"2 + 3"` ist keine automatisch ausgeführte Rechnung. Er bleibt zunächst eine Zeichenkette.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Setze Klammern, wenn sie die beabsichtigte Gruppierung verständlicher machen. Behandle fremden Text nicht als vertrauenswürdigen Programmcode. Insbesondere ist die allgemeine Auswertung über `eval` kein geeigneter Weg, um beliebige Benutzereingaben sicher in Zahlen umzuwandeln. Das gezeigte Beispiel enthält nur feste, selbst gewählte Werte und greift weder auf Dateien noch auf Dienste zu.

# Methode

## 1. Kurzbeschreibung

Eine Methode ist zu einem Objekt oder einer Klasse gehörendes aufrufbares Verhalten. Bei einer gewöhnlichen Python-Instanzmethode wird die betreffende Instanz beim Aufruf automatisch mitgegeben. Das Quellbeispiel `button.click()` kann eine solche Methode aufrufen. Der Name allein beweist jedoch nicht, dass dabei eine echte Schaltfläche oder ein Betriebssystemereignis beteiligt ist.

## 2. Was bedeutet der Begriff?

Eine Methode verbindet eine Operation mit ihrem fachlichen Gegenstand. Eine Auftragsbeschreibung könnte beispielsweise ihren eigenen Zustand prüfen oder eine Meldung aus ihren Daten erzeugen. Der aufrufende Code benötigt dafür eine passende Schnittstelle und muss nicht sämtliche internen Details kennen.

Python unterscheidet zwischen einer in der Klasse definierten Funktion und dem über eine Instanz gebundenen Methodenobjekt. Die [offizielle Einführung zu Methodenobjekten](https://docs.python.org/3.13/tutorial/classes.html#method-objects) erklärt, dass der Instanzzugriff Funktion und Objekt zusammenführt. Das ist der Grund für das automatisch übergebene erste Argument.

## 3. Einfacher Vergleich aus dem Alltag

Ein Arbeitsauftrag trägt die Anweisung „eigenen Status melden“. Wird diese Operation an einem bestimmten Auftrag ausgelöst, bezieht sie sich auf genau dessen Daten und nicht auf einen beliebigen anderen Auftrag.

Die Grenze des Vergleichs: Das Objekt versteht keine Umgangssprache und wählt nicht selbstständig die richtige Handlung. Die Methode besteht aus festgelegtem Code. Außerdem können Methoden außerhalb liegende Daten verändern oder Fehler auslösen; die Zugehörigkeit zu einem Objekt macht eine Operation nicht automatisch rein oder nebenwirkungsfrei.

## 4. Wie funktioniert das?

Eine gewöhnliche Instanzmethode wird in der Klasse als Funktion definiert. Ihr erster Parameter heißt üblicherweise `self`. Bei `objekt.methode()` setzt Python die gebundene Instanz für diesen Parameter ein. `self` ist eine Benennungskonvention, kein besonderes Python-Schlüsselwort.

Der Zugriff `objekt.methode` ohne Aufrufklammern kann das gebundene Methodenobjekt liefern. Erst ein späterer Aufruf führt den Körper aus. Dadurch kann passendes Verhalten beispielsweise für eine spätere Verarbeitung gespeichert werden.

Nicht jede innerhalb einer Klasse zugängliche Funktion besitzt dieselbe Bindung. `staticmethod` definiert ausdrücklich eine Variante ohne automatisch übergebenes erstes Argument, wie die [offizielle staticmethod-Referenz](https://docs.python.org/3.13/library/functions.html#staticmethod) beschreibt. Eine vereinfachte Regel „jede Methode erhält immer self“ wäre deshalb falsch.

## 5. Wo begegnet mir das unter Linux?

Python-Bibliotheken verwenden Methoden etwa für das Lesen eines Dateiobjekts oder das Bearbeiten einer Sammlung. Anwendungen können eigene Methoden für Ansichtsmodelle und Zustandswechsel bereitstellen. Die tatsächliche Wirkung muss aus der jeweiligen Dokumentation hervorgehen.

Bei einer GUI kann eine Callback-Verbindung vorsehen, dass eine Methode später aufgerufen wird. Das bloße Abrufen der Methode ist dann etwas anderes als ihr sofortiger Aufruf. Ob eine konkrete Bibliothek weitere Ereignisargumente übergibt, gehört zu deren eigener Schnittstelle.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verwendet eine eigene Zählerklasse ohne grafische Oberfläche:

```python
class Button:
    def __init__(self):
        self.klicks = 0

    def click(self):
        self.klicks += 1
        return self.klicks

button = Button()
assert button.click() == 1
aktion = button.click
assert button.klicks == 1
assert aktion() == 2
assert button.klicks == 2
print(button.klicks)
```

Die Ausgabe lautet:

```text
2
```

Der erste Aufruf erhöht den Zustand. Die Zuweisung an `aktion` speichert danach die gebundene Methode, ohne erneut zu zählen. Erst `aktion()` führt sie aus und verändert denselben Objektzustand. Es wurde kein tatsächlicher Mausklick erzeugt.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine Funktion kann unabhängig von einer Instanz aufgerufen werden. Eine gewöhnliche gebundene Methode verbindet Verhalten und Instanz. Ein Attribut kann auch reine Daten enthalten. Ein Callback beschreibt die Rolle eines später aufzurufenden Bausteins und kann eine Methode, Funktion oder andere passende Aufrufart verwenden.

## 8. Häufige Missverständnisse

Ein Methodenname ohne Klammern ist nicht automatisch ein ausgeführter Aufruf. `self` erzeugt keine Kopie des Objekts. Eine Methode muss nicht einen Wert anzeigen; Rückgabe und Ausgabe sind getrennt. Auch gelten die Bindungsregeln nicht in jeder Programmiersprache exakt wie in Python.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Dokumentiere Eingaben, Ergebnis und mögliche Zustandsänderungen. Unterscheide bei Ereignisschnittstellen das Registrieren vom sofortigen Aufrufen. Das Beispiel bearbeitet ausschließlich seinen eigenen Zähler; echte GUI-Callbacks und Betriebssystemereignisse wurden nicht praktisch geprüft.

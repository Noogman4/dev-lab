# Profiling

## 1. Kurzbeschreibung

Profiling sammelt Messdaten darüber, wo eine konkrete Programmausführung Zeit oder Speicher verwendet. Das Ergebnis ist ein Profil. Es hilft dir, auffällige Stellen zu finden und eine gezielte Untersuchung zu beginnen.

## 2. Was bedeutet der Begriff?

Ein Profil kann Funktionsaufrufe zählen, Laufzeiten zuordnen oder Speicherzuweisungen verfolgen. Welche Aussage möglich ist, hängt vom Messwerkzeug ab. [cProfile und profile](https://docs.python.org/3.13/library/profile.html) dokumentieren deterministisches Profiling für Python. [tracemalloc](https://docs.python.org/3.13/library/tracemalloc.html) verfolgt ausgewählte Speicherzuweisungen im Python-Programm.

## 3. Einfacher Vergleich aus dem Alltag

In einer Küche notierst du, welche Arbeitsschritte beim Kochen Zeit kosten. Eine zweite Liste könnte erfassen, wo wie viele Zutaten gebraucht werden. Die beiden Listen beantworten verschiedene Fragen. Auch Software braucht eine Messgröße, die zum beobachteten Problem passt.

## 4. Wie funktioniert das?

Ein deterministischer Profiler kann Aufrufereignisse beobachten. Ein Stichprobenprofiler betrachtet zu ausgewählten Zeitpunkten, wo das Programm gerade arbeitet. Das bietet unterschiedliche Genauigkeit und unterschiedlichen Messaufwand. Eine Zeitangabe für eine Funktion kann nur ihre eigene Arbeit enthalten oder zusätzlich die aufgerufenen Unterfunktionen.

Speicherprofile benötigen ebenfalls einen klaren Bezug. Ein Werkzeug kann beispielsweise die Herkunft bestimmter Zuweisungen im Python-Code verfolgen. Daraus ergibt sich noch keine vollständige Messung aller Speicheranteile des Prozesses.

## 5. Wo begegnet mir das unter Linux?

Unter Linux kann es Profile für die Sprachebene und Werkzeuge für Vorgänge am Betriebssystem geben. Wenn ein Fenster bei einer bestimmten Aktion stockt, kann eine Messung im relevanten Ausschnitt hilfreicher sein als ein langer Startlauf mit vielen anderen Tätigkeiten.

## 6. Konkretes Beispiel Schritt für Schritt

`cProfile` erfasst den gesamten Abschnitt zwischen `enable()` und `disable()`. Dazu gehören die drei Aufrufe von `notizlaenge` und deren Aufrufe von `strip()` und `len()`. Anschließend filtert das Beispiel die Statistik auf `notizlaenge` und prüft deren Aufrufzahl. [Python-Dokumentation zu `cProfile.Profile.enable`](https://docs.python.org/3.13/library/profile.html#cProfile.Profile.enable)

```python
import cProfile
import pstats

def notizlaenge(text):
    return len(text.strip())

profile = cProfile.Profile()
profile.enable()
result = [notizlaenge(t) for t in ("a", " bb", "ccc ")]
profile.disable()

calls = [values[1] for key, values in pstats.Stats(profile).stats.items()
         if key[2] == "notizlaenge"]
assert result == [1, 2, 3] and calls == [3]
print("Aufrufe:", calls[0])
```

Die Ausgabe ist `Aufrufe: 3`. Das Beispiel misst keine relevante reale Anwendungslast.

## 7. Abgrenzung zu ähnlichen Begriffen

Profiling zeigt, wo Arbeit anfällt. Ein Benchmark misst eine definierte Aufgabe unter vergleichbaren Bedingungen. Ein Debugger hilft bei Fragen zum konkreten Zustand in einem Ablauf.

## 8. Häufige Missverständnisse

Eine Funktion mit hoher kumulierter Zeit muss die Arbeit nicht selbst ausführen. Sie kann langsamere Unterfunktionen aufrufen. Die Rangfolge eines Profils gilt zunächst für die gemessene Eingabe und Umgebung.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Wähle repräsentative Testdaten und halte Version und Messmethode fest. Prüfe Änderungen anschließend mit einer geeigneten Vergleichsmessung. Ein Profiler kann Zeitbedarf oder Ablauf seines Ziels beeinflussen.

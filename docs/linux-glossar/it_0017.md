# Funktion

## 1. Kurzbeschreibung

Eine Funktion ist ein aufrufbarer Programmbaustein, der eine bestimmte Aufgabe ausführt. Sie kann Eingaben entgegennehmen und ein Ergebnis zurückgeben. Die Quelle beschreibt einen wiederverwendbaren Codeblock mit Namen. Das passt zu vielen Funktionen; ein eigener Name ist jedoch nicht für jede Funktionsform erforderlich.

## 2. Was bedeutet der Begriff?

Eine Funktion bündelt zusammengehörende Schritte hinter einer Schnittstelle. Ein Aufruf verwendet diese Schnittstelle, statt die Schritte jedes Mal erneut aufzuschreiben. Das erleichtert gezielte Änderungen und Prüfungen. Wiederverwendung ist ein Vorteil, aber eine Funktion darf auch nur einmal aufgerufen werden.

In Python erzeugt eine ausgeführte `def`-Definition ein Funktionsobjekt und bindet es an einen Namen. Der eingerückte Körper läuft bei einer gewöhnlichen Funktion erst beim Aufruf. Das [Tutorial zum Definieren von Funktionen](https://docs.python.org/3.13/tutorial/controlflow.html#defining-functions) erklärt Definition, lokale Namen und Rückgaben. Spezielle Funktionsarten können zusätzliche Ausführungsregeln besitzen; das Beispiel behandelt eine gewöhnliche Funktion.

## 3. Einfacher Vergleich aus dem Alltag

Ein beschrifteter Arbeitsauftrag wie „Etikett erstellen“ kann festgelegte Eingaben, Arbeitsschritte und ein Ergebnis besitzen. Wer ein Etikett benötigt, übergibt die benötigten Angaben und erhält den fertigen Text.

Der Vergleich hat Grenzen: Eine Programmfunktion kann auch lediglich etwas ausgeben oder einen Zustand verändern. Sie muss nicht ausschließlich ein neues Produkt herstellen. Ebenso ist sie keine mathematische Garantie, dass gleiche Eingaben stets dasselbe Ergebnis liefern. Uhrzeit, Zufall oder äußere Daten können ihr Verhalten beeinflussen.

## 4. Wie funktioniert das?

Die Definition nennt Parameter, also vorgesehene Eingabeplätze. Beim Aufruf werden konkrete Argumente zugeordnet. Im Körper können lokale Namen und andere Funktionen verwendet werden. Mit `return` wird ein Ergebnis an den Aufrufer geliefert. Erreicht eine gewöhnliche Python-Funktion ihr Ende ohne solche Rückgabe, liefert sie `None`.

Python kennt außerdem `lambda` für kleine anonyme Funktionen aus einem Ausdruck. Diese besitzen nicht dieselbe Körperstruktur wie eine mit `def` geschriebene mehrzeilige Funktion. Die [Sprachreferenz zu Lambda-Ausdrücken](https://docs.python.org/3.13/reference/expressions.html#lambda) belegt, warum „mit Namen“ keine allgemeine Voraussetzung des Begriffs ist.

## 5. Wo begegnet mir das unter Linux?

Ein Python-Werkzeug kann das Formatieren einer Meldung von ihrem Anzeigen trennen. Dieselbe Formatierungsfunktion lässt sich dann in einer Terminalausgabe und in einer grafischen Ansicht verwenden. Für ihre Prüfung muss keine echte Systemkonfiguration verändert werden.

Der Name `check_dns` aus der Quelle wäre lediglich eine gewählte Bezeichnung. Er beweist nicht, dass eine Funktion eine vollständige DNS-Prüfung ausführt. Aussagekräftige Namen sollten deshalb zu dokumentierten Eingaben, Ergebnissen und möglichen Nebenwirkungen passen.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel erzeugt zwei Meldungen aus eigenen Zahlen:

```python
def meldung(anzahl):
    return f"Einträge: {anzahl}"

erste = meldung(2)
zweite = meldung(5)
assert erste == "Einträge: 2"
assert zweite == "Einträge: 5"
assert meldung(0) == "Einträge: 0"
print(erste)
print(zweite)
```

Die Ausgabe lautet:

```text
Einträge: 2
Einträge: 5
```

Die Definition legt die Arbeit fest. Jeder Aufruf ordnet dem Parameter `anzahl` einen konkreten Wert zu und liefert einen formatierten String zurück. Erst die späteren `print`-Aufrufe zeigen die Ergebnisse an. Die zusätzliche Zusicherung prüft auch eine leere Anzahl.

## 7. Abgrenzung zu ähnlichen Begriffen

Die Definition erstellt die Funktion; der Aufruf verwendet sie. Ein Parameter gehört zur Definition, ein Argument zum Aufruf. Ein Algorithmus beschreibt einen Lösungsweg und kann durch eine oder mehrere Funktionen umgesetzt werden. Eine einzelne Anweisung kann innerhalb eines Funktionskörpers stehen.

## 8. Häufige Missverständnisse

Das Definieren einer gewöhnlichen Funktion führt ihren Körper noch nicht aus. Ausgabe und Rückgabewert sind verschieden. Eine Funktion ohne ausdrücklich geschriebenes `return` liefert in Python nicht automatisch den zuletzt berechneten Ausdruck zurück. Der Aufruf mit Klammern ist außerdem etwas anderes als der bloße Zugriff auf das Funktionsobjekt.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Halte Aufgaben und Schnittstellen überschaubar. Dokumentiere, ob eine Funktion externe Daten verändert. Prüfe kleine eigene Eingaben und Grenzfälle. Das Beispiel verarbeitet nur Zahlen und Text im Speicher; es prüft kein echtes Netzwerk und startet keinen Dienst.

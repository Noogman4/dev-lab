# Anweisung

## 1. Kurzbeschreibung

Eine Anweisung ist eine sprachlich festgelegte Einheit eines Programms, die beim Ausführen eine Aktion oder einen Ablauf beschreibt. Sie kann einen Namen an einen Wert binden, eine Ausgabe auslösen oder zwischen Wegen entscheiden. Die genaue Bedeutung hängt von der Programmiersprache ab; sie ist nicht mit einem Terminalbefehl gleichzusetzen.

## 2. Was bedeutet der Begriff?

In der Glossarquelle steht „Ein einzelner Befehl im Programmcode“. Das ist eine erste Orientierung, aber zu eng: Eine Anweisung kann auch aus mehreren Zeilen und untergeordneten Anweisungen bestehen. Python unterscheidet einfache und zusammengesetzte Anweisungen.

Das Quellbeispiel `print('Hallo')` lässt sich genauer einordnen: Der Funktionsaufruf ist ein Ausdruck. Steht dieser allein als ausführbare Einheit, bildet er eine Ausdrucksanweisung. Diese Unterscheidung beschreibt die [Python-Sprachreferenz zu Ausdrucksanweisungen](https://docs.python.org/3.13/reference/simple_stmts.html#expression-statements). Dadurch können dieselben sichtbaren Zeichen je nach Betrachtung einen Aufrufausdruck oder die ganze Anweisung bezeichnen.

## 3. Einfacher Vergleich aus dem Alltag

Eine Arbeitsanweisung kann lauten: „Schreibe den Namen auf das Etikett.“ Eine umfangreichere lautet: „Wenn die Schachtel zerbrechlichen Inhalt enthält, klebe einen Warnhinweis auf.“ Beide geben vor, was unter bestimmten Umständen zu tun ist.

Der Vergleich endet dort, wo Menschen unausgesprochene Voraussetzungen ergänzen. Ein Programm errät weder fehlende Werte noch eine unklare Reihenfolge. Seine Sprache legt Schreibweise und Ausführungsregeln wesentlich genauer fest als ein alltäglicher Satz.

## 4. Wie funktioniert das?

Python liest den Programmtext nach Regeln seiner Grammatik, also seiner zulässigen Formen. Eine Zuweisung wie `anzahl = 2` bindet einen Namen an ein Objekt. Eine Ausdrucksanweisung wertet einen Ausdruck aus; ihr Nutzen kann beispielsweise die Ausgabe eines Textes sein.

Eine `if`-Anweisung führt abhängig vom Wahrheitswert ihrer Bedingung einen Block aus. Ein Block ist eine zusammengehörende Gruppe von Anweisungen. Bei Python wird diese Zugehörigkeit durch Einrückung sichtbar. Die [Referenz zur if-Anweisung](https://docs.python.org/3.13/reference/compound_stmts.html#the-if-statement) beschreibt die Auswahl zwischen den Zweigen. Der Doppelpunkt und die Einrückung sind hier Teil der Sprache, keine frei wählbare Dekoration.

## 5. Wo begegnet mir das unter Linux?

Bei einem Python-Hilfsskript können Anweisungen eine Auswertung vorbereiten, Daten vergleichen und das Ergebnis anzeigen. Auch Shell-Skripte besitzen sprachliche Konstruktionen für Entscheidungen und Wiederholungen; deren Regeln unterscheiden sich jedoch von Python.

Das Terminal ist nur eine mögliche Oberfläche zum Starten eines Programms. Eine Python-Anweisung gehört zum Python-Programmtext. Sie wird nicht dadurch zu einem gültigen Shell-Befehl, dass du sie in ein Terminalfenster kopierst. Für die Beispiele dieser Dokumentation wird daher ausdrücklich Python 3 vorausgesetzt.

## 6. Konkretes Beispiel Schritt für Schritt

Dieses vollständige Beispiel arbeitet nur mit einer selbst gewählten Zahl und einem kurzen Text:

```python
anzahl = 2
meldung = "leer"
if anzahl > 0:
    meldung = "vorhanden"
assert meldung == "vorhanden"
print(meldung)
```

Die Ausgabe lautet:

```text
vorhanden
```

Zuerst binden zwei Zuweisungen die Namen `anzahl` und `meldung`. Anschließend prüft die `if`-Anweisung die Bedingung. Weil zwei größer als null ist, wird die eingerückte Zuweisung ausgeführt. `assert` überprüft das erwartete Ergebnis; die letzte Ausdrucksanweisung ruft `print` auf.

Es gibt hier mehr Anweisungen als Ausgaben. Die Zuweisungen schreiben keinen sichtbaren Text. Außerdem gehört die eingerückte Zeile zur zusammengesetzten `if`-Anweisung, statt einen unabhängig ausgeführten Zweig zu bilden.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Ausdruck berechnet oder bezeichnet einen Wert. Eine Anweisung beschreibt einen ausführbaren Programmschritt oder eine Ablaufstruktur. Eine Funktion ist aufrufbarer Programmcode; der Aufruf kann innerhalb einer Anweisung vorkommen. Ein Shell-Befehl wird dagegen nach den Regeln der jeweiligen Shell verarbeitet.

## 8. Häufige Missverständnisse

Eine Anweisung entspricht nicht zwingend genau einer Textzeile. Ebenso garantiert eine syntaktisch gültige Anweisung kein sinnvolles Ergebnis: Die Bedingung kann falsch gewählt sein, ein benötigter Name kann fehlen oder eine ausgeführte Aktion kann einen Fehler auslösen.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Lies bei Entscheidungen zuerst die Bedingung und dann den zugehörigen Block. Prüfe vor dem Ausführen fremden Codes, ob er Dateien, Prozesse oder Netzwerkzugriffe verändert. Das gezeigte Beispiel hat lediglich eine Textausgabe. `assert` dient hier der Prüfung eines Lernbeispiels; es ersetzt keine dauerhafte Eingabeprüfung, weil Python Zusicherungen im Optimierungsmodus entfernen kann.

## 10. Verwandte Begriffe

Ein [Ausdruck](it_0003.md) liefert beispielsweise den Wahrheitswert einer Bedingung. Eine [Variable](it_0004.md) wird durch eine Zuweisung gebunden. Mehrere Anweisungen können zusammen einen [Algorithmus](it_0001.md) umsetzen.

# Liste

## 1. Kurzbeschreibung

Eine Liste ist eine geordnete Sammlung von Elementen. „Geordnet“ bedeutet hier, dass die Positionen und ihre Reihenfolge eine Rolle spielen; es bedeutet nicht automatisch „sortiert“. In Python ist `list` eine veränderliche Folge. Das Quellbeispiel `ports = [80, 443, 53]` legt eine solche Liste mit drei Zahlen an.

## 2. Was bedeutet der Begriff?

Eine Liste kann mehrere Werte zusammenhalten und nacheinander verarbeiten lassen. Ein Wert darf mehrfach vorkommen. Die konkrete Programmiersprache oder Bibliothek bestimmt, welche Elementarten, Zugriffsmöglichkeiten und Veränderungen erlaubt sind.

Python-Listen können unterschiedliche Objektarten enthalten, auch wenn zusammengehörige gleichartige Werte oft verständlicher sind. Die [offizielle Referenz zum Typ list](https://docs.python.org/3.13/library/stdtypes.html#lists) definiert sie als veränderliche Folgen und beschreibt ihre Konstruktion. Daraus folgt keine Aussage, dass alle in anderen Sprachen „Liste“ genannten Strukturen intern genauso aufgebaut oder ebenfalls veränderlich sind.

## 3. Einfacher Vergleich aus dem Alltag

Eine Einkaufsliste enthält Einträge in einer bestimmten Reihenfolge. Du kannst einen neuen Eintrag ergänzen, einen erledigten entfernen oder einen vorhandenen ersetzen. Derselbe Artikel darf versehentlich oder absichtlich zweimal vorkommen.

Die Grenze des Vergleichs: Ein Programm speichert keine Papierzeilen, sondern Verweise auf Objekte oder andere sprachspezifische Darstellungen. Das Kopieren einer Python-Liste erzeugt nicht zwangsläufig unabhängige Kopien aller darin enthaltenen Objekte. Außerdem haben Operationen festgelegte Fehlerfälle und keinen menschlichen Interpretationsspielraum.

## 4. Wie funktioniert das?

Ein Index bezeichnet eine Position. Python beginnt bei null; bei drei Elementen sind die normalen nichtnegativen Indizes also null, eins und zwei. Das Ersetzen eines Eintrags verändert die bestehende Liste. Das kann auch über einen anderen Namen sichtbar werden, der dieselbe Liste bezeichnet.

`append` fügt ein einzelnes Element am Ende an. `pop` entfernt ein Element an einer Position und liefert es zurück; ohne Positionsangabe wird das letzte verwendet. `remove` arbeitet dagegen nach Wert und entfernt die erste passende Stelle. Diese Unterschiede erklärt das [Python-Tutorial zu Listenmethoden](https://docs.python.org/3.13/tutorial/datastructures.html#more-on-lists). Besonders bei doppelten Werten ist Position nicht dasselbe wie Inhalt.

## 5. Wo begegnet mir das unter Linux?

Ein Python-Hilfsprogramm kann eine Folge von Dateinamen, Meldungen oder ausgewählten Einträgen als Liste verarbeiten. Die Reihenfolge kann dabei vom ursprünglichen Eingabetext oder von einer ausdrücklichen Sortierung stammen. Eine Liste sortiert sich nicht allein, weil ihre Werte Zahlen sind.

Das Quellbeispiel mit Portnummern ist zunächst nur eine Datensammlung. Das Speichern dieser Zahlen öffnet keinen Port, prüft keine Erreichbarkeit und ändert keine Firewall. Die fachliche Bedeutung entsteht erst durch die weitere Verarbeitung im betreffenden Programm.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verändert ausschließlich eine selbst angelegte Liste:

```python
ports = [80, 443, 53]
assert ports[0] == 80
ports.append(80)
assert ports == [80, 443, 53, 80]
entfernt = ports.pop()
assert entfernt == 80
assert ports == [80, 443, 53]
ports[1] = 8443
assert ports == [80, 8443, 53]
print(ports)
```

Die Ausgabe lautet:

```text
[80, 8443, 53]
```

Zuerst wird der erste Wert über Index null gelesen. Das Anhängen erzeugt einen erlaubten doppelten Eintrag. `pop` entfernt ihn anschließend wieder. Zum Schluss wird der zweite Eintrag ersetzt. Die Zusicherungen prüfen jeden Zwischenstand, statt nur die letzte Ausgabe zu betrachten.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Array kann andere Typ- und Größenregeln besitzen. Eine Menge dient der Sammlung eindeutiger Elemente und nicht derselben Art von Positionsverwaltung. Ein String ist ebenfalls eine Folge, aber in Python unveränderlich und auf Text spezialisiert. Eine Listenvariable ist der Name einer Bindung, nicht die gesamte Datenstruktur selbst.

## 8. Häufige Missverständnisse

Geordnet bedeutet nicht aufsteigend sortiert. `b = a` erstellt bei Python-Listen keine unabhängige Kopie. Auch ersetzt `remove` nicht automatisch alle gleichen Werte. Manche verändernden Methoden liefern `None` statt einer neuen Liste; ihr Ergebnis sollte nicht ungeprüft wieder an den Listennamen gebunden werden.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe leere Listen und gültige Indexgrenzen. Sei vorsichtig, wenn mehrere Programmteile dieselbe Liste bearbeiten. Ein Entfernen aus dieser Lernliste löscht keine Datei und verändert kein Netzwerk. Für echte Datenoperationen müssen die Wirkungen der jeweiligen nachfolgenden Funktionen gesondert beurteilt werden.

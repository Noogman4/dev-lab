# Docstring Python

## 1. Kurzbeschreibung

Ein Docstring ist eine Zeichenkette, die ein Python-Modul, eine Klasse, eine Funktion oder eine Methode dokumentiert. An der vorgesehenen Stelle kann Python sie als Dokumentation des Objekts zugänglich machen.

## 2. Was bedeutet der Begriff?

Die [Docstring-Konventionen in PEP 257](https://peps.python.org/pep-0257/) beschreiben die erste Anweisung im betreffenden Block als Ort für einen Docstring. Üblich sind dreifache doppelte Anführungszeichen, auch bei einer kurzen Zeile. Der Text ist über `__doc__` verfügbar, sofern er zur Laufzeit vorhanden ist.

## 3. Einfacher Vergleich aus dem Alltag

Ein Bedienhinweis direkt am Griff erklärt, wofür ein Hebel gedacht ist. Ein Docstring sitzt ähnlich nah an der Funktion. Er sollte Zweck und Bedingungen nennen. Bei Python können Werkzeuge den Text zusätzlich auslesen und zusammen mit der Schnittstelle darstellen.

## 4. Wie funktioniert das?

Beim Anlegen der Funktion ordnet Python die Zeichenkette dem Funktionsobjekt zu. [inspect.getdoc](https://docs.python.org/3.13/library/inspect.html) liest Dokumentation aus und bereinigt dabei die Einrückung. Je nach Objekt kann es außerdem Dokumentation aus einer übergeordneten Definition ermitteln.

Ein kurzer Docstring kann die Aufgabe zusammenfassen. Wenn Parameter, Rückgabewerte oder typische Fehler erklärungsbedürftig sind, helfen weitere Zeilen und klare Begriffe. Eine Typannotation liefert zusätzliche Typinformationen. Die Beschreibung muss trotzdem erklären, was ein Wert bedeutet.

## 5. Wo begegnet mir das unter Linux?

Unter Linux begegnen dir Docstrings etwa in der interaktiven Python-Hilfe, in Editoren und in aus Quellcode erzeugten Referenzseiten. Für Python-Programme gilt derselbe Mechanismus unabhängig vom Betriebssystem.

## 6. Konkretes Beispiel Schritt für Schritt

Das Beispiel definiert eine Funktion mit einem einzeiligen Docstring. Es prüft zuerst die Rückgabe und liest danach den Text aus.

```python
import inspect

def doppelt(zahl):
    """Verdoppelt eine Zahl."""
    return zahl * 2

assert doppelt(4) == 8
text = inspect.getdoc(doppelt)
assert text == "Verdoppelt eine Zahl."
print(text)
```

Die Ausgabe lautet `Verdoppelt eine Zahl.`. Der Testwert 4 bestätigt nur den gezeigten Aufruf.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Kommentar mit `#` kann eine lokale Implementierungsentscheidung erklären. Ein Docstring beschreibt die Verwendung eines Objekts und lässt sich häufig auslesen. Eine README hilft beim projektweiten Einstieg.

## 8. Häufige Missverständnisse

Der Text prüft seine eigenen Aussagen nicht. Eine veraltete Beschreibung kann korrekt angezeigt werden und das aktuelle Verhalten falsch beschreiben. Optimierte Python-Ausführung mit `-OO` kann Docstrings entfernen.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Dokumentiere die Tücken, die ein Funktionsname allein nicht erkennen lässt. Halte Einheiten, Randbedingungen und Seiteneffekte fest, wenn sie für Aufrufer wichtig sind. Aktualisiere die Beschreibung zusammen mit der Schnittstelle.

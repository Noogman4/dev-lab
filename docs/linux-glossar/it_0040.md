# Dictionary

## 1. Kurzbeschreibung

Ein Dictionary ist eine Zuordnung von Schlüsseln zu Werten. Anstatt nur eine Position zu kennen, kannst du einen Wert über seinen Schlüssel nachschlagen. In Python heißt der eingebaute Typ `dict`. Das Quellbeispiel `{'dns': '1.1.1.1'}` ordnet dem Textschlüssel `dns` einen Textwert zu. Diese Datenstruktur verändert noch keine DNS-Einstellung.

## 2. Was bedeutet der Begriff?

Ein Schlüssel identifiziert innerhalb eines Dictionarys einen Eintrag. Ein Wert kann die dazugehörige Information enthalten, etwa eine Beschreibung oder eine Einstellung. Derselbe Schlüssel besitzt nicht gleichzeitig mehrere unabhängige Einträge: Eine neue Zuweisung unter einem bereits vorhandenen Schlüssel ersetzt dessen bisherigen Wert.

Python verlangt hashbare Schlüssel. Vereinfacht müssen sie für die interne Zuordnung einen stabilen Hashwert und passende Gleichheitsregeln besitzen. Gewöhnliche Strings eignen sich; Listen nicht. Die [Referenz zum Mapping-Typ dict](https://docs.python.org/3.13/library/stdtypes.html#mapping-types-dict) beschreibt diese Anforderungen. Die Werte müssen dagegen nicht selbst hashbar sein und können beispielsweise Listen enthalten.

## 3. Einfacher Vergleich aus dem Alltag

Ein beschriftetes Karteiregister ermöglicht das Nachschlagen über eine Kennung. Wenn eine Karte zur Kennung aktualisiert wird, soll die nächste Suche den aktuellen Inhalt liefern. Die Kennung ist nicht bloß die zufällige laufende Position im Stapel.

Die Grenze des Vergleichs: Ein Python-Dictionary kann andere Schlüsseltypen als Text und beliebige Objektwerte verwenden. Außerdem besitzt es genaue Regeln für Gleichheit und fehlende Einträge. Zwei im Alltag ähnlich bezeichnete Kennungen müssen technisch nicht denselben Schlüssel darstellen, und umgekehrt können gleich vergleichende Werte dieselbe Zuordnung ansprechen.

## 4. Wie funktioniert das?

Mit `daten[schluessel]` liest du den zugehörigen Wert. Fehlt der Schlüssel, entsteht `KeyError`. Mit `get` kannst du stattdessen einen vorgesehenen Standardwert erhalten. Die [Python-Einführung zu Dictionaries](https://docs.python.org/3.13/tutorial/datastructures.html#dictionaries) erläutert beide Varianten sowie das Ersetzen vorhandener Werte.

Seit Python 3.7 ist die Einfügereihenfolge für `dict` als Sprachverhalten garantiert. Das macht ein Dictionary dennoch nicht zu einer nummerisch adressierten Liste und sortiert seine Schlüssel nicht automatisch. Ein Schlüssel mit dem Wert `False` ist außerdem nicht dasselbe wie ein fehlender Schlüssel. Vorhandensein und Inhalt beantworten verschiedene Fragen.

## 5. Wo begegnet mir das unter Linux?

Ein Python-Werkzeug kann eingelesene Einstellungen oder einen strukturierten Bericht als Dictionary verarbeiten. Ein Feldname beschreibt dann die Rolle des zugeordneten Werts. Daten aus externen Quellen müssen trotzdem auf erwartete Felder, Typen und Inhalte geprüft werden.

Eine im Speicher gespeicherte Zuordnung ist noch keine geschriebene Konfigurationsdatei. Ein Textwert mit einer Serveradresse löst ebenfalls keine Verbindung aus. Erst weitere Verarbeitung entscheidet, ob solche Angaben tatsächlich verwendet, gespeichert oder an andere Programme übergeben werden.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verwendet nur eine eigene Zuordnung; keine Adresse wird kontaktiert:

```python
daten = {"dns": "1.1.1.1"}
daten["dns"] = "9.9.9.9"
assert len(daten) == 1
daten["aktiv"] = False
assert "aktiv" in daten
assert daten["aktiv"] is False
assert "fehlend" not in daten
assert daten.get("fehlend") is None
assert list(daten) == ["dns", "aktiv"]
print(daten["dns"])
print(len(daten))
print(daten["aktiv"])
```

Die Ausgabe lautet:

```text
9.9.9.9
2
False
```

Die neue DNS-Angabe ersetzt einen Wert, statt einen zweiten gleichen Schlüssel anzulegen. `aktiv` ist ausdrücklich vorhanden, obwohl sein Wert falsch ist. Das fehlende Feld wird gesondert geprüft. Die Reihenfolgeprüfung gilt für die genannte Python-Version; eine automatisch alphabetische Sortierung wird nicht behauptet.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine Liste verwendet Positionszugriffe. Ein Dictionary verwendet Schlüssel. Eine Menge speichert eindeutige Elemente ohne zugeordnete Nutzwerte derselben Art. JSON ist ein Datenformat; ein Python-Dictionary ist ein Objekt im Programm. Nicht jede beliebige Dictionary-Schlüsselstruktur lässt sich unverändert als JSON-Objekt übertragen.

## 8. Häufige Missverständnisse

Ein Schlüssel darf nicht beliebig oft unabhängig vorkommen. Ein vorhandener Wert `None` ist nicht automatisch ein fehlender Eintrag. Leere geschweifte Klammern erzeugen in Python ein Dictionary, nicht eine leere Menge. Eine erhaltene Einfügereihenfolge bedeutet außerdem keine sortierte Reihenfolge.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Lege erforderliche und optionale Felder fest. Unterscheide Nachschlagefehler von einem ausdrücklich gespeicherten Sonderwert. Behandle eingelesene Adressen oder Pfade zunächst als Daten. Das Beispiel ändert nur sein eigenes Dictionary; vorhandene Dateien, Resolver und Netzwerkeinstellungen bleiben unberührt.

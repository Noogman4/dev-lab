# Klasse

## 1. Kurzbeschreibung

Eine Klasse beschreibt eine Art von Objekten mit vorgesehenen Eigenschaften und Verhaltensweisen. Sie kann zum Erzeugen konkreter Instanzen verwendet werden. Die Quelle nennt sie eine Vorlage; dieses Bild ist als Einstieg hilfreich. In Python ist die Klasse selbst allerdings ebenfalls ein Objekt und kein bloßes unveränderliches Zeichnungsblatt.

## 2. Was bedeutet der Begriff?

Eine Klasse bündelt zusammengehörende Regeln. Eine Klasse für eine Fensterbeschreibung könnte einen Titel speichern und passende Operationen anbieten. Die einzelnen Beschreibungen tragen ihre eigenen Daten, obwohl sie dieselbe Art von Objekt besitzen.

Die Anweisung `class Window:` aus der Quelle ist nur der Beginn einer Python-Klassendefinition. Ein Körper muss folgen. Die [offizielle Beschreibung der Klassendefinition](https://docs.python.org/3.13/tutorial/classes.html#class-definition-syntax) erklärt den dabei erzeugten Namensraum und das anschließende Klassenobjekt. Eine Klassendefinition muss ausgeführt werden, bevor der so gebundene Name verwendet werden kann.

## 3. Einfacher Vergleich aus dem Alltag

Ein Formular beschreibt, welche Angaben mehrere einzelne Datensätze besitzen sollen. Verschiedene ausgefüllte Exemplare können unterschiedliche Namen tragen und trotzdem demselben Aufbau folgen.

Die Grenze des Vergleichs: Eine Klasse kann auch Verhalten und technische Regeln bereitstellen. Python erlaubt zudem Veränderungen bestimmter Klassenattribute und bietet weitere dynamische Möglichkeiten. Das einfache Bild einer Vorlage erklärt weder sämtliche Typregeln noch automatisch, welche Daten zwischen Instanzen gemeinsam verwendet werden.

## 4. Wie funktioniert das?

Beim Ausführen der Klassendefinition entsteht ein Klassenobjekt. Der gewöhnliche Aufruf dieses Objekts erzeugt eine passende Instanz. Attribute sind über Namen zugängliche Eigenschaften. Methoden stellen aufrufbares Verhalten bereit. Die [Python-Einführung zu Klassenobjekten](https://docs.python.org/3.13/tutorial/classes.html#class-objects) beschreibt Attributzugriffe und Instanziierung.

`__init__` initialisiert eine neu erzeugte Instanz. Es ist nicht allgemein mit der eigentlichen Speichererzeugung gleichzusetzen. Im üblichen Beispiel erhält sein erster Parameter `self` die betreffende Instanz. Zuweisungen wie `self.titel = titel` speichern dann ein Attribut an diesem Objekt.

Klassenattribute und Instanzattribute sind zu unterscheiden. Besonders veränderliche Daten, die an der Klasse statt an einzelnen Instanzen liegen, können unerwartet gemeinsam verwendet werden. Die richtige Ablage folgt aus der beabsichtigten Zuständigkeit.

## 5. Wo begegnet mir das unter Linux?

Python-Anwendungen können mit Klassen Fensterzustände, Einstellungen oder Arbeitsergebnisse strukturieren. Bibliotheken stellen eigene Klassen bereit, die eine Anwendung verwenden kann. Das bedeutet nicht, dass jede Klasse eine sichtbare Oberfläche oder ein Betriebssystemobjekt erzeugt.

Ein Name wie `Window` beschreibt nur die gewählte Schnittstelle. Eine echte grafische Fensterklasse würde zusätzliche Bibliotheken und einen passenden Anzeigezugang benötigen. Das folgende Lernmodell verwaltet dagegen ausschließlich Textdaten.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel ergänzt den Definitionsanfang um eine reine Datenklasse:

```python
class Window:
    def __init__(self, titel):
        self.titel = titel

links = Window("Links")
rechts = Window("Rechts")
assert isinstance(links, Window)
assert type(links) is type(rechts)
assert links is not rechts
links.titel = "Neu"
assert rechts.titel == "Rechts"
print(links.titel)
print(rechts.titel)
```

Die Ausgabe lautet:

```text
Neu
Rechts
```

Die Definition erzeugt die Klasse. Zwei Aufrufe erzeugen zwei unterschiedliche Instanzen. Die Titeländerung am linken Objekt verändert den rechten Titel nicht. Geprüft wird genau diese Datenstruktur, nicht das Verhalten einer grafischen Fensterbibliothek.

## 7. Abgrenzung zu ähnlichen Begriffen

Die Klasse beschreibt die Art und stellt Regeln bereit. Eine Instanz ist ein konkretes Objekt dieser Klasse. Ein Attribut trägt Daten oder verweist auf einen Bestandteil. Eine Methode beschreibt zugehöriges Verhalten. Eine Funktion benötigt nicht zwingend eine eigene Klasse, um wiederverwendbar zu sein.

## 8. Häufige Missverständnisse

Eine Klassendefinition erzeugt nicht automatisch alle später benötigten Instanzen. `__init__` ist nicht die allgemeine Definition von Objekterzeugung. Auch besitzen nicht alle Programmiersprachen dasselbe Klassenmodell. Eine gemeinsame Klasse bedeutet zudem nicht, dass sämtliche Instanzdaten gemeinsam gespeichert werden sollten.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Lege Verantwortlichkeiten und gemeinsame Daten bewusst fest. Verwende Klassen, wenn sie die Struktur verständlicher machen. Das Beispiel erstellt ausschließlich eigene Python-Objekte; es startet keine GUI und verändert keine Dateien oder Systemeinstellungen.

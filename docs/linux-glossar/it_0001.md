# Algorithmus

## 1. Kurzbeschreibung

Ein Algorithmus ist ein genau beschriebenes Verfahren zur Lösung einer Aufgabe. Er legt fest, welche Schritte mit welchen Eingaben auszuführen sind und welches Ergebnis entstehen soll. Ein Sortierverfahren kann beispielsweise eine Liste von Zahlen aufsteigend ordnen. Ein Algorithmus lässt sich zunächst in Worten beschreiben; Programmcode ist eine mögliche Umsetzung.

## 2. Was bedeutet der Begriff?

Die Beschreibung muss so eindeutig sein, dass sich ihre Schritte ohne Raten ausführen lassen. „Finde die größte Zahl“ nennt nur das Ziel. „Merke die erste Zahl, vergleiche jede weitere damit und ersetze den gemerkten Wert nur bei einer größeren Zahl“ beschreibt ein Verfahren.

Dabei gehören Voraussetzungen zur Erklärung: Gibt es überhaupt Zahlen? Sind sie miteinander vergleichbar? Soll ein leeres Ergebnis erlaubt sein? Für die hier betrachtete Berechnung soll das Verfahren bei gültigen, endlichen Eingaben nach endlich vielen Schritten enden. Ein dauerhaft laufender Überwachungsdienst ist dagegen nicht insgesamt eine solche abgeschlossene Berechnung, kann aber einzelne Algorithmen wiederholt einsetzen.

## 3. Einfacher Vergleich aus dem Alltag

Beim Sortieren von Spielkarten kannst du jede neue Karte an die passende Stelle in einer bereits geordneten Reihe stecken. Wiederholst du das für alle Karten, entsteht eine sortierte Reihe.

Der Vergleich zeigt kleine, wiederholbare Schritte und einen Endzustand. Er hat Grenzen: Ein Mensch erkennt Zahlen und Farben beiläufig. Ein Programm braucht dafür festgelegte Darstellungen und Vergleichsregeln. Außerdem bedeutet „passend“ ohne eine vereinbarte Reihenfolge noch keine eindeutige Anweisung.

## 4. Wie funktioniert das?

Typische Bausteine sind eine feste Reihenfolge, Entscheidungen und Wiederholungen. Eine Entscheidung wählt abhängig von einer Bedingung den nächsten Schritt. Eine Wiederholung führt Schritte mehrfach aus. Pythons `for` durchläuft beispielsweise die Elemente einer Folge in ihrer Reihenfolge; das erklärt das [offizielle Tutorial zu Schleifen](https://docs.python.org/3.13/tutorial/controlflow.html#for-statements).

Zum Verfahren gehören auch seine Kosten: Wie viele Vergleiche fallen an, wie viel zusätzlicher Speicher wird benötigt? Bei unserem Maximum-Beispiel wird jede weitere Zahl einmal geprüft. Für große Listen kann die Wahl des Verfahrens deshalb spürbare Auswirkungen haben. Ein kürzer geschriebenes Programm ist nicht automatisch schneller.

## 5. Wo begegnet mir das unter Linux?

Dateisuchen, Paketverwaltungen und Netzwerkprogramme verwenden Algorithmen zum Vergleichen, Auswählen oder Verarbeiten von Daten. Wenn ein Werkzeug eine Prozessliste nach Speicherbedarf anzeigt, braucht es eine definierte Sortierreihenfolge.

Du musst dafür nicht jeden Sortierschritt selbst programmieren. Python bietet `sorted()` und Sortierschlüssel an: Eine Funktion bestimmt dabei den Vergleichswert jedes Eintrags, etwa dessen Größe. Das [Sorting HOWTO](https://docs.python.org/3.13/howto/sorting.html#key-functions) beschreibt diese Schnittstelle. Die Schnittstelle verwenden und den intern gewählten Algorithmus kennen sind unterschiedliche Wissensebenen.

## 6. Konkretes Beispiel Schritt für Schritt

Das folgende vollständige Python-3-Beispiel verwendet ausschließlich selbst gewählte Zahlen. Führe es als Python-Code aus, nicht als Shell-Befehle.

```python
zahlen = [7, 2, 9, 4]
groesste = zahlen[0]
for zahl in zahlen[1:]:
    if zahl > groesste:
        groesste = zahl
assert groesste == 9
assert zahlen == [7, 2, 9, 4]
print(groesste)
```

Die Ausgabe lautet:

```text
9
```

Zuerst wird `7` zum Vergleichswert. `2` verändert ihn nicht. Bei `9` wird er ersetzt; `4` ist anschließend kleiner. Die ursprüngliche Liste bleibt erhalten. Die Zusicherungen mit `assert` prüfen beides. Für eine leere Liste wäre bereits der Zugriff auf das erste Element ungültig; ein allgemeines Werkzeug müsste diesen Fall ausdrücklich behandeln.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Programm enthält neben Verfahren auch Eingabe-, Ausgabe- und Fehlerbehandlung. Ein Algorithmus beschreibt den Lösungsweg unabhängig von einem bestimmten Dateinamen oder einer grafischen Oberfläche. Eine einzelne Anweisung ist nur ein möglicher Schritt darin.

## 8. Häufige Missverständnisse

Ein Algorithmus ist weder zwangsläufig kompliziert noch automatisch richtig. Selbst eindeutig beschriebene Schritte können das falsche Ziel verfolgen. Ein korrektes Ergebnis bei einer Liste beweist außerdem nicht, dass alle erlaubten Eingaben richtig behandelt werden.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe Normalfälle, Grenzfälle und Voraussetzungen getrennt. Für dieses Beispiel sind insbesondere eine einzige Zahl, gleiche Werte und negative Zahlen interessant. Das gezeigte Skript liest oder verändert keine Dateien. Überträgst du Verfahren auf echte Daten, müssen Auswirkungen wie Überschreiben oder Löschen zusätzlich beurteilt werden.

## 10. Verwandte Begriffe

[Anweisung](it_0002.md) bezeichnet einen ausführbaren Programmschritt. Ein [Ausdruck](it_0003.md) liefert etwa das Ergebnis des Größenvergleichs. Eine [Variable](it_0004.md) hält im Beispiel den jeweils gemerkten größten Wert fest.

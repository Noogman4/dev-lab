# Attribut

## 1. Kurzbeschreibung

Ein Attribut ist ein über einen Namen zugänglicher Bestandteil eines Objekts oder einer Klasse. Es kann Daten, eine Methode oder einen berechneten Zugriff darstellen. Die Quellbeschreibung „Eigenschaft“ ist als Einstieg passend. Aus einer Schreibweise wie `window.title` lässt sich jedoch nicht allein ableiten, welcher Wert oder welches Verhalten tatsächlich dahintersteht.

## 2. Was bedeutet der Begriff?

In Python bezeichnet der Punkt einen Attributzugriff: Zuerst wird das Objekt links bestimmt, dann der Name rechts nach den Regeln dieses Objekts aufgelöst. Der Attributname muss nicht eine frei beschreibbare einfache Speicherzelle bezeichnen.

Die [Einführung zu Instanzobjekten](https://docs.python.org/3.13/tutorial/classes.html#instance-objects) unterscheidet Datenattribute und Methoden. Auch Klassen können Attribute bereitstellen. Wenn eine Instanz einen Namen verwendet, ist deshalb zu prüfen, ob ihr eigener Zustand oder eine über die Klasse bereitgestellte Eigenschaft angesprochen wird.

## 3. Einfacher Vergleich aus dem Alltag

Ein beschriftetes Datenblatt kann Felder wie „Titel“ und „Anzahl“ besitzen. Über die Beschriftung findest du die zugehörige Angabe. Bei mehreren Datenblättern können dieselben Feldnamen unterschiedliche Werte besitzen.

Die Grenze des Vergleichs: Manche technische Eigenschaft wird erst beim Zugriff berechnet, statt als fertiger Wert im Feld zu liegen. Eine Methode ist sogar aufrufbares Verhalten. Außerdem kann ein Zugriff Fehler auslösen oder nur lesend erlaubt sein. Das einfache Formularbild erklärt diese Möglichkeiten nicht vollständig.

## 4. Wie funktioniert das?

Gewöhnliche eigene Python-Objekte können Datenattribute etwa durch `self.titel = wert` erhalten. Eine spätere Zuweisung kann den gespeicherten Zustand ändern. Welche Attributnamen zulässig sind und ob sie verändert werden dürfen, hängt vom Typ und seiner Implementierung ab.

Mit `property` kann eine Klasse einen Attributzugriff über Funktionen vermitteln. Ein Getter berechnet oder liest den Wert; ein optionaler Setter regelt eine Zuweisung. Die [offizielle property-Referenz](https://docs.python.org/3.13/library/functions.html#property) erläutert auch eine nur lesbare Eigenschaft. Gleich aussehende Zugriffe können daher unterschiedliche interne Arbeit ausführen.

Eine solche Schnittstelle ist kein allgemeiner Sicherheitsmechanismus. Sie strukturiert Zugriffe im vorgesehenen Programmablauf. Ob weitere interne oder dynamische Zugriffsmöglichkeiten bestehen, ist eine andere Frage.

## 5. Wo begegnet mir das unter Linux?

Python-Anwendungen verwenden Attribute für Zustandsdaten, Ergebnisobjekte und Bibliothekszugriffe. Eine Bibliothek könnte `title` als Text, als Methode oder als vermittelte Eigenschaft bereitstellen. Für eine echte Fensterklasse muss deshalb deren Dokumentation gelesen werden.

Bei einer Fehlersuche kann ein unerwarteter Attributwert auf eine falsche Instanz, einen überschriebenen Namen oder einen unpassenden Zustand hinweisen. Ein Attributzugriff sollte nicht ungeprüft als nebenwirkungsfreies reines Nachschlagen behandelt werden, wenn ein fremder Typ dahintersteht.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verwendet eine reine Datenklasse ohne GUI:

```python
class Window:
    def __init__(self, title):
        self.title = title

    @property
    def titel_laenge(self):
        return len(self.title)

window = Window("NetMon")
assert window.titel_laenge == 6
print(window.title, window.titel_laenge)
window.title = "Test"
assert window.titel_laenge == 4
print(window.title, window.titel_laenge)
```

Die Ausgabe lautet:

```text
NetMon 6
Test 4
```

`title` trägt im eigenen Modell einen Text. `titel_laenge` wird dagegen beim Zugriff berechnet. Nach der Textänderung liefert dieselbe Eigenschaft die neue Länge, ohne dass eine gesonderte Längenvariable aktualisiert werden muss. Das Beispiel prüft diesen Getter, nicht das Verhalten irgendeiner realen Fensterbibliothek.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine Variable ist eine benannte Bindung in einem Namensraum. Ein Attribut wird über ein Objekt angesprochen. Eine Methode ist eine mögliche Art zugänglichen Verhaltens. Ein Dictionary-Schlüssel besitzt wiederum eine andere Nachschlageschnittstelle; `daten["titel"]` ist nicht automatisch gleichbedeutend mit `daten.titel`.

## 8. Häufige Missverständnisse

Ein Attribut muss nicht einfach gespeicherter Text sein. Ein Name mit Punkt ist nicht automatisch eine aufgerufene Methode. Nicht jedes Objekt erlaubt beliebige neue Attribute. Eine nur lesbare Property garantiert außerdem nicht, dass der gesamte erreichbare Objektzustand unveränderlich ist.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Lies bei fremden Typen, ob ein Zugriff berechnet, verändert oder fehlschlagen kann. Vermeide die unbeabsichtigte Überschreibung wichtiger Methodennamen. Das Beispiel verändert nur einen eigenen Textzustand und erzeugt weder Fenster noch Datei- oder Netzwerkzugriffe.

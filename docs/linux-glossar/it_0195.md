# Zeile

## 1. Kurzbeschreibung

Eine Zeile einer Datenbanktabelle enthält die zusammengehörigen Werte eines Eintrags. Sie besitzt Werte zu den vorgesehenen Spalten. Der Ausdruck bezeichnet hier eine logische Datenstruktur, keine einzelne sichtbare Textzeile auf dem Bildschirm. Eine Zeile muss außerdem nicht durch ihren Platz in einer Ausgabe dauerhaft identifiziert sein.

## 2. Was bedeutet der Begriff?

Im Katalogbeispiel kann ein Radiosender als Zeile einer passenden Tabelle beschrieben werden. Seine Kennung, Bezeichnung und weitere Angaben gehören dann zu einem gemeinsamen Datensatz. Welche Eigenschaften dazu nötig sind, bestimmt das Datenmodell.

Die [PostgreSQL-Grundlagen zu Tabellen](https://www.postgresql.org/docs/current/ddl-basics.html) erläutern die Verbindung von Zeilen und benannten Spalten. Sie weisen auch auf mögliche gleiche Zeilen und fehlende garantierte Reihenfolge hin. Deshalb ist „die dritte Zeile“ ohne klaren Kontext keine geeignete dauerhafte Kennung eines Fachobjekts.

## 3. Einfacher Vergleich aus dem Alltag

Eine ausgefüllte Karte enthält mehrere Rubriken zu einem Vorgang. Der Text einer Rubrik kann über mehrere gedruckte Zeilen gehen, ohne dass daraus mehrere Karten werden. Die zusammengehörige Einheit bleibt der Vorgangseintrag.

Die Grenze: Datenbankzeilen werden nicht durch Blattkanten oder sichtbare Zeilenumbrüche getrennt. Ihre Struktur wird technisch bestimmt. Auch ein angezeigter Datensatz kann aus einer Abfrage stammen und mehrere gespeicherte Einträge zusammenführen. Bildschirmdarstellung und Speicherstruktur sind daher auseinanderzuhalten.

## 4. Wie funktioniert das?

Eine Auswahl ermittelt Zeilen nach den angegebenen Bedingungen und liefert die gewünschten Werte. Das Ergebnis kann keine, eine oder viele Zeilen enthalten. Die [SQLite-Referenz zu SELECT](https://www.sqlite.org/lang_select.html) beschreibt Auswahl, Ergebnisbildung und Sortierung.

Die Zahl der gelieferten Zeilen hängt dabei von der Anfrage ab, nicht nur von der Gesamtgröße der Tabelle. Eine Spaltenauswahl verändert die Form jedes Ergebniseintrags, während eine Bedingung bestimmte Einträge ausschließen kann. Mehrere gleich aussehende Werte können weiterhin zu verschiedenen Datensätzen gehören.

Ein fehlender Wert ist ebenfalls von einer fehlenden Zeile zu unterscheiden. Ein Eintrag kann vorhanden sein und in einer dafür erlaubten Spalte `NULL` enthalten. Daraus folgt nicht automatisch, dass die Auswahl überhaupt keinen Datensatz gefunden hat.

## 5. Wo begegnet mir das unter Linux?

Programme lesen Zeilen über Datenbankbibliotheken und stellen sie möglicherweise als Tupel oder andere Objekte dar. Eine Oberfläche kann daraus eine Tabelle oder eine Detailansicht bauen. Diese Form ist eine Darstellung des Ergebnisses, keine direkte Aussage über die physische Speicheranordnung.

Bei einer Fehlersuche ist wichtig, ob eine Anfrage keinen Eintrag findet oder ein vorhandener Eintrag einen unerwarteten Wert besitzt. Beide Fälle benötigen unterschiedliche Behandlung. Eine leere Anzeige darf deshalb nicht ohne Prüfung als leere Datenbank interpretiert werden.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Beispiel wurde mit Python 3.13 in einem temporären Arbeitsordner ausgeführt. Es verwendet nur eine neue In-Memory-Tabelle und selbst gewählte Texte.

```python
from contextlib import closing
import sqlite3

with closing(sqlite3.connect(":memory:")) as db:
    db.execute("CREATE TABLE notizen (id INTEGER PRIMARY KEY, text TEXT)")
    db.executemany(
        "INSERT INTO notizen VALUES (?, ?)",
        [(1, "Probe\nZweite Textzeile"), (2, None)],
    )
    zeilen = db.execute("SELECT id, text FROM notizen WHERE id = ?", (1,)).fetchall()
    assert zeilen == [(1, "Probe\nZweite Textzeile")]
    assert len(zeilen) == 1
    assert zeilen[0][1].count("\n") == 1
    assert db.execute("SELECT text FROM notizen WHERE id = 2").fetchone() == (None,)
    assert db.execute("SELECT text FROM notizen WHERE id = 3").fetchone() is None
    print("Ausgewählte Datensätze:", len(zeilen))
    print("Zeilenumbrüche im Text:", zeilen[0][1].count("\n"))
```

Geprüfte Ausgabe:

```text
Ausgewählte Datensätze: 1
Zeilenumbrüche im Text: 1
```

Der erste Eintrag bleibt eine Zeile, obwohl sein Text einen Zeilenumbruch enthält. Beim zweiten Eintrag steht ein fehlender Wert als Python-`None` im Ergebnis. Der dritte ist nicht vorhanden; die Auswahl liefert deshalb keine Zeile. Diese Fälle sind bewusst getrennt geprüft. Keine echte Notiz oder Senderinformation wird verarbeitet.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine Spalte beschreibt eine benannte Eigenschaft. Eine Zeile verbindet deren Werte für einen Eintrag. Eine Textzeile ist dagegen durch eine Textdarstellung bestimmt. Ein Python-Tupel kann eine Ergebniszeile darstellen, ist aber nicht selbst das gesamte Datenbanksystem oder dessen dauerhaft gespeicherte Identität.

## 8. Häufige Missverständnisse

Ein Zeilenumbruch erzeugt nicht automatisch einen neuen Datenbankeintrag. Eine leere Spalte ist nicht gleichbedeutend mit einer fehlenden Zeile. Die beobachtete Ausgabeposition kann sich außerdem ändern. Eine Datenbank muss schließlich nicht automatisch gleiche Anzeigenamen als denselben Eintrag behandeln.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Unterscheide keine Treffer, fehlende Werte und tatsächliche Datenfehler. Verwende ausdrücklich passende Bedingungen und Identifikationsregeln. Dieses Beispiel verändert nur eigene Speicherdaten und greift weder auf Anwendungsdateien noch auf Dienste oder Konten zu.

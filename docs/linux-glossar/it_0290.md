# Manpage

## 1. Kurzbeschreibung

Eine Manpage ist eine Handbuchseite für ein Unix- oder Linux-Thema. Sie kann einen Befehl, ein Dateiformat, eine Bibliotheksfunktion oder eine Schnittstelle beschreiben. Das Programm `man` sucht die passende Seite und stellt sie in einem Lesewerkzeug dar.

## 2. Was bedeutet der Begriff?

Die [Handbuchseite zu man](https://man7.org/linux/man-pages/man1/man.1.html) erklärt den Aufruf und die nummerierten Bereiche. Abschnitt 1 enthält üblicherweise Benutzerbefehle, Abschnitt 5 Dateiformate und Konventionen. Derselbe Name kann in mehreren Bereichen vorkommen, zum Beispiel als Kommando und als Konfigurationsdatei.

## 3. Einfacher Vergleich aus dem Alltag

Ein Regal mit beschrifteten Handbüchern hilft, die passende Anleitung zu finden. Der Abschnitt ist eine zusätzliche Beschriftung. Hat ein Buch mehrere Ausgaben, spielt die Ausgabe eine Rolle. Ebenso kann eine Online-Manpage eine andere Programmversion beschreiben als die lokal installierte Seite.

## 4. Wie funktioniert das?

Viele Manpages haben Abschnitte wie NAME, SYNOPSIS, DESCRIPTION und OPTIONS. Die Synopsis zeigt die Aufrufform. Eckige Klammern markieren in solchen Darstellungen häufig optionale Bestandteile. Klammern gehören daher normalerweise nicht wörtlich in den Aufruf.

Mit einem Abschnitt kannst du eine mehrdeutige Suche eingrenzen. Eine Seitendarstellung wie `systemctl(1)` nennt Thema und Abschnitt. Die [systemd-Referenz zu systemctl](https://www.freedesktop.org/software/systemd/man/latest/systemctl.html) ist das Online-Gegenstück zur entsprechenden Handbuchseite und beschreibt insbesondere die Verwaltung von Diensten und anderen Einheiten.

## 5. Wo begegnet mir das unter Linux?

Unter Linux werden Manpages häufig zusammen mit Programmen oder in separaten Dokumentationspaketen ausgeliefert. In minimalen Umgebungen können lokale Seiten fehlen. Wenn sie vorhanden sind, sind sie besonders nützlich für Fragen zum installierten Stand.

## 6. Konkretes Beispiel Schritt für Schritt

Gedankenbeispiel ohne Dienstaktion.

1. `man systemctl` würde die lokal auffindbare Referenz öffnen, sofern sie installiert ist. Dieser Aufruf dient dem Lesen der Hilfe.
2. In der Synopsis würdest du Unterbefehle und gemeinsame Optionen erkennen.
3. Du würdest die gewünschte Operation in der Beschreibung nachschlagen und auf Hinweise zu System- oder Benutzerinstanz achten.
4. Bei einem Unterschied zur Online-Fassung wäre die Programmversion der nächste Prüfpunkt.

Das Modell führt keinen der beschriebenen Verwaltungsunterbefehle aus.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine Manpage ist vor allem eine Referenz zum Nachschlagen. Ein [Tutorial](it_0289.md) vermittelt eine neue Fertigkeit an einem geführten Beispiel. Eingebaute Kurzhilfe kann zusätzlich eine kompakte Übersicht liefern.

## 8. Häufige Missverständnisse

Das Erscheinen einer Option in einer neueren Online-Referenz beweist ihre Verfügbarkeit im lokalen Programm nicht. Eine lesbare Beispielzeile in einer Manpage ist auch keine Aufforderung, sie unverändert auszuführen.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Lies bei Verwaltungsbefehlen die Wirkung und den Geltungsbereich vollständig. Gib bei einem mehrdeutigen Namen den Abschnitt an, bevor du eine Anleitung auf eine Manpage stützt.

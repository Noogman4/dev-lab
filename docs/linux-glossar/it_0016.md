# Iteration

## 1. Kurzbeschreibung

Eine Iteration ist im Zusammenhang mit einer Schleife ein einzelner Durchlauf. Der Begriff wird außerdem für wiederholtes Anwenden eines Verfahrens verwendet. In der Quelle heißt es, beim Durchlaufen einer Liste sei jedes Element eine Iteration. Genauer ist das Element der verarbeitete Wert; die Iteration ist die Ausführung des zugehörigen Arbeitsschritts.

## 2. Was bedeutet der Begriff?

Bei drei Durchläufen einer Schleife finden drei Iterationen statt, auch wenn zweimal derselbe Zahlenwert verarbeitet wird. Eine Iteration muss also kein neues oder einmaliges Datenelement betreffen. Bei einer bedingungsgesteuerten Schleife kann überhaupt keine vorab vorhandene Liste beteiligt sein.

Die Anzahl der Iterationen und die Anzahl erledigter Aufgaben können sich unterscheiden. Ein Durchlauf kann wegen einer Prüfung keine fachliche Arbeit ausführen. Umgekehrt kann ein Durchlauf mehrere Daten zusammen verarbeiten. Darum sollte ein Protokoll erklären, was sein Zähler tatsächlich zählt.

## 3. Einfacher Vergleich aus dem Alltag

Beim Abgehen eines Stapels Karten ziehst du in jedem Durchgang die nächste Karte und liest sie. Zwei Karten dürfen denselben Text tragen; trotzdem hast du zwei getrennte Durchgänge ausgeführt.

Der Vergleich erfasst einen endlichen Stapel. Eine technische Iteration kann dagegen auf einen veränderten Zwischenstand angewendet werden, ohne eine neue Karte zu entnehmen. Bei solchen Annäherungsverfahren wird wiederholt gerechnet, bis ein festgelegtes Ende oder ein genügend genaues Ergebnis erreicht ist.

## 4. Wie funktioniert das?

Python verwendet beim Durchlaufen vieler Datenquellen einen Iterator: ein Objekt, das nacheinander Werte liefert. Ist die Quelle erschöpft, signalisiert es das Ende. Die `for`-Schleife verarbeitet dieses Signal selbst. Das [offizielle Glossar zu Iteratoren](https://docs.python.org/3.13/glossary.html#term-iterator) beschreibt auch, dass ein bereits erschöpfter Iterator nicht automatisch wieder von vorn beginnt.

Ein Iterator ist deshalb nicht dasselbe wie eine beliebig oft durchlaufbare Sammlung. Eine Liste kann für einen neuen Durchlauf einen neuen Iterator bereitstellen; ein konkreter Iterator besitzt seinen eigenen Fortschrittsstand.

Mit `enumerate` lassen sich Werte und ein mitlaufender Zähler gemeinsam gewinnen. Der Startwert ist standardmäßig null, kann aber ausdrücklich gewählt werden. Die [Funktionsdokumentation zu enumerate](https://docs.python.org/3.13/library/functions.html#enumerate) zeigt diese Zuordnung. Der Zähler ist eine Hilfsinformation, keine Eigenschaft des verarbeiteten Werts.

## 5. Wo begegnet mir das unter Linux?

Ein Skript kann die Zeilen einer kleinen Beispieldatei nacheinander auswerten oder mehrere Suchergebnisse abarbeiten. Ein Fortschrittsfenster könnte anzeigen, wie viele Durchläufe bereits beendet sind. Das wäre nur dann eine verlässliche Prozentangabe, wenn auch die relevante Gesamtarbeit bekannt ist.

Ein Programm kann zudem mehrere komplette Verarbeitungsläufe ausführen. „Iteration“ kann dann je nach Beschreibung den inneren Schleifendurchlauf oder einen größeren Verfahrensschritt meinen. Eine gute Dokumentation nennt die betrachtete Ebene statt lediglich eine Zahl auszugeben.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel zählt drei Durchläufe mit einem bewusst doppelten Wert:

```python
werte = [2, 2, 5]
protokoll = []
for nummer, wert in enumerate(werte, start=1):
    protokoll.append((nummer, wert))
assert protokoll == [(1, 2), (2, 2), (3, 5)]
assert len(protokoll) == 3
assert len(set(werte)) == 2
for nummer, wert in protokoll:
    print(nummer, wert)
```

Die Ausgabe lautet:

```text
1 2
2 2
3 5
```

Die ersten beiden Durchläufe verarbeiten denselben Zahlenwert, sind aber unterschiedliche Iterationen. `set` wird nur zur Kontrolle der Anzahl verschiedener Werte verwendet. Drei Durchläufe und zwei verschiedene Werte sind hier beide richtige Angaben zu unterschiedlichen Fragen.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine Schleife beschreibt den gesamten wiederholten Ablauf. Eine Iteration bezeichnet einen Durchlauf. Ein Iterator liefert Werte für einen solchen Ablauf. Ein Index ist eine Position in einer Datenstruktur; ein frei gewählter Durchlaufzähler muss nicht dieselbe Nummer haben.

## 8. Häufige Missverständnisse

Eine Iteration ist nicht das Element selbst. Ein Zähler ab eins ändert auch nicht die nullbasierten Listenindizes in Python. Eine bereits verbrauchte Datenquelle lässt sich nicht allein durch eine weitere Schleife zuverlässig zurücksetzen.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Beschrifte Fortschrittszähler verständlich. Lege bei Annäherungsverfahren eine sinnvolle Abbruchbedingung und gegebenenfalls eine Durchlaufgrenze fest. Das gezeigte Beispiel arbeitet nur mit drei eigenen Zahlen; es führt keine Dateioperationen oder wiederholten Systemzugriffe aus.

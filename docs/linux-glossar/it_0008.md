# Integer

## 1. Kurzbeschreibung

Ein Integer ist eine ganze Zahl, also eine Zahl ohne Bruchteil. Dazu zählen negative Zahlen, null und positive Zahlen. In Python heißt der eingebaute Typ `int`; `42` ist ein passendes Beispiel. Integer eignen sich etwa zum Zählen einzelner Ereignisse, wenn halbe Ereignisse in der betrachteten Aufgabe keinen Sinn ergeben.

## 2. Was bedeutet der Begriff?

Der Begriff beschreibt zunächst eine Art von Zahlen, nicht deren Schreibweise. Die Dezimalschreibweise `42` und die Hexadezimalschreibweise `0x2a` bezeichnen in Python denselben ganzzahligen Wert. Die Zahlbasis bestimmt, wie Stellen gewichtet werden; sie erzeugt keinen grundsätzlich anderen Wert.

Wichtig ist die Unterscheidung zwischen der Sprache und dem allgemeinen Konzept. Python-Integer besitzen keine feste 32- oder 64-Bit-Grenze für ihre Genauigkeit. Sie können mit dem benötigten Speicher wachsen. Die [Python-Referenz zu numerischen Typen](https://docs.python.org/3.13/library/stdtypes.html#numeric-types-int-float-complex) spricht von unbegrenzter Genauigkeit. Das bedeutet keine unbegrenzten Ressourcen: Sehr große Zahlen benötigen Speicher und Rechenzeit. In anderen Sprachen und binären Dateiformaten sind feste Grenzen verbreitet.

## 3. Einfacher Vergleich aus dem Alltag

Beim Zählen von Stühlen erhältst du normalerweise ganze Zahlen: null, eins, zwei und so weiter. Ein halber Stuhl ist für die Frage nach verfügbaren vollständigen Sitzplätzen keine sinnvolle zusätzliche Einheit.

Der Vergleich hat Grenzen. Integer können auch negative Werte enthalten, obwohl eine negative Anzahl bereitstehender Stühle in dieser einfachen Situation unsinnig wäre. Der Zahlentyp allein kennt die fachliche Bedeutung nicht. Eine negative Kontobewegung kann sinnvoll sein, eine negative Anzahl vorhandener Dateien möglicherweise ein Fehler.

## 4. Wie funktioniert das?

Mit Python-Integern kannst du unter anderem addieren, multiplizieren und vergleichen. Die gewöhnliche Division `/` liefert bei zwei Integern einen Float. `//` liefert den nach unten abgerundeten ganzzahligen Quotienten; `%` den dazugehörigen Rest. Bei positiven Zahlen lässt sich damit eine Anzahl in vollständige Gruppen und übrig gebliebene Elemente zerlegen.

Bei negativen Zahlen ist „nach unten“ wichtig: Es bedeutet Richtung negativer Unendlichkeit, nicht grundsätzlich Richtung null. Eine Umwandlung mit `int` aus einem Float schneidet den Bruchteil dagegen Richtung null ab. Die [Dokumentation zu int](https://docs.python.org/3.13/library/functions.html#int) erklärt diese Umwandlung. Sie ist keine allgemeine kaufmännische Rundung.

## 5. Wo begegnet mir das unter Linux?

Zählerstände, Dateigrößen in Bytes und Prozesskennungen können als ganze Zahlen verarbeitet werden. Trotzdem haben sie verschiedene Bedeutungen. Eine Prozesskennung ist eine Kennung; ihre Addition mit einer anderen Kennung ist normalerweise keine nützliche Operation.

An Schnittstellen kann ein eigentlich ganzzahliger Wert zunächst als Text ankommen. Ein Python-Skript muss dann eine passende Umwandlung vornehmen und Grenzen prüfen. Bei der Übergabe an ein Dateiformat oder eine Systembibliothek kann außerdem ein fester Wertebereich gelten, selbst wenn der Python-Integer den Wert problemlos darstellen kann.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verteilt 42 selbst gewählte Einheiten auf Gruppen zu zehn:

```python
anzahl = 42
gruppengroesse = 10
gruppen = anzahl // gruppengroesse
rest = anzahl % gruppengroesse
assert type(anzahl) is int
assert (gruppen, rest) == (4, 2)
assert gruppen * gruppengroesse + rest == anzahl
assert int("2a", 16) == anzahl
print(gruppen, rest)
print(int("2a", 16))
```

Die Ausgabe lautet:

```text
4 2
42
```

Zuerst berechnet `//` die vier vollständigen Gruppen. `%` ermittelt die zwei verbleibenden Einheiten. Eine Zusicherung prüft, dass sich daraus wieder 42 ergibt. Die letzte Umwandlung zeigt dieselbe Zahl in Basis sechzehn: Dort steht die Ziffer `a` für zehn. Es werden keine echten Dateien oder Geräte verarbeitet.

## 7. Abgrenzung zu ähnlichen Begriffen

Der String `"42"` enthält Zeichen; der Integer `42` ist eine Zahl. Der Float `42.0` besitzt einen anderen Typ, obwohl er hier denselben Zahlenwert repräsentiert. Python-Boolean ist zwar ein Untertyp von `int`, soll aber logisch eine Ja/Nein-Frage ausdrücken und nicht bloß irgendeinen Zähler ersetzen.

## 8. Häufige Missverständnisse

Ein Integer ist nicht automatisch positiv. Eine Zahl ohne sichtbare Nachkommastellen muss auch nicht vom Typ `int` sein. Unbegrenzte Genauigkeit in Python schützt außerdem nicht vor Ressourcenverbrauch oder vor den festen Grenzen eines externen Formats.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe bei Mengenangaben, ob null erlaubt ist und wo eine sinnvolle Obergrenze liegt. Prüfe vor Divisionen, dass der Teiler nicht null ist. Bei sehr langen fremden Zahlentexten sind auch Zeit- und Speichergrenzen relevant. Das Beispiel verwendet kleine feste Zahlen und schreibt ausschließlich die dokumentierte Ausgabe.

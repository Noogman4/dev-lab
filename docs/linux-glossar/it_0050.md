# Pointer

## 1. Kurzbeschreibung

Ein Pointer, auf Deutsch Zeiger, ist ein Wert, der in einer Sprache wie C auf Daten oder eine Funktion verweisen kann. Bei einem Datenzeiger beschreibt der Zeigertyp, welche Art von Daten angesprochen werden soll. Die Quelle verbindet Speicheradresse und Referenz; diese Begriffe dürfen jedoch nicht für alle Sprachen als identische Schnittstelle behandelt werden.

## 2. Was bedeutet der Begriff?

Ein Zeigerwert ist vom Inhalt des angesprochenen Objekts zu unterscheiden. Ein Zeiger auf eine Zahl ist nicht die Zahl selbst. Ein Zugriff über den Zeiger heißt Dereferenzierung. Das [GNU-C-Handbuch zu Pointern](https://www.gnu.org/software/c-intro-and-ref/manual/html_node/Pointers.html) erläutert Adressen, Typen und den Dereferenzierungsoperator.

Ein Zeiger kann außerdem einen besonderen Nullzeigerwert besitzen, der kein Objekt bezeichnet. Nicht jede beliebige Zahl ist eine gültige verwendbare Adresse. Gültigkeit hängt unter anderem vom adressierten Objekt, dessen Lebensdauer und der vorgesehenen Zugriffsart ab.

## 3. Einfacher Vergleich aus dem Alltag

Ein Abholschein enthält einen Hinweis, wo ein Gegenstand liegt. Du kannst den Hinweis weitergeben, ohne den Gegenstand selbst zu kopieren. Zwei Scheine können auf denselben Gegenstand verweisen.

Die Grenze des Vergleichs: Eine Speicheradresse ist keine dauerhaft gültige Postanschrift. Ein früher gültiger Verweis kann nach Ende einer Objektlebensdauer unbrauchbar sein. Ein C-Programm erhält bei jedem falschen Zugriff auch nicht automatisch eine verständliche Rückmeldung wie an einer Ausgabestelle.

## 4. Wie funktioniert das?

In C kann `&wert` die Adresse eines passenden Objekts liefern. Ein entsprechend deklarierter Pointer speichert diesen Verweis. Über `*p` kann anschließend das bezeichnete Objekt gelesen oder, wenn erlaubt, verändert werden. Der Stern in einer Deklaration beschreibt dabei einen Zeigertyp; in einem Ausdruck kann er die Dereferenzierung bedeuten.

Das [GNU-Handbuch zu ungültiger Dereferenzierung](https://www.gnu.org/software/c-intro-and-ref/manual/html_node/Invalid-Dereference.html) beschreibt die Folgen ungültiger Zugriffe. Solche Situationen können undefiniertes Verhalten verursachen; ein erwarteter Absturz ist keine zuverlässige Schutzfunktion.

Andere Sprachen setzen zusätzliche Regeln durch. Das [offizielle Rust-Kapitel zu Referenzen](https://doc.rust-lang.org/book/ch04-02-references-and-borrowing.html) erklärt deren Gültigkeitszusicherung im sicheren Sprachmodell. Diese Referenzen sind deshalb nicht einfach mit beliebig verwendbaren rohen C-Zeigern gleichzusetzen.

## 5. Wo begegnet mir das unter Linux?

C-Bibliotheken und Systemprogramme verwenden Zeiger an ihren Schnittstellen. Ein Programm muss beispielsweise klären, wie lange übergebene Daten verfügbar bleiben und wer ihren Speicher verwaltet. Das gehört zur Schnittstellenvereinbarung.

Python-Variablen geben dagegen keine allgemeine Erlaubnis, beliebige Speicheradressen direkt anzusprechen. Auch eine als Zahl angezeigte Objektidentität ist keine portable Anleitung zum Dereferenzieren. Für Fremdsprachen-Schnittstellen gelten eigene dokumentierte Regeln.

## 6. Konkretes Beispiel Schritt für Schritt

Die folgende C-Funktion ist ein Erläuterungsbeispiel. Sie wurde nicht kompiliert oder ausgeführt:

```c
int beispiel(void)
{
    int wert = 7;
    int *p = &wert;
    *p = 9;
    return wert;
}
```

Zuerst entsteht ein lokales Integerobjekt. `p` erhält dessen Adresse und ist als Pointer auf `int` deklariert. Die Zuweisung über `*p` betrifft dasselbe Objekt. Der vorgesehene Rückgabewert der Funktion ist deshalb neun.

Der Pointer wird hier nicht über die Lebensdauer des lokalen Objekts hinaus zurückgegeben. Die Funktion ist kein vollständiges eigenständig gestartetes Programm und erzeugt keine dokumentierte Terminalausgabe. Die Erklärung basiert auf den genannten C-Regeln, nicht auf einer behaupteten praktischen Prüfung.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Index bezeichnet eine Position in einer Struktur. Ein Pointer verweist nach den Regeln seiner Sprache auf Speicher oder Funktionen. Eine Referenz kann stärkere sprachliche Zusicherungen besitzen. Ein Dateipfad bezeichnet ebenfalls etwas, ist aber keine Speicheradresse.

## 8. Häufige Missverständnisse

Ein Pointer ist nicht automatisch acht Byte groß. Er ist nicht mit dem gespeicherten Nutzwert identisch. Ein nichtnull Zeiger ist nicht allein deshalb gültig. Auch muss die sichtbare Schreibweise eines Zeigers nicht einer dauerhaft verwendbaren physischen Adresse entsprechen.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe Typ, Lebensdauer und Zuständigkeit der Speicherverwaltung. Verwende keine ausgedachten Adressen für Lernversuche. Hier wurden weder Speicherexperimente noch C-/Rust-Ausführungen vorgenommen. Das Beispiel enthält nur eine statisch erläuterte lokale C-Funktion.

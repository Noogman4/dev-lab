# Datentyp

## 1. Kurzbeschreibung

Ein Datentyp beschreibt, welche Art von Wert vorliegt und welche Operationen dafür vorgesehen sind. Text, ganze Zahlen und Wahrheitswerte sind typische Beispiele. In Python heißen wichtige eingebaute Typen `str`, `int`, `bool` und `float`. Ein Typ ist mehr als eine Anzeigeform: Er beeinflusst die Bedeutung von Berechnungen und Vergleichen.

## 2. Was bedeutet der Begriff?

Der Typ beantwortet Fragen wie: Kann dieser Wert addiert werden? Hat er eine Länge? Ist er nach seiner Erstellung veränderbar? Die Antworten hängen vom jeweiligen Typ und gegebenenfalls vom zweiten beteiligten Wert ab.

In Python besitzt jedes Objekt einen Typ. Der Name einer Variablen ist dagegen nicht dauerhaft an einen bestimmten Typ gebunden. Die Zuweisung eines anderen Objekts ändert die Bindung des Namens, nicht nachträglich den Typ des ursprünglichen Objekts. Das [Python-Datenmodell zu Objekten, Werten und Typen](https://docs.python.org/3.13/reference/datamodel.html#objects-values-and-types) erklärt diese Grundlagen. Andere Sprachen können Typen zusätzlich für Variablen oder Ausdrücke vorab festlegen.

## 3. Einfacher Vergleich aus dem Alltag

Eine Hausnummer und eine Anzahl von Paketen können beide als „12“ auf Papier stehen. Trotzdem würdest du Hausnummern nicht addieren, um eine Gesamtadresse zu erhalten. Eine Paketanzahl lässt sich dagegen sinnvoll mit einer weiteren Anzahl zusammenzählen.

Das zeigt, warum die äußere Darstellung nicht ausreicht. Der Vergleich hat allerdings Grenzen: Ein grundlegender Zahlentyp kennt häufig keine fachliche Bedeutung wie „Hausnummer“. Ein Programm kann zwei Zahlen technisch addieren, obwohl die Rechnung fachlich unsinnig ist. Ein Typ hilft beim Umgang mit Daten, ersetzt aber nicht das Verständnis ihrer Bedeutung und Einheit.

## 4. Wie funktioniert das?

Python wählt Operationen passend zu den beteiligten Objekten. Bei zwei ganzen Zahlen bedeutet `+` Addition. Bei zwei Strings bedeutet es das Zusammenfügen der Zeichenketten. Eine beliebige Mischung wird nicht automatisch passend gemacht: Text und eine ganze Zahl lassen sich mit `+` nicht einfach verknüpfen.

Mit `type(wert)` erhältst du den konkreten Typ eines Objekts. Für Prüfungen, die auch Untertypen berücksichtigen sollen, empfiehlt die [Dokumentation zur Funktion type](https://docs.python.org/3.13/library/functions.html#type) dagegen `isinstance`. Ein Untertyp übernimmt bestimmte Eigenschaften eines allgemeineren Typs. Diese Unterscheidung ist beispielsweise bei `bool` und `int` in Python relevant, muss aber für das erste Zahlenbeispiel noch nicht ausgereizt werden.

## 5. Wo begegnet mir das unter Linux?

Ein Skript kann Text aus einer selbst angelegten Beispieldatei einlesen und daraus Zahlen gewinnen. Zuerst liegt häufig eine Zeichenkette vor. Für arithmetische Berechnungen ist anschließend eine ausdrücklich gewählte Umwandlung nötig. Eine Ziffernfolge wird nicht schon durch ihr Aussehen zur Zahl.

Auch in strukturierten Datenformaten können Zahlen, Texte und Wahrheitswerte getrennt gespeichert werden. Ein Auswertungsprogramm sollte prüfen, welchen Typ eine Schnittstelle tatsächlich liefert, statt jede Darstellung gleich zu behandeln. Ein Zeitwert benötigt außerdem eine bekannte Einheit, unabhängig davon, ob er als Integer oder Float übertragen wird.

## 6. Konkretes Beispiel Schritt für Schritt

Dieses vollständige Python-3-Beispiel vergleicht den Text `"42"` mit der Zahl `42`:

```python
text = "42"
zahl = int(text)
assert type(text) is str
assert type(zahl) is int
assert text + "1" == "421"
assert zahl + 1 == 43
print(type(text).__name__, type(zahl).__name__)
print(text + "1")
print(zahl + 1)
```

Die Ausgabe lautet:

```text
str int
421
43
```

`int(text)` erstellt aus einem geeigneten Zahlentext eine ganze Zahl. Die [Dokumentation zu int](https://docs.python.org/3.13/library/functions.html#int) beschreibt erlaubte Eingaben und Zahlbasen. Anschließend zeigt das Beispiel zwei verschiedene Bedeutungen des Pluszeichens. Der ursprüngliche Text bleibt Text; die Umwandlung ersetzt nicht heimlich sein Objekt durch einen anderen Typ.

## 7. Abgrenzung zu ähnlichen Begriffen

Der Wert unterscheidet etwa die Zahlen `3` und `4`; der Typ kann bei beiden `int` sein. Eine Variable bezeichnet in Python ein Objekt. Ein Dateiformat regelt die Speicherung von Daten; ein Dateiname wie `werte.txt` sagt noch nicht, welche Typen ein lesendes Programm daraus erzeugt.

## 8. Häufige Missverständnisse

Dynamische Typisierung bedeutet nicht, dass Python keine Typregeln hat. Eine Umwandlung ist außerdem kein Versprechen, dass jede Eingabe geeignet ist. Ein Text mit einer ausgeschriebenen Zahl lässt sich nicht mit derselben einfachen Integer-Umwandlung behandeln wie eine passende Ziffernfolge.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe Typ, Wertebereich und Einheit getrennt. Ungültige Eingaben sollten verständliche Fehlermeldungen ergeben. Vermeide allgemeine Codeauswertung als Ersatz für eine Zahlenumwandlung. Das Lernbeispiel arbeitet mit festen Daten im Speicher und verändert keine Dateien. Bei echten Eingaben müsstest du zusätzlich Umwandlungsfehler behandeln und fachlich sinnvolle Grenzen prüfen.

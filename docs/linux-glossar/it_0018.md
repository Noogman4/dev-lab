# Parameter

## 1. Kurzbeschreibung

Ein Parameter ist ein benannter Eingabeplatz in der Definition einer Funktion. Er beschreibt, welche Angaben die Funktion entgegennehmen kann. In `def greet(name):` ist `name` ein Parameter. Dieser Definitionsanfang benötigt in Python noch einen eingerückten Körper; erst daraus entsteht eine vollständige Funktionsdefinition.

## 2. Was bedeutet der Begriff?

Parameter gehören zur Schnittstelle eines Programmbausteins. Ihr Name kann die Bedeutung der Eingabe erklären, etwa `name` für einen Namen oder `dauer_sekunden` für eine Zeitspanne. Ein Parameter bestimmt allein durch seinen Namen aber noch keine verlässlich geprüfte Einheit oder erlaubten Wertebereich.

Das [offizielle Python-Glossar zu Parametern](https://docs.python.org/3.13/glossary.html#term-parameter) unterscheidet mehrere Arten: Manche Eingaben können nach Position oder Namen übergeben werden, andere nur auf eine dieser Weisen. Außerdem können bestimmte Parameter mehrere übergebene Angaben sammeln. Für den Einstieg genügt eine kleine feste Parameterliste.

## 3. Einfacher Vergleich aus dem Alltag

Auf einem Formular steht ein Feld „Name“. Die Feldbezeichnung entspricht dem Parameter; der später eingetragene Name entspricht einer konkreten Eingabe. Dasselbe Formular kann mit unterschiedlichen Namen verwendet werden.

Die Grenze des Vergleichs: Eine Funktion kann Eingaben anders als ein Papierformular über ihre Reihenfolge zuordnen. Außerdem können Objekte übergeben werden, die sich während der Verarbeitung verändern lassen. Die Vorstellung eines unveränderlichen Textfelds bildet solche technischen Zusammenhänge nicht vollständig ab.

## 4. Wie funktioniert das?

Beim Aufruf einer gewöhnlichen Python-Funktion werden passende Argumentwerte an die Parameternamen gebunden. Der Körper kann diese Namen wie lokale Namen verwenden. Die Anzahl und Zuordnung müssen zur Definition passen; fehlende erforderliche oder widersprüchlich zugeordnete Angaben führen zu einem Aufruffehler.

Ein Parameter kann einen Standardwert besitzen, den die Funktion bei ausgelassener Eingabe verwendet. In Python wird dieser Standardwert beim Ausführen der Definition ausgewertet, nicht bei jedem Aufruf neu erzeugt. Das [Tutorial zu Standardargumentwerten](https://docs.python.org/3.13/tutorial/controlflow.html#default-argument-values) warnt deshalb besonders vor veränderlichen Standardobjekten wie Listen. Ein fester Begrüßungstext ist im folgenden Beispiel unproblematisch.

## 5. Wo begegnet mir das unter Linux?

Ein Python-Hilfsprogramm kann eine Formatierungsfunktion für unterschiedliche Anzeigen verwenden. Statt einen Namen fest in ihren Körper zu schreiben, nimmt die Funktion ihn als Parameter entgegen. So lässt sich dieselbe Verarbeitung mit kleinen eigenen Testdaten prüfen.

Auch Werkzeughandbücher sprechen von Parametern. Dort kann das Wort allgemeiner eine Einstellung oder Kommandozeilenangabe meinen. Für die genaue Zuordnung zwischen Funktionsdefinition und Aufruf ist die hier erklärte sprachliche Unterscheidung hilfreicher. Die jeweilige Dokumentation sollte erkennen lassen, welche Bedeutung sie verwendet.

## 6. Konkretes Beispiel Schritt für Schritt

Dieses vollständige Python-3-Beispiel erweitert den Definitionsanfang der Quelle:

```python
def greet(name, gruss="Hallo"):
    return f"{gruss}, {name}!"

erste = greet("Sven")
zweite = greet("Sven", gruss="Guten Tag")
assert erste == "Hallo, Sven!"
assert zweite == "Guten Tag, Sven!"
assert greet("NetMon") == "Hallo, NetMon!"
print(erste)
print(zweite)
```

Die Ausgabe lautet:

```text
Hallo, Sven!
Guten Tag, Sven!
```

`name` besitzt keinen Standardwert und wird bei jedem gezeigten Aufruf angegeben. `gruss` verwendet beim ersten Aufruf seinen Standard. Beim zweiten wird ausdrücklich ein anderer Text zugeordnet. Die Funktion verändert keine außerhalb liegenden Daten, sondern gibt jeweils eine Zeichenkette zurück.

## 7. Abgrenzung zu ähnlichen Begriffen

Der Parameter ist der Eingabeplatz in der Definition. Das Argument ist die konkrete Angabe beim Aufruf. Eine lokale Variable kann erst im Körper entstehen, ohne Parameter zu sein. Der Rückgabewert fließt in die andere Richtung: von der Funktion zurück zum Aufrufer.

## 8. Häufige Missverständnisse

Ein Parameternamen wie `anzahl` erzwingt in Python nicht automatisch einen Integer. Ebenso ist eine Typannotation allein normalerweise keine Laufzeitprüfung. Ein Standardwert bedeutet nicht, dass für jeden Aufruf ein neues unabhängiges Objekt erzeugt wird. Position und Namen einer veröffentlichten Schnittstelle können für bestehende Aufrufer wichtig sein.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Wähle verständliche Namen und dokumentiere Einheiten sowie sinnvolle Grenzen. Verwende wenige klar zusammengehörende Eingaben. Prüfe ausgelassene optionale Angaben und bewusst übergebene Alternativen. Das Beispiel verwendet nur feste Texte; es liest keine persönlichen Daten oder Systemeinstellungen.

# Radiobutton

## 1. Kurzbeschreibung

Ein Radiobutton gehört typischerweise zu einer Gruppe gegenseitig ausschließender Auswahlmöglichkeiten. Die Quelle beschreibt genau eine Auswahl aus mehreren Optionen. Präziser erzwingt das Gruppenmodell zunächst höchstens eine passende Auswahl; ob von Anfang an eine Option gewählt ist, hängt von Ausgangswert und Anwendung ab.

## 2. Was bedeutet der Begriff?

Die Gruppe repräsentiert einen gemeinsamen Wert, etwa einen ausgewählten Modus. Jede Option steht für einen anderen möglichen Wert. Wird eine Option gewählt, ist die vorher passende Option derselben Gruppe nicht mehr ausgewählt.

Das [offizielle Tk-Handbuch zum ttk::radiobutton](https://raw.githubusercontent.com/tcltk/tk/core-8-6-branch/doc/ttk_radiobutton.n) beschreibt die gemeinsame Variable und den jeweiligen Optionswert. Nur nebeneinander gezeichnete Elemente sind deshalb noch keine verlässlich konfigurierte Gruppe. Die tatsächliche Zuordnung muss stimmen.

## 3. Einfacher Vergleich aus dem Alltag

An einem alten Radio konnte eine Stationstaste die zuvor gewählte Station ablösen. Die Tasten stellten Alternativen derselben Auswahl dar, nicht unabhängige An/Aus-Schalter für beliebig viele gleichzeitige Stationen.

Die Grenze des Vergleichs: Eine Softwaregruppe kann anfangs keinen passenden Wert besitzen oder einzelne Optionen deaktivieren. Außerdem muss die fachliche Aufgabe tatsächlich eine exklusive Entscheidung verlangen. Nicht jede äußerlich ähnliche Auswahl eignet sich für dieses Modell.

## 4. Wie funktioniert das?

In Tk verwenden zusammengehörige Radiobuttons dieselbe Variable und unterschiedliche Werte. Die ausgewählte Option entspricht dem aktuellen Variableninhalt. Passt kein Wert, kann keine Option ausgewählt erscheinen.

Pythons `ttk.Radiobutton.invoke` setzt den zugehörigen Wert und ruft die vorgesehene Aktion auf. Die [offizielle Python-Referenz](https://docs.python.org/3.13/library/tkinter.ttk.html#tkinter.ttk.Radiobutton.invoke) erläutert diesen Ablauf. Anders als bei einer gewöhnlichen Checkbox ist erneutes Aktivieren derselben Option keine allgemeine Aufforderung, die ganze Auswahl auszuschalten.

Die Anwendung muss zusätzlich entscheiden, ob eine Auswahl bereits wirksam oder erst nach einem weiteren Bestätigungsschritt angewandt wird. Eine passende Markierung beweist keine erfolgreich durchgeführte äußere Aktion.

## 5. Wo begegnet mir das unter Linux?

Einstellungen können zwischen mehreren Darstellungs- oder Auswertungsmodi wählen lassen. Radiobuttons machen die Alternativen gleichzeitig sichtbar. Bei sehr vielen Optionen kann eine andere Darstellung geeigneter sein.

Das Quellbeispiel IPv4 oder IPv6 ist nur für eine ausdrücklich exklusive Moduswahl passend. Reale Netzwerkumgebungen können beide Protokolle gleichzeitig verwenden. Die Oberflächenentscheidung darf deshalb nicht als allgemeine technische Unvereinbarkeit ausgegeben werden.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel prüft nur einen eigenen Moduswert unter dem virtuellen Bildschirm:

```python
# GUI-Prüfung im virtuellen Bildschirm
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.withdraw()
try:
    modus = tk.StringVar(master=root, value="keine Auswahl")
    v4 = ttk.Radiobutton(root, text="IPv4", variable=modus, value="IPv4")
    v6 = ttk.Radiobutton(root, text="IPv6", variable=modus, value="IPv6")
    assert v4.instate(["!selected"]) and v6.instate(["!selected"])
    v4.invoke()
    assert modus.get() == "IPv4" and v4.instate(["selected"])
    v6.invoke()
    assert modus.get() == "IPv6" and v4.instate(["!selected"])
    v6.invoke()
    assert v6.instate(["selected"])
    print(modus.get())
finally:
    root.destroy()
```

Die Ausgabe lautet:

```text
IPv6
```

Anfangs passt der Variablenwert zu keiner Option. Die Aktivierungen wählen erst IPv4 und dann IPv6. Die erste Option wird dabei abgelöst. Erneutes Aktivieren der bereits gewählten Option hebt diese Wahl nicht auf. Es wird keine Netzwerkkonfiguration geändert.

## 7. Abgrenzung zu ähnlichen Begriffen

Checkboxen repräsentieren typischerweise unabhängige Entscheidungen. Radiobuttons teilen einen Gruppenwert. Ein Button löst eine Aktion aus, ohne selbst dieselbe dauerhafte Auswahlrolle zu besitzen. Ein String ist nur der gespeicherte Wert und noch kein Auswahlwidget.

## 8. Häufige Missverständnisse

Eine Gruppe besitzt nicht automatisch eine gültige Anfangsauswahl. Gleiche Elterncontainer garantieren keine korrekte Variablenzuordnung. Zwei gleich konfigurierte Optionswerte wären keine unterscheidbaren Alternativen. Auch darf eine exklusive GUI-Wahl nicht als allgemeine Einschränkung des dargestellten Fachgebiets missverstanden werden.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Verwende das Muster nur für tatsächlich ausschließende Alternativen. Setze einen nachvollziehbaren Anfangszustand und erkläre den Wirkzeitpunkt. Das Beispiel testet programmgesteuerte lokale Werte und Auswahlzustände, keine echten Eingaben oder Protokollaktivierung.

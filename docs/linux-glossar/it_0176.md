# YAML

## 1. Kurzbeschreibung

YAML ist ein Datenformat für strukturierte Informationen und wird häufig für Konfigurationen verwendet. Es kann unter anderem Zuordnungen, Listen und einfache Werte darstellen. Einrückung und Schreibweise besitzen dabei Bedeutung. „Gut lesbar“ heißt nicht, dass jeder ähnlich aussehende Text dieselben Typen oder dieselbe Programmwirkung erzeugt.

## 2. Was bedeutet der Begriff?

Der Name wird als „YAML Ain’t Markup Language“ erläutert. Die [offizielle Spezifikation YAML 1.2.2](https://yaml.org/spec/1.2.2/) beschreibt die Sprache, Darstellungsformen und die Auflösung von Werten. Welche Typen aus unquotiertem Text entstehen, hängt auch vom verwendeten Schema und Parser ab.

Das Katalogbeispiel `docker-compose.yml` ist passend. Die [Compose-Spezifikation](https://compose-spec.github.io/compose-spec/spec.html) beschreibt Compose-Dateien als YAML und unterstützt diesen Namen weiterhin; bevorzugt wird dort `compose.yaml`. Das bedeutet nicht, dass beliebiges gültiges YAML automatisch eine gültige Compose-Konfiguration wäre.

## 3. Einfacher Vergleich aus dem Alltag

Ein eingerücktes Formular zeigt, welche Unterpunkte zu welchem Abschnitt gehören. Ein Wert kann ausdrücklich als Text gekennzeichnet sein, wenn er nicht als Zahl oder anderer Typ gelesen werden soll. Die gemeinsame Form erleichtert das Verständnis.

Die Grenze: Ein Parser richtet sich nach exakten Regeln, nicht nach dem optischen Eindruck. Eine andere Einrückung kann eine andere Struktur bilden. Auch ist die Schreibweise einer Kennung wie `0123` nicht zwingend als beliebige Zahl gemeint. Wenn Text benötigt wird, sollte diese Absicht klar dargestellt werden.

## 4. Wie funktioniert das?

Eine Zuordnung verbindet Schlüssel und Werte. Eine Liste enthält eine Folge von Elementen. YAML kann diese Strukturen unter anderem im Blockstil mit Einrückung ausdrücken. Für die Einrückung sind nach der Spezifikation Leerzeichen vorgesehen, keine Tabulatoren.

Werte können implizit einem Typ zugeordnet werden. Hier sind Versionsunterschiede wichtig: Bestimmte ältere YAML-Konventionen und verbreitete Parser behandeln Wörter wie `yes` anders als das YAML-1.2-Kernschema. Eine Aussage über „YAML allgemein“ sollte deshalb nicht allein aus einem einzelnen Parserergebnis abgeleitet werden.

Anchors, Aliase und Tags erweitern die Möglichkeiten. Ihre Wirkung ist nicht bloß das Kopieren beliebiger Textzeilen. Für den Einstieg genügen einfache Strukturen und bewusst gewählte Typen, bevor komplexere Konstruktionen hinzukommen.

## 5. Wo begegnet mir das unter Linux?

Werkzeuge können YAML zur Beschreibung von Diensten, Projekten oder anderen Einstellungen verwenden. Jedes davon definiert zusätzlich erlaubte Schlüssel und Bedeutungen. Eine syntaktisch korrekte Datei kann deshalb weiterhin vom eigentlichen Werkzeug abgelehnt werden.

Für die lokale Prüfung ist hier bereits PyYAML 6.0.2 vorhanden. Es wurde nichts installiert. Die [offizielle PyYAML-Dokumentation](https://pyyaml.org/wiki/PyYAMLDocumentation) beschreibt `safe_load` für Standarddaten. Dieser Aufruf ersetzt weder eine Schema- noch eine umfassende Sicherheitsprüfung beliebiger Eingaben.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Beispiel wurde mit Python 3.13 und dem vorhandenen PyYAML 6.0.2 in einem temporären Ordner ausgeführt. Es verarbeitet nur selbst erzeugten Text und keine tatsächliche Konfiguration.

```python
import yaml

text = 'name: Probe\naktiv: true\nkennung: "0123"\nports:\n  - 8080\n  - 8443\n'
werte = yaml.safe_load(text)
assert werte["name"] == "Probe"
assert werte["aktiv"] is True
assert werte["kennung"] == "0123"
assert werte["ports"] == [8080, 8443]
legacy = yaml.safe_load("wert: yes\n")["wert"]
assert legacy is True
print(werte["kennung"])
print(werte["ports"])
print("PyYAML deutet yes als Boolean:", legacy is True)
```

Geprüfte Ausgabe:

```text
0123
[8080, 8443]
PyYAML deutet yes als Boolean: True
```

Die Anführungszeichen erhalten die Kennung als Text. Die Liste enthält zwei Zahlen. Der letzte Fall zeigt ausdrücklich das Verhalten dieses Parsers, nicht die allgemeine YAML-1.2-Regel für `yes`. Es wird keine Compose-Datei geladen und kein Dienst eingerichtet.

## 7. Abgrenzung zu ähnlichen Begriffen

JSON ist ein anderes Datenformat mit anderen Darstellungsregeln. Eine Konfiguration verwendet ein Format und zusätzlich einen Anwendungsvertrag. Ein Python-Dictionary ist eine Datenstruktur im laufenden Programm. YAML-Text und das daraus erzeugte Objekt sind verschiedene Repräsentationen.

## 8. Häufige Missverständnisse

Eine Datei mit Endung `.yml` ist nicht allein dadurch gültig. Einrückung ist nicht nur Dekoration. Ein erfolgreiches Parsing bestätigt auch keine erlaubten Konfigurationsschlüssel. Außerdem dürfen Ergebnisse eines Parsers mit älteren Typregeln nicht stillschweigend allen YAML-Versionen zugeschrieben werden.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Nenne Parser und Version bei reproduzierbaren Beispielen. Wähle Datentypen bewusst und lade unbekannte Tags nicht ungeprüft als Programmobjekte. Der Versuch nutzt nur eigene kleine Daten und verändert weder Projektdateien, Abhängigkeiten noch Dienste oder Paketbestände.

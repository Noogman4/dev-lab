# Rückgabewert

## 1. Kurzbeschreibung

Ein Rückgabewert ist ein Wert, den ein aufgerufener Programmbaustein an seinen Aufrufer zurückliefert. Der Aufrufer kann ihn speichern, vergleichen oder weiterverarbeiten. Im Quellbeispiel gibt `return True` den Wahrheitswert `True` zurück. Eine sichtbare Ausgabe entsteht dadurch nicht automatisch.

## 2. Was bedeutet der Begriff?

Eine Funktion kann aus Eingaben ein Ergebnis bestimmen und es über ihre Schnittstelle zurückgeben. Der Rückgabewert verbindet damit zwei Verarbeitungsschritte, ohne dass der zweite eine Bildschirmausgabe wieder einlesen müsste. Ein String mit einer Meldung und das Anzeigen dieser Meldung sind unterschiedliche Vorgänge.

Welche Rückgaben vorgesehen sind, gehört zur Funktionsbeschreibung. Eine Suchfunktion könnte beispielsweise einen gefundenen Wert oder einen ausdrücklich vereinbarten Sonderwert liefern. Ohne diese Vereinbarung ist aus einem Ergebnis wie `False` oder `None` nicht automatisch abzulesen, ob ein Fehler, ein negatives Prüfergebnis oder eine fehlende Information gemeint ist.

## 3. Einfacher Vergleich aus dem Alltag

Du gibst einer Person eine Rechenaufgabe und erhältst einen Zettel mit dem Ergebnis zurück. Du kannst den Zettel anschließend für eine weitere Rechnung verwenden. Ruft die Person das Ergebnis nur laut aus, ist das eine andere Form der Weitergabe.

Der Vergleich hat Grenzen: Python muss nicht immer eine unabhängige Kopie eines Gegenstands zurückgeben. Eine Funktion kann ein bereits vorhandenes veränderliches Objekt liefern. Außerdem kann sie mit einer Ausnahme abbrechen, statt den erwarteten normalen Rückgabepfad zu beenden.

## 4. Wie funktioniert das?

Bei einer gewöhnlichen Python-Funktion wertet `return` seinen Ausdruck aus und leitet die Rückkehr zum Aufrufer ein. Bei `return` ohne Ausdruck ist der vorgesehene Rückgabewert `None`. Gehört die Rückkehr zu einem `try` mit `finally`, läuft vor der Rückkehr zuerst der `finally`-Block. Ein eigenes `return` in diesem Block kann den vorher vorgesehenen Wert ersetzen. Besondere Funktionsarten wie Generatoren folgen zusätzlichen Regeln. [Referenz zur return-Anweisung](https://docs.python.org/3.13/reference/simple_stmts.html#the-return-statement)

Auch wenn eine gewöhnliche Funktion ihr Ende ohne `return` erreicht, liefert sie `None`. Das [Tutorial zum Definieren von Funktionen](https://docs.python.org/3.13/tutorial/controlflow.html#defining-functions) erläutert diesen Unterschied zwischen sichtbarer Arbeit und einer fachlich nützlichen Rückgabe. Python übernimmt nicht automatisch den letzten im Körper berechneten Wert als Ergebnis.

## 5. Wo begegnet mir das unter Linux?

Ein Python-Hilfsprogramm kann einen Text prüfen und einen Boolean zurückliefern. Eine aufrufende Oberfläche entscheidet dann, welchen Hinweis sie anzeigt. Dieselbe Prüfung lässt sich dadurch unabhängig von einer bestimmten grafischen Ansicht verwenden.

Ein externes Kommandozeilenprogramm besitzt dagegen unter anderem Ausgabeströme und einen Prozess-Exitstatus. Das sind eigene Schnittstellen. Der Rückgabewert einer Python-Funktion, die einen solchen Prozess startet, kann ein Ergebnisobjekt mit mehreren Angaben sein. „Rückgabe“ bedeutet deshalb nicht automatisch „Terminaltext“ oder „Exitcode“.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel prüft eine selbst gewählte Zahl und trennt Berechnung und Ausgabe:

```python
def ist_positiv(zahl):
    if zahl > 0:
        return True
    return False

ergebnis = ist_positiv(3)
assert ergebnis is True
assert ist_positiv(0) is False
assert ist_positiv(-2) is False
print(ergebnis)
print(ist_positiv(0))
```

Die Ausgabe lautet:

```text
True
False
```

Beim positiven Wert beendet das erste `return` die Funktion. Bei null und negativen Werten wird dieser Zweig ausgelassen, und das abschließende `return False` liefert das Ergebnis. Die Funktion selbst druckt nichts. Erst der Aufrufer zeigt zwei Ergebnisse an; die Zusicherungen prüfen zusätzlich den negativen Fall.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Argument geht in den Aufruf hinein, der Rückgabewert kommt zurück. Eine Ausgabe ist eine Nebenwirkung auf einem Ausgabekanal. Eine Ausnahme kann einen anderen Kontrollfluss auslösen. Eine lokale Variable bleibt nicht allein deshalb außerhalb sichtbar, weil sie im Funktionskörper berechnet wurde.

## 8. Häufige Missverständnisse

`print` ersetzt kein fachlich sinnvolles `return`. Mehrere mit Kommas zurückgegebene Werte werden in Python typischerweise zu einem gemeinsamen Tupelwert zusammengefasst. `None` ist ebenfalls ein Rückgabewert, nicht der Beweis, dass ein Aufruf gar nicht stattgefunden hat.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Dokumentiere Ergebnistyp, Sonderfälle und mögliche Ausnahmen. Vermeide unklare Mischungen aus „Text anzeigen“ und „Daten liefern“, wenn aufrufender Code das Ergebnis weiterverwenden soll. Das Beispiel arbeitet ausschließlich mit eigenen Zahlen und verändert keine Dateien, Konten oder Dienste.

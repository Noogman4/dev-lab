# Variable

## 1. Kurzbeschreibung

Eine Variable erlaubt es, während eines Programmablaufs über einen Namen auf Daten zuzugreifen. Die Glossarquelle nennt sie einen „benannten Speicherplatz“. Dieses Bild hilft beim Einstieg, beschreibt aber nicht jede Sprache genau. In Python ist ein Name an ein Objekt gebunden; mehrere Namen können auf dasselbe Objekt verweisen.

## 2. Was bedeutet der Begriff?

Ein Name wie `name` kann einen Text bezeichnen, ein Name wie `anzahl` eine Zahl. Bei `name = 'Sven'` wird in Python der Name links an das Textobjekt rechts gebunden. Die [Sprachreferenz zur Namensbindung](https://docs.python.org/3.13/reference/executionmodel.html#binding-of-names) beschreibt diesen Zusammenhang.

Wird demselben Namen später etwas anderes zugewiesen, ändert sich die Bindung. Daraus folgt nicht, dass das vorherige Objekt selbst verändert wurde. Andere Programmiersprachen können Variablen dagegen stärker als Speicherstellen eines festgelegten Typs behandeln. Die Python-Erklärung ist deshalb eine konkrete Ausprägung des allgemeinen Begriffs, keine allgemeine Speicherregel.

## 3. Einfacher Vergleich aus dem Alltag

Stell dir beschriftete Lesezeichen vor: Eines trägt den Namen „aktuelle Rechnung“ und zeigt auf ein Dokument. Du kannst das Lesezeichen auf ein anderes Dokument setzen. Zwei Lesezeichen können auch dasselbe Dokument markieren.

Der Vergleich erklärt Bindungen besser als eine Schachtel, die ihren Inhalt bei jeder Weitergabe kopiert. Er hat dennoch Grenzen: Ein Programmobjekt ist kein Papierdokument. Es besitzt einen Typ, technische Eigenschaften und einen geregelten Lebenszyklus. Die tatsächliche Speicherverwaltung bleibt Aufgabe der Sprachimplementierung.

## 4. Wie funktioniert das?

Python wertet zunächst die rechte Seite einer Zuweisung aus und bindet das Ergebnis an das Ziel. Bei späteren Zugriffen wird der Name im passenden Gültigkeitsbereich gesucht. Ein Gültigkeitsbereich legt fest, wo eine Bindung sichtbar ist; eine Funktion kann beispielsweise eigene lokale Namen besitzen.

Wichtig ist der Unterschied zwischen Neuzuweisung und Veränderung. Zahlen und Strings sind in Python unveränderlich. Listen sind veränderlich: Das Anhängen eines Elements verändert die bestehende Liste. Sind zwei Namen daran gebunden, sehen beide diese Veränderung. Diese Eigenschaften erläutert das [Python-Datenmodell](https://docs.python.org/3.13/reference/datamodel.html#objects-values-and-types).

## 5. Wo begegnet mir das unter Linux?

Ein Python-Skript kann einen Dateinamen, einen selbst eingelesenen Messwert oder eine Benutzerauswahl in Variablen halten. Dadurch muss derselbe Wert nicht an mehreren Stellen wörtlich in den Code geschrieben werden. Gut gewählte Namen erleichtern das Lesen von Diagnose- und Hilfsprogrammen.

Auch Shell-Variablen und Umgebungsvariablen tragen Namen, folgen aber anderen Regeln. Eine normale Python-Variable wird nicht automatisch an gestartete Programme weitergegeben. Ebenso ändert eine Python-Zuweisung nicht nebenbei eine Systemeinstellung. Diese Ebenen solltest du beim Lesen von Linux-Anleitungen auseinanderhalten.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verwendet den Namen aus der Quelle und ergänzt zwei Bezeichnungen für eine Liste:

```python
name = "Sven"
kopie_des_namens = name
name = "NetMon"
werte = [1]
weitere_werte = werte
weitere_werte.append(2)
assert kopie_des_namens == "Sven"
assert name == "NetMon"
assert werte is weitere_werte
assert werte == [1, 2]
print(kopie_des_namens, name)
print(werte)
```

Die Ausgabe lautet:

```text
Sven NetMon
[1, 2]
```

Die zweite Zuweisung erstellt keinen allgemeinen Kopiermechanismus: Beide Namen bezeichnen zunächst denselben String. Die Neuzuweisung von `name` lässt die andere Bindung unverändert. Bei der Liste verweisen dagegen weiterhin beide Namen auf dasselbe veränderliche Objekt. `append` hängt dort ein Element an; deshalb zeigt auch `werte` anschließend zwei Zahlen.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Wert ist der Inhalt beziehungsweise Zustand eines Objekts. Die Variable ist in der Python-Betrachtung die benannte Bindung. Ein Datentyp bestimmt Eigenschaften des Objekts. Eine Konstante bezeichnet eine bewusst unverändert gehaltene Größe; ein großgeschriebener Python-Name allein erzwingt das nicht.

## 8. Häufige Missverständnisse

Die Zuweisung `b = a` bedeutet in Python nicht automatisch „erzeuge eine unabhängige Kopie“. Außerdem unterscheiden sich Namen in Groß- und Kleinschreibung. Ein Name kann vor seiner ersten Bindung nicht wie ein bereits gespeicherter Standardwert verwendet werden; Python meldet dann einen entsprechenden Namensfehler.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Wähle Namen, die Bedeutung und möglichst auch Einheiten erkennen lassen, etwa `dauer_sekunden`. Prüfe bei gemeinsam verwendeten Listen, ob eine Änderung wirklich alle Nutzer dieser Liste betreffen soll. Das Beispiel verändert nur eine selbst angelegte Liste im Arbeitsspeicher; vorhandene Dateien, Benutzerkonten und Systemeinstellungen bleiben unberührt.

## 10. Verwandte Begriffe

Ein [Ausdruck](it_0003.md) kann den Wert für eine Zuweisung liefern. [Datentyp](it_0006.md) erklärt die erlaubten Operationen. [String](it_0007.md) und [Integer](it_0008.md) sind konkrete Python-Typen; [Konstante](it_0005.md) erläutert die Absicht, eine Größe nicht neu zuzuweisen.

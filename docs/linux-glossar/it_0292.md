# Interpreter

## 1. Kurzbeschreibung

Ein Interpreter führt Anweisungen eines Programms mit einer Laufzeitumgebung aus. Die Eingabe kann Quelltext oder eine zuvor erzeugte Zwischenform sein. Bei CPython wird Python-Code typischerweise zunächst in Bytecode übersetzt.

## 2. Was bedeutet der Begriff?

Das [Python-Glossar zu Bytecode](https://docs.python.org/3.13/glossary.html) beschreibt die interne Darstellung, die CPython ausführt. Bytecode enthält Anweisungen für die virtuelle Maschine des Interpreters. Andere Python-Implementierungen können denselben Quelltext mit anderen internen Verfahren verarbeiten.

## 3. Einfacher Vergleich aus dem Alltag

Ein Musiker liest Noten und setzt sie beim Spielen um. Ein Programm kann in einer ähnlichen Weise Anweisungen bei der Ausführung verarbeiten. Der Vergleich endet bei der Vorbereitung. Ein Interpreter kann den ursprünglichen Text vorab in eine für seine Verarbeitung geeignetere Darstellung übersetzen.

## 4. Wie funktioniert das?

Bei CPython entsteht aus einer Folge von Anweisungen ein Codeobjekt. Die Laufzeit führt es in einem Kontext mit Variablen und verfügbaren Funktionen aus. Einige Fehler sind schon beim Übersetzen erkennbar, andere treten erst dann auf, wenn ein bestimmter Ausdruck ausgeführt wird.

Die [CPython-Dokumentation des Moduls dis](https://docs.python.org/3.13/library/dis.html) weist darauf hin, dass Bytecode ein Implementierungsdetail ist. Befehle und deren Darstellung können sich zwischen Python-Versionen ändern. Eine Auflistung solcher Befehle ist daher keine portable Programmierschnittstelle.

## 5. Wo begegnet mir das unter Linux?

Unter Linux kann ein Aufruf wie `python3` eine interaktive Sitzung starten oder eine Datei ausführen. Welche Python-Implementierung und Version verwendet wird, hängt von dem aufgerufenen Programm und seiner Umgebung ab.

## 6. Konkretes Beispiel Schritt für Schritt

Das Beispiel verwendet fest im Skript eingebetteten Code. Zunächst erzeugt es ein Codeobjekt. Danach führt es dieses in einem eigens angelegten Namensraum aus und prüft das Ergebnis.

```python
program = compile("ergebnis = 3 + 5", "<eigenes-beispiel>", "exec")
names = {}
exec(program, names)
assert names["ergebnis"] == 8
print(names["ergebnis"])
```

Die Ausgabe lautet `8`. Der Namensraum dient hier nur der Zuordnung des Werts und stellt keine Sandbox dar.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein [Compiler](it_0291.md) erzeugt Zielcode. Ein Interpreter führt Code in seiner Laufzeit aus. Derselbe Sprachweg kann beide Aufgaben enthalten. Ein nativer Maschinenbefehl wird hingegen unmittelbar vom Prozessor gemäß seiner Architektur verarbeitet.

## 8. Häufige Missverständnisse

Interpretation bedeutet nicht zwingend, den Text immer Zeile für Zeile zu lesen. Auch die Aussage, eine Sprache sei grundsätzlich langsam, lässt sich aus dem Einsatz eines Interpreters allein nicht ableiten.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Führe mit `exec` ausschließlich Code aus, dem du vertraust. Für Versionsfragen prüfe die konkrete Laufzeit. Verlasse dich bei internen Bytecode-Details nicht auf das Verhalten einer anderen Python-Ausgabe.

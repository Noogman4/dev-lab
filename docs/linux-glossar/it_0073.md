# Dropdown

## 1. Kurzbeschreibung

Ein Dropdown ist eine ausklappbare Auswahl, die im geschlossenen Zustand wenig Platz benötigt. Die Quelle nennt die Wahl eines Netzwerkinterfaces als Beispiel. Welche Werte angeboten werden und ob auch freie Texteingabe möglich ist, hängt vom konkreten Widget ab. Dropdown und editierbare Combobox sind nicht in jeder Schnittstelle identische Begriffe.

## 2. Was bedeutet der Begriff?

Die Oberfläche zeigt meist einen aktuellen Wert und öffnet bei Bedarf eine Liste möglicher Angaben. Die Person wählt daraus einen Eintrag. Eine Anwendung muss festlegen, ob keine Auswahl erlaubt ist, wie der Anfangswert entsteht und was die Auswahl fachlich bezeichnet.

Pythons `ttk.Combobox` verbindet einen einzeiligen Textbereich mit einer Werteliste. Die [offizielle Combobox-Referenz](https://docs.python.org/3.13/library/tkinter.ttk.html#tkinter.ttk.Combobox) beschreibt unter anderem Zustände und Auswahloperationen. Eine Combobox kann deshalb mehr als eine ausschließlich festgelegte Auswahl bereitstellen.

## 3. Einfacher Vergleich aus dem Alltag

Eine aufklappbare Karte bietet mehrere Alternativen an, zeigt aber nicht immer alle gleichzeitig. Das spart Platz. Die sichtbare Kurzangabe sollte trotzdem erkennen lassen, welche Alternative aktuell gewählt ist.

Die Grenze des Vergleichs: Softwarewerte können sich während des Betriebs ändern. Ein zuvor vorhandenes Gerät kann verschwinden, und eine sichtbare Beschriftung muss nicht die stabile interne Kennung sein. Die angebotene Liste und ihre fachliche Gültigkeit müssen deshalb passend gepflegt werden.

## 4. Wie funktioniert das?

Eine Anwendung stellt Werte und einen aktuellen Inhalt bereit. Bei einer Auswahl kann sie den zugehörigen Zustand übernehmen oder eine weitere Aktion vorsehen. Die konkrete Ereignisschnittstelle bestimmt, wann zusätzliche Verarbeitung stattfindet.

Das [offizielle Tk-Handbuch zur Combobox](https://raw.githubusercontent.com/tcltk/tk/core-8-6-branch/doc/ttk_combobox.n) beschreibt `readonly` als Beschränkung der Bearbeitung durch die Person. Das ist nicht automatisch eine allgemeine Validierung aller programmgesteuerten Zuweisungen. Eigener Code kann einen Inhalt setzen, der nicht in der Auswahlliste steht.

Auch ein Index der aktuellen Auswahl ist keine dauerhafte Kennung des gewählten Fachobjekts. Ändert sich die Reihenfolge, können andere Positionen entstehen. Beschriftung, Kennung und Listenposition sollten bewusst getrennt werden.

## 5. Wo begegnet mir das unter Linux?

Einstellungsfenster wählen beispielsweise Geräte, Profile oder Darstellungsmodi über Dropdowns. Bei Netzwerkinterfaces müssten die angebotenen Einträge zum tatsächlichen Datenstand passen. Eine Auswahl allein beweist keine Verbindung oder erfolgreiche Konfigurationsänderung.

Bei vielen Optionen kann zusätzlich eine Suchfunktion oder andere Darstellung sinnvoll sein. Die bloße Platzersparnis ist nicht das einzige Kriterium. Verständliche Bezeichnungen, Tastaturbedienung und erkennbare aktuelle Auswahl bleiben wichtig.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verwendet ausschließlich eigene Bezeichnungen unter dem virtuellen Bildschirm:

```python
# GUI-Prüfung im virtuellen Bildschirm
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.withdraw()
try:
    auswahl = ttk.Combobox(root, values=["Beispiel-A", "Beispiel-B"], state="readonly")
    auswahl.current(0)
    assert auswahl.get() == "Beispiel-A"
    auswahl.current(1)
    assert auswahl.get() == "Beispiel-B"
    print(auswahl.get())
    auswahl.set("Fremdwert")
    assert auswahl.get() == "Fremdwert"
    assert auswahl.current() == -1
    print(auswahl.current())
finally:
    root.destroy()
```

Die Ausgabe lautet:

```text
Beispiel-B
-1
```

Die erste Änderung wählt einen vorgesehenen Eintrag. Danach setzt das Programm bewusst einen anderen Text. Der Rückgabewert minus eins zeigt hier, dass kein Listeneintrag passt. Das demonstriert die Grenze des Nur-Lese-Zustands; eine reale Geräteliste wird nicht abgefragt.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Textfeld kann freie Eingabe anbieten. Radiobuttons zeigen eine kleine Gruppe von Alternativen gleichzeitig. Ein Menü kann Aktionen statt eines gespeicherten Auswahlwerts enthalten. Eine Combobox kann je nach Zustand freie Eingabe und Listenauswahl verbinden.

## 8. Häufige Missverständnisse

`readonly` garantiert keine fachlich gültige interne Zuweisung. Der erste Eintrag ist nicht zwangsläufig die richtige Voreinstellung. Eine Anzeigenummer ist keine stabile Gerätekennung. Ein im Widget gespeicherter Text beweist außerdem nicht, dass das bezeichnete Gerät aktuell vorhanden ist.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe leere, veränderte und nicht mehr gültige Auswahllisten. Kläre den Wirkzeitpunkt einer Wahl. Das Beispiel testet nur programmgesteuerten Inhalt; Popupdarstellung, echte Eingaben und Netzwerkauswahl wurden nicht praktisch abgenommen.

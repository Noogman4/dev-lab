# TUI

## 1. Kurzbeschreibung

TUI steht für Text User Interface, eine textbasierte Benutzeroberfläche. Häufig werden Bereiche eines Terminalbildschirms als zusammenhängende Ansicht mit Auswahl, Menüs und Statuszeilen verwendet. Die Quelle nennt `htop` als Beispiel. Eine TUI ist nicht einfach jede einzelne Textausgabe eines Kommandozeilenprogramms.

## 2. Was bedeutet der Begriff?

Eine TUI verwendet typischerweise Zeichenpositionen statt frei gestalteter grafischer Pixeloberflächen. Sie kann laufend aktualisiert werden und Tastatureingaben verarbeiten. Je nach Programm und Terminal sind auch Mausereignisse möglich. Die konkrete Bedienung legt die Anwendung fest.

Die [offizielle curses-Einführung für Python](https://docs.python.org/3.13/howto/curses.html#what-is-curses) beschreibt Bildschirmdarstellung und Tastaturverarbeitung für Textterminals. Dabei werden Unterschiede verschiedener Terminalfähigkeiten durch eine Bibliothek vermittelt. Eine TUI benötigt also ebenfalls eine passende Darstellungsumgebung, auch wenn sie kein gewöhnliches Desktopfenster erzeugt.

## 3. Einfacher Vergleich aus dem Alltag

Ein elektronischer Anzeigebereich mit festen Zeichenfeldern kann Tabellen, Markierungen und Hinweise darstellen. Die Bedienperson bewegt eine Auswahl und löst passende Aktionen aus, ohne jedes Mal einen vollständigen neuen Satz zu schreiben.

Die Grenze des Vergleichs: Ein Terminalprogramm muss Eingaben, Größenänderungen und Darstellungsfähigkeiten technisch verarbeiten. Der Textbildschirm ist nicht bloß ein statisches Formular. Ein unpassendes Terminal oder veränderte Zeichendarstellung kann Layout und Bedienung beeinflussen.

## 4. Wie funktioniert das?

Die Anwendung zeichnet benötigte Zeichenbereiche und verarbeitet Ereignisse. Ein ausgewählter Eintrag, eine Statuszeile und eine Hilfeleiste können gemeinsam den aktuellen Zustand anzeigen. Das muss nicht bedeuten, dass bei jeder Aktualisierung das gesamte Terminal als neue Textfolge nach unten wächst.

`htop` beschreibt sich im [offiziellen Handbuch des Projekts](https://raw.githubusercontent.com/htop-dev/htop/main/htop.1.in) als interaktiver, auf ncurses basierender Prozessbetrachter. Das Handbuch nennt Scrollen und Mausbedienung. Damit ist eine TUI nicht zwangsläufig auf reine Tastaturbedienung beschränkt.

Ein solches Programm kann zugleich Kommandozeilenoptionen besitzen. Die Aufrufschnittstelle und die danach laufende Textoberfläche sind unterschiedliche Aspekte derselben Anwendung.

## 5. Wo begegnet mir das unter Linux?

Prozessbetrachter, textbasierte Editoren und manche Einrichtungsprogramme verwenden TUIs. Sie können in einer Linux-Konsole, einem geeigneten Terminalemulator oder einer passenden entfernten Sitzung laufen. Die Voraussetzungen hängen vom konkreten Werkzeug ab.

Textbasierte Darstellung bedeutet weder automatisch geringes Risiko noch ausschließlich lesende Wirkung. Laut `htop`-Handbuch sind beispielsweise auch Aktionen auf Prozesse vorgesehen. Eine TUI kann daher ebenso verändernde Operationen anbieten wie eine grafische Oberfläche.

## 6. Konkretes Beispiel Schritt für Schritt

Das folgende Gedankenbeispiel ist eine erfundene Ansicht mit ausschließlich eigenen Auftragsnamen:

```text
Aufträge
> A   wartet
  B   fertig

Pfeile: Auswahl ändern    Enter: Details    Q: Beenden
```

Zunächst bezeichnet die Markierung den gewählten Eintrag. Eine Abwärtsbewegung würde im vorgesehenen Modell B auswählen. Die Detailaktion sollte sich danach auf B beziehen, nicht auf eine frühere Auswahl. Die Statusangabe ist wiederum vom bloßen Markieren zu unterscheiden.

Eine tatsächliche Prüfung müsste Darstellungsbreite, Eingabeverarbeitung, Auswahlzustand und sauberes Beenden untersuchen. Eine lesbare Zeichnung allein belegt diese Fähigkeiten nicht. Auch wäre zu prüfen, ob eine Aktion im betreffenden Programm nur Details zeigt oder reale Änderungen ausführt.

Dieses Bildschirmmodell wurde nicht implementiert oder interaktiv bedient. Es wurde kein `htop` gestartet und kein Prozess verändert.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine CLI beschreibt Kommandoaufrufe. Eine TUI bietet eine laufende textbasierte Bedienansicht. Eine GUI verwendet grafische Oberflächenelemente. Ein Terminalemulator kann selbst ein GUI-Programm sein und darin eine TUI anzeigen. Diese Begriffe beschreiben deshalb verschiedene Ebenen statt ausschließlich konkurrierende Programme.

## 8. Häufige Missverständnisse

Nicht jede Textausgabe ist eine TUI. Eine TUI ist nicht zwingend mauslos. Ein Terminalfenster ist nicht bereits die darin laufende Anwendung. Ein erfolgreich gestartetes Programm beweist zudem keine korrekte Darstellung bei jeder Größe oder in jeder entfernten Sitzung.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Lies Hilfe und Tastenbelegung des konkreten Programms. Unterscheide Auswahl von Ausführung. Prüfe vor verändernden Aktionen das tatsächlich betroffene Ziel. Dieses Dokument enthält ausschließlich ein Gedankenmodell und keine ausgeführte Prozess- oder Terminalbedienung.

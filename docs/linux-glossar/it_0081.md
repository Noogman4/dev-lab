# Canvas

## 1. Kurzbeschreibung

Ein Canvas ist eine Zeichenfläche innerhalb einer Benutzeroberfläche. Darauf können etwa Linien, Formen, Texte oder Bilder dargestellt werden. Die Quelle nennt Diagramme und Statusgrafiken passend als Beispiele. Welche Zeichenoperationen, Objekte und Eingabemöglichkeiten verfügbar sind, hängt vom verwendeten Toolkit ab.

## 2. Was bedeutet der Begriff?

Eine Zeichenfläche bietet einen eigenen räumlichen Zusammenhang. Koordinaten beschreiben Positionen; Farben und weitere Eigenschaften gestalten die Darstellung. Der angezeigte Inhalt kann ein Diagramm, eine schematische Übersicht oder eine andere grafische Information sein.

Tk verwaltet auf seinem Canvas einzelne grafische Elemente mit Kennungen und optionalen Tags. Das [offizielle Canvas-Handbuch](https://raw.githubusercontent.com/tcltk/tk/core-8-6-branch/doc/canvas.n) beschreibt Formen, Texte und ihre Bearbeitung. Diese Objektverwaltung ist keine allgemeine Zusicherung für jede andere Schnittstelle namens Canvas.

## 3. Einfacher Vergleich aus dem Alltag

Eine Pinnwand bietet Platz für mehrere Zeichnungen und beschriftete Formen. Einzelne Bestandteile können verschoben oder entfernt werden, ohne die gesamte Information neu zu entwerfen.

Die Grenze des Vergleichs: Eine technische Zeichenfläche besitzt genaue Koordinaten-, Ebenen- und Ereignisregeln. Nicht jede Implementierung bewahrt einzelne Formen als später ansprechbare Objekte. Manche arbeiten stärker mit unmittelbaren Zeichenoperationen oder Bilddaten. Das gewählte Modell muss deshalb bekannt sein.

## 4. Wie funktioniert das?

Die Anwendung erzeugt die Fläche und passende Zeicheninhalte. Bei Tk können diese über Kennungen oder gemeinsame Tags angesprochen werden. Ein Tag kann mehrere Elemente gruppieren; eine Elementkennung bezeichnet dagegen einen konkreten Bestandteil.

Zeichenreihenfolge und Überlagerung beeinflussen, was sichtbar ist. Ein vorhandenes Element kann durch andere Inhalte verdeckt sein. Eine Liste gespeicherter Objekte ist daher noch kein Nachweis, dass alle Informationen auf dem Bildschirm erkennbar sind.

Qt bietet mit `QGraphicsScene` ein anderes System zur Verwaltung zweidimensionaler grafischer Elemente. Die [offizielle Klassenbeschreibung](https://doc.qt.io/qt-6/qgraphicsscene.html) erläutert diese Aufgabe. Szene, zugehörige Ansicht und Tk-Canvas besitzen unterschiedliche Schnittstellen und dürfen nicht allein aufgrund ähnlicher Zwecke gleichgesetzt werden.

## 5. Wo begegnet mir das unter Linux?

Anwendungen können Messreihen, Verbindungen oder eigene Skizzen auf Zeichenflächen darstellen. Die Grafik muss aus passenden Daten entstehen; ein gezeichnetes Verbindungssymbol beweist keine echte Netzwerkverbindung.

Auch Größenänderung, Skalierung und Bedienung brauchen eigene Regeln. Eine Form an einer korrekten gespeicherten Position kann bei einer unpassenden Ansicht trotzdem abgeschnitten oder zu klein sein. Datenprüfung und Darstellungsabnahme bleiben getrennte Aufgaben.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel prüft eigene Tk-Zeichenobjekte unter dem vorhandenen virtuellen Bildschirm. Das Fenster bleibt verborgen:

```python
# GUI-Prüfung im virtuellen Bildschirm
import tkinter as tk

root = tk.Tk()
root.withdraw()
try:
    flaeche = tk.Canvas(root, width=200, height=100)
    rechteck = flaeche.create_rectangle(10, 10, 50, 40, tags=("probe",))
    text = flaeche.create_text(30, 25, text="A", tags=("probe",))
    assert len(flaeche.find_withtag("probe")) == 2
    flaeche.move("probe", 5, 0)
    assert flaeche.coords(rechteck) == [15.0, 10.0, 55.0, 40.0]
    flaeche.delete(text)
    assert len(flaeche.find_all()) == 1
    print(flaeche.type(rechteck))
    print(flaeche.coords(rechteck))
finally:
    root.destroy()
```

Die Ausgabe lautet:

```text
rectangle
[15.0, 10.0, 55.0, 40.0]
```

Zwei eigene Elemente erhalten denselben Gruppentag und werden gemeinsam verschoben. Danach wird nur der Text entfernt. Geprüft werden gespeicherte Objekte und Koordinaten. Sichtbare Linienqualität, Überlagerung und tatsächliche Bedienung wurden damit nicht abgenommen.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Frame gruppiert Widgets. Ein Canvas stellt eine Zeichenfläche mit toolkitabhängigen Zeichenmöglichkeiten bereit. Ein Bild ist ein möglicher Inhalt. Ein Layout ordnet Oberflächenelemente an und ersetzt nicht automatisch die interne Koordinatenverwaltung einer Grafik.

## 8. Häufige Missverständnisse

Ein Canvas ist nicht von selbst ein fertiges Diagrammwerkzeug. Vorhandene Objekte sind nicht zwangsläufig sichtbar. Eine gespeicherte Koordinate garantiert keine passende Darstellung bei jeder Skalierung. Das Löschen eines Zeichenobjekts entfernt außerdem keine zugrunde liegenden externen Daten.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Dokumentiere Koordinatenmodell, Skalierung und Bedeutung der Grafik. Prüfe lange Texte und veränderte Fenstergrößen gesondert. Das Beispiel bearbeitet nur eigene Canvas-Objekte; Qt, NetMons Grafiken und reale Messdaten wurden nicht praktisch geprüft.

## 10. Verwandte Begriffe

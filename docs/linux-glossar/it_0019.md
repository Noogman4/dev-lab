# Argument

## 1. Kurzbeschreibung

Ein Argument ist eine konkrete Eingabe bei einem Funktionsaufruf. Bei `greet('Sven')` wird der Textwert `Sven` übergeben. Ein Parameter beschreibt dagegen den Eingabeplatz in der Definition. Diese Unterscheidung hilft, eine Funktionsbeschreibung mit einem konkreten Aufruf zu verbinden und Fehler bei der Zuordnung zu verstehen.

## 2. Was bedeutet der Begriff?

Ein Argument muss nicht als fester Wert im Code stehen. Es kann auch durch einen Namen oder eine Berechnung geliefert werden. Beim Aufruf wird der betreffende Ausdruck ausgewertet; der entstehende Wert wird der Funktion übergeben. Das [Python-Glossar zu Argumenten](https://docs.python.org/3.13/glossary.html#term-argument) beschreibt diese Rolle ausdrücklich.

Python unterscheidet Positionsargumente und Schlüsselwortargumente. Ein Positionsargument wird über seine Stelle zugeordnet. Bei einem Schlüsselwortargument benennt der Aufruf den vorgesehenen Parameter. Welche Formen erlaubt sind, hängt von der Funktionsdefinition ab; nicht jede Eingabe darf auf beide Weisen übergeben werden.

## 3. Einfacher Vergleich aus dem Alltag

Bei einer Bestellung kannst du entweder sagen „ein Tee, zwei Zucker“ oder die Angaben in beschriftete Felder eintragen. Die konkreten Bestelldaten entsprechen den Argumenten; die vorgesehenen Felder entsprechen den Parametern.

Der Vergleich hat Grenzen. Ein Mensch kann eine unvollständige Bestellung durch Nachfragen klären. Eine Funktion verwendet ihre festgelegten Zuordnungsregeln. Außerdem werden nicht zwingend unabhängige Kopien aller Daten übergeben. Bei veränderlichen Python-Objekten kann eine Funktion dasselbe Objekt bearbeiten, das der Aufrufer weiterhin verwendet.

## 4. Wie funktioniert das?

Python wertet Argumentausdrücke vor dem eigentlichen Aufruf aus. Danach werden ihre Werte den vorgesehenen Eingabeplätzen zugeordnet. Fehlen erforderliche Angaben, gibt es zu viele oder wird derselbe Platz doppelt belegt, kann ein `TypeError` entstehen. Die genaue Verarbeitung erläutert die [Sprachreferenz zu Aufrufen](https://docs.python.org/3.13/reference/expressions.html#calls).

Eine Schreibweise wie `name="Sven"` im Aufruf ist dabei keine beliebige Zuweisung an einen Namen außerhalb der Funktion. Sie kennzeichnet die Zuordnung zum betreffenden Parameter. Ein Standardwert der Definition wird nur für einen nicht anderweitig belegten optionalen Eingabeplatz verwendet.

## 5. Wo begegnet mir das unter Linux?

Ein Python-Hilfsprogramm kann eine Meldungsfunktion mit einem Namen und einer gewählten Sprache aufrufen. Derselbe Baustein erzeugt dann anhand unterschiedlicher Argumente passende Ausgaben. Klare Schlüsselwortargumente können besonders bei mehreren ähnlich aussehenden Zahlen die Lesbarkeit verbessern.

Auch ein gestartetes Kommandozeilenprogramm erhält Argumente. Das ist ein anderer Übergabekontext als ein Python-Funktionsaufruf. Welche Angaben das Programm erwartet und wie die Shell sie aufteilt, erklären dessen Handbuch und die Shell-Regeln. Eine ähnliche Bezeichnung ersetzt diese Dokumentation nicht.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel zeigt zwei gleichwertige Zuordnungen sowie einen berechneten Argumentwert:

```python
def greet(name, gruss="Hallo"):
    return f"{gruss}, {name}!"

name = "Sven"
position = greet(name, "Guten Tag")
benannt = greet(gruss="Guten Tag", name=name)
berechnet = greet("Net" + "Mon")
assert position == benannt == "Guten Tag, Sven!"
assert berechnet == "Hallo, NetMon!"
print(position)
print(berechnet)
```

Die Ausgabe lautet:

```text
Guten Tag, Sven!
Hallo, NetMon!
```

Der erste Aufruf ordnet nach Position zu. Der zweite nennt beide Parameter ausdrücklich und darf ihre Reihenfolge hier ändern. Beim dritten wird zunächst der Textausdruck ausgewertet. Die Funktion erhält dessen Ergebnis `NetMon`, nicht eine Anweisung, später selbst Texte zusammenzukleben.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein Parameter steht in der Definition, ein Argument im Aufruf. Der Rückgabewert ist die Antwort der Funktion. Ein Operand gehört zu einer Operation mit einem Operator; ein Argument gehört zur Aufrufschnittstelle. Ein und derselbe Zahlenwert kann in unterschiedlichen Ausdrücken unterschiedliche dieser Rollen übernehmen.

## 8. Häufige Missverständnisse

Der Name einer Variablen beim Aufrufer muss nicht genauso heißen wie der Parameter. Schlüsselwortargumente müssen dagegen zur definierten Schnittstelle passen. Eine Typannotation erzwingt in Python allein normalerweise keine Laufzeitkontrolle der übergebenen Objekte. Auch das bloße Übergeben einer Liste erzeugt keine garantierte unabhängige Kopie.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe Anzahl, Zuordnung, Typ und fachliche Bedeutung getrennt. Lies bei unbekannten Funktionen nach, ob veränderliche Eingaben bearbeitet werden. Das Beispiel verwendet ausschließlich eigene unveränderliche Texte und gibt neue Meldungen zurück. Es startet kein externes Programm und verändert keine vorhandenen Dateien.

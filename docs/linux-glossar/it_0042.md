# Set

## 1. Kurzbeschreibung

Ein Set ist eine Menge eindeutiger Elemente. Es beantwortet vor allem die Frage, ob ein Element dazugehört, nicht an welcher Position es steht. Pythons `set` speichert keine Listenpositionen oder zugesicherte Einfügereihenfolge. Gleiche Elemente werden nur einmal vertreten. Was als gleich gilt, folgt den Regeln des verwendeten Typs.

## 2. Was bedeutet der Begriff?

Die Quelle beschreibt das automatische Entfernen doppelter Einträge. Für Python ist genauer: Wird eine Liste in ein Set überführt, entsteht eine Sammlung eindeutiger Elemente. Die ursprüngliche Liste bleibt dabei erhalten, solange sie nicht ausdrücklich verändert wird. Informationen über Häufigkeit und ursprüngliche Reihenfolge gehen in der Menge verloren.

Die [Referenz zu set und frozenset](https://docs.python.org/3.13/library/stdtypes.html#set-types-set-frozenset) definiert Mengen als ungeordnete Sammlungen unterschiedlicher hashbarer Objekte. Hashbar bedeutet vereinfacht, dass ein Objekt die benötigten stabilen Hash- und Gleichheitsregeln unterstützt. Gewöhnliche Listen eignen sich nicht als Set-Elemente.

## 3. Einfacher Vergleich aus dem Alltag

Eine Liste verschiedener vorhandener Werkzeugarten soll „Hammer“ nur einmal nennen, auch wenn drei Hämmer vorhanden sind. Eine Mengenansicht beantwortet dann, welche Arten vorhanden sind, nicht wie viele Exemplare es jeweils gibt.

Der Vergleich hat Grenzen: Die technische Gleichheit folgt nicht automatisch menschlicher Ähnlichkeit. Unterschiedlich geschriebene Namen können verschiedene Elemente sein. Umgekehrt können in Python bestimmte Zahlen und Wahrheitswerte gleich vergleichen. Ein Set bereinigt daher nicht selbstständig uneinheitliche fachliche Bezeichnungen.

## 4. Wie funktioniert das?

`set(eingabe)` übernimmt die unterschiedlichen Elemente einer durchlaufbaren Eingabe. `in` prüft Zugehörigkeit. Die Schnittmenge enthält Elemente beider Mengen, die Vereinigung Elemente mindestens einer und die Differenz diejenigen nur der ersten Menge. Das [Python-Tutorial zu Mengen](https://docs.python.org/3.13/tutorial/datastructures.html#sets) zeigt diese Operationen.

Ein veränderliches `set` erlaubt Hinzufügen und Entfernen. `frozenset` besitzt dagegen eine unveränderliche Mengenstruktur. Beide sind keine Positionsfolgen: Ein Zugriff auf „das zweite Element“ gehört nicht zu ihrer Schnittstelle. Für eine geordnete Anzeige kann eine ausdrücklich sortierte neue Folge erstellt werden.

## 5. Wo begegnet mir das unter Linux?

Ein Auswertungsskript kann eindeutige Kategorien eines Berichts sammeln oder zwei selbst erfasste Bestandslisten vergleichen. Eine Menge eignet sich, wenn Vorkommen und Zugehörigkeit wichtig sind. Für eine Warteschlange oder eine chronologische Ereignisfolge wäre der Verlust der Reihenfolge dagegen problematisch.

Eine Mengenbildung sollte außerdem nicht ungefragt doppelte Datensätze verwerfen, wenn ihre Anzahl Bedeutung besitzt. Zwei gleiche Fehlermeldungen können zwei getrennte Ereignisse dokumentieren. Das gewählte Datenmodell muss zur Frage passen.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verarbeitet nur eigene Zahlen, keine Netzwerkverbindungen:

```python
eingabe = [80, 443, 80, 53]
ports = set(eingabe)
andere = {53, 8080}
assert eingabe == [80, 443, 80, 53]
assert len(ports) == 3
assert 443 in ports
assert ports & andere == {53}
assert ports - andere == {80, 443}
print(sorted(ports))
print(sorted(ports & andere))
```

Die Ausgabe lautet:

```text
[53, 80, 443]
[53]
```

Die doppelte `80` erzeugt kein zweites Set-Element. Die Eingabeliste behält ihre vier Einträge. Die Schnittmenge enthält nur `53`. `sorted` erzeugt für die Ausgabe eine sortierte Liste; die gezeigte Reihenfolge ist keine zugesicherte Eigenschaft des ursprünglichen Sets.

## 7. Abgrenzung zu ähnlichen Begriffen

Eine Liste erhält Positionen und erlaubt Duplikate. Ein Dictionary ordnet Schlüsseln Werte zu. Ein Set hält nur die eindeutigen Elemente. Eine Sammlung mit Häufigkeiten benötigt zusätzliche Zähler. Die Wahl beeinflusst, welche Informationen erhalten bleiben und welche später noch beantwortbar sind.

## 8. Häufige Missverständnisse

Leere geschweifte Klammern erzeugen in Python ein Dictionary; ein leeres Set wird mit `set()` erstellt. Ungeordnet bedeutet nicht zufällig sortiert. Ein Set speichert keine verlässliche ursprüngliche Position und korrigiert keine Schreibfehler oder fachlich gleichbedeutenden Texte.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Prüfe vor dem Entfernen von Duplikaten, ob Häufigkeiten oder Reihenfolge benötigt werden. Lege fachliche Gleichheit ausdrücklich fest. Das Beispiel verändert nur eigene Speicherobjekte und kontaktiert keine der als Zahlen notierten Ports.

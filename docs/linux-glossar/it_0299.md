# Benchmark

## 1. Kurzbeschreibung

Ein Benchmark misst die Leistung einer festgelegten Aufgabe unter beschriebenen Bedingungen. Er kann beispielsweise zeigen, wie lange zwei Varianten für dieselbe Eingabe brauchen. Ein Vergleich setzt voraus, dass beide Varianten die beabsichtigte Arbeit tatsächlich erledigen.

## 2. Was bedeutet der Begriff?

Bei zwei Scanner-Methoden musst du zunächst klären, was sie erfassen sollen. Wenn eine Methode mehr Daten oder zusätzliche Prüfungen berücksichtigt, beantworten die Laufzeiten unterschiedliche Fragen. Für einen ersten lokalen Vergleich eignen sich kleine, reproduzierbare Eingaben.

## 3. Einfacher Vergleich aus dem Alltag

Ein Laufvergleich auf derselben Strecke ist aussagekräftiger, wenn Länge und Untergrund gleich sind. Ein Softwarebenchmark braucht ebenfalls vergleichbare Bedingungen. Zusätzlich wirken etwa der Warmzustand eines Caches und Hintergrundaktivität des Rechners.

## 4. Wie funktioniert das?

Lege Eingabe, Messgrenzen und Einheit fest. Wenn das Laden von Daten Teil der Nutzeraufgabe ist, kann es zur Messung gehören. Wenn du nur einen Rechenschritt untersuchst, solltest du die Vorbereitung passend davon trennen. Wiederholungen zeigen, ob einzelne Läufe stark abweichen.

Die [Python-Dokumentation zu timeit](https://docs.python.org/3.13/library/timeit.html) beschreibt kleine Zeitmessungen und weist auf ihre Grenzen hin. Die [pyperf-Dokumentation zur Messung](https://pyperf.readthedocs.io/en/latest/run_benchmark.html) erläutert unter anderem vorbereitende Durchläufe und den Einsatz mehrerer Messprozesse.

## 5. Wo begegnet mir das unter Linux?

Unter Linux können Parallelprogramme, Stromsparzustand und Dateicaches Ergebnisse beeinflussen. Halte Softwarestand, Hardware und Bedingungen bei einer wichtigen Messung fest. Messungen auf einem Laptop lassen sich nicht direkt auf einen Server übertragen.

## 6. Konkretes Beispiel Schritt für Schritt

Das Beispiel vergleicht zwei Rechenformen mit derselben Folge. Zuerst prüft es, dass beide dasselbe Ergebnis liefern. Danach misst es drei Durchläufe pro Variante. Jeder Messwert bündelt mehrere Funktionsaufrufe.

```python
from timeit import repeat

values = tuple(range(20))
def a():
    return sum(values)

def b():
    result = 0
    for value in values:
        result += value
    return result

assert a() == b() == 190
samples = [repeat(fn, repeat=3, number=100) for fn in (a, b)]
assert all(len(group) == 3 and min(group) >= 0 for group in samples)
print("3 Messungen pro Variante")
```

Die Ausgabe bestätigt den Prüfaufbau. Die tatsächlichen Zeiten werden hier bewusst nicht als Referenzwerte ausgegeben.

## 7. Abgrenzung zu ähnlichen Begriffen

Ein [Profiling](it_0298.md) kann erklären helfen, wo innerhalb eines Programms Aufwand entsteht. Ein Benchmark vergleicht definierte Arbeiten. Ein Funktionstest prüft das Ergebnis, ohne zwingend eine Leistungsfrage zu beantworten.

## 8. Häufige Missverständnisse

Ein einzelner schneller Lauf ist kein belastbarer Vergleich. Eine schnellere kleine Rechnung bedeutet auch nicht, dass die gesamte Anwendung beispielsweise beim Lesen von Dateien schneller wird.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Berichte Größenordnung und Schwankung zusammen mit dem Messaufbau. Prüfe Ergebnisgleichheit und wähle Eingaben, die die fragliche Nutzeraufgabe abbilden. Halte Startmessungen und Messungen im warmen Zustand gegebenenfalls getrennt.

## 10. Verwandte Begriffe

# Python

## 1. Kurzbeschreibung

Python ist eine vielseitig verwendete Programmiersprache mit vergleichsweise kompakter Schreibweise. Sie wird unter anderem für Automatisierung, Datenverarbeitung und Anwendungen eingesetzt. Die Quelle bezeichnet sie als beliebt und gut lesbar. Lesbarkeit bleibt jedoch eine Eigenschaft des konkreten Codes; die Sprachwahl allein garantiert keine verständliche oder richtige Umsetzung.

## 2. Was bedeutet der Begriff?

Eine Programmiersprache legt fest, wie Anweisungen, Ausdrücke und Daten beschrieben werden. Eine passende Implementierung verarbeitet den Programmtext. Python ist deshalb von einem bestimmten Interpreterprogramm und dessen installierten Bibliotheken zu unterscheiden.

Das [offizielle Tutorial zum Einstieg](https://docs.python.org/3.13/tutorial/appetite.html) beschreibt typische Einsatzbereiche und grundlegende Eigenschaften. Es ist keine Aussage, dass Python jede Aufgabe ohne weitere Abhängigkeiten oder Plattformvoraussetzungen lösen kann. Ein Python-Skript kann einfache lokale Daten verarbeiten oder umfangreiche externe Komponenten benötigen.

## 3. Einfacher Vergleich aus dem Alltag

Eine gemeinsame Arbeitssprache erleichtert es, Aufgaben verständlich zu beschreiben und vorhandene Begriffe wiederzuverwenden. Ein verständlicher Wortschatz allein ergibt aber noch keinen richtigen Arbeitsplan.

Die Grenze des Vergleichs: Programmcode muss präzise Sprachregeln erfüllen. Der Rechner ergänzt keine fachlich gemeinte Absicht, wenn ein Vergleich oder eine Einheit falsch gewählt wurde. Auch können scheinbar kurze Ausdrücke komplexe Operationen oder äußere Nebenwirkungen auslösen.

## 4. Wie funktioniert das?

Ein Python-Programm verwendet Werte, Namen, Funktionen und weitere Sprachkonstruktionen. Einrückungen kennzeichnen in wichtigen Fällen zusammengehörige Blöcke. Die Standardbibliothek bietet zusätzliche Module, die viele häufige Aufgaben unterstützen.

CPython ist eine konkrete, verbreitete Python-Implementierung. Das [offizielle Glossar](https://docs.python.org/3.13/glossary.html#term-CPython) erklärt diese Bezeichnung zur Abgrenzung von anderen Implementierungen. Sprachversion und konkrete Laufzeit gehören daher zu einer reproduzierbaren Beschreibung des Umfelds.

Auch zur Standardbibliothek gehörende Schnittstellen können äußere Voraussetzungen besitzen. `tkinter` verbindet Python mit Tcl/Tk, wie die [offizielle Modulbeschreibung](https://docs.python.org/3.13/library/tkinter.html#module-tkinter) erläutert. Ein Modulname allein beweist keinen nutzbaren grafischen Anzeigezugang.

## 5. Wo begegnet mir das unter Linux?

Eigene Hilfsskripte, Entwicklungswerkzeuge und Desktopanwendungen können Python verwenden. NetMons Quelltext und die bisherigen Glossarbeispiele sind passende Zusammenhänge. Das bedeutet nicht, dass jedes Linux-System dieselbe Version oder sämtliche benötigten Erweiterungen bereitstellt.

Für die Entwicklung sollten Interpreter, Abhängigkeiten und Startverzeichnis zur Projektanleitung passen. Eine installierte Anwendung und eine bearbeitete Quellkopie können verschiedene Stände verwenden. Das Ändern einer Datei beweist deshalb nicht, dass der nächste Programmstart gerade diese Datei nutzt.

## 6. Konkretes Beispiel Schritt für Schritt

Das vollständige Python-3-Beispiel verarbeitet ausschließlich eigene Integerlisten:

```python
def verdoppeln(werte):
    ergebnis = []
    for wert in werte:
        ergebnis.append(wert * 2)
    return ergebnis

original = [2, 4, 6]
ergebnis = verdoppeln(original)
assert ergebnis == [4, 8, 12]
assert original == [2, 4, 6]
assert verdoppeln([0, -1]) == [0, -2]
assert verdoppeln([]) == []
print(ergebnis)
```

Die Ausgabe lautet:

```text
[4, 8, 12]
```

Die Funktion erstellt eine neue Liste und verarbeitet die Eingaben in einer Schleife. Der Rückgabewert wird anschließend geprüft und ausgegeben. Zusicherungen berücksichtigen null, eine negative Zahl und eine leere Eingabe. Die Ausführung erfolgte mit dem hier bereitstehenden Python 3.13.5; andere Sprach- oder Bibliotheksversionen benötigen bei umfangreicheren Beispielen eigene Beachtung.

## 7. Abgrenzung zu ähnlichen Begriffen

Python ist die Sprache. CPython ist eine Implementierung. Eine Datei mit Endung `.py` kann Quelltext enthalten. Eine Bibliothek stellt zusätzliche Funktionalität bereit. Tkinter ist eine GUI-Schnittstelle und nicht die gesamte Sprache. Eine Entwicklungsumgebung ist wiederum das Zusammenspiel der benötigten Werkzeuge.

## 8. Häufige Missverständnisse

Kurzer Code ist nicht automatisch einfach oder effizient. Eine `.py`-Endung garantiert keinen gültigen oder harmlosen Inhalt. Allein die Installation von Python stellt nicht jede Bibliothek bereit. Auch sind verschiedene Interpreter und Versionen nicht in allen Details austauschbar.

## 9. Praktische Hinweise und gegebenenfalls Risiken

Lies Projektanforderungen und halte verwendete Versionen nachvollziehbar. Führe unbekannten Code nicht allein wegen guter Lesbarkeit ungeprüft aus. Das Beispiel benutzt nur eigene Werte und installiert nichts. Eine tatsächliche NetMon- oder Tkinter-GUI-Abnahme ist damit nicht verbunden.

# NetMon Screenshot Capture Checklist

## Vorbereitung

1. NetMon in einem konsistenten Theme starten.
2. Fenster auf eine breite Desktop-Aufloesung bringen, z. B. `1440x900`.
3. Alle persoenlichen Daten, Hostnamen und unruhigen Testartefakte entfernen.

## Zielmotive

### Hauptnavigation

- Hauptfenster sichtbar
- mehrere Haupttabs erkennbar
- Navigation nicht angeschnitten

### DNS Guard / DoT

- DNS-Tab aktiv
- DNS Guard Status sichtbar
- Resolver-/DoT-Informationen lesbar

### Security / Firewall

- Security-Notebook aktiv
- UFW/Firewall sichtbar
- mindestens ein weiterer Security-Bereich sichtbar

### Radio / Detached

- Radio-UI klar lesbar
- Station und Controls sichtbar
- optional projectM-/Visualizer-Hinweis

### Diagnose / Support

- Support-/Diagnose-Flaeche sichtbar
- Export-/Supportpaket-Aktion sichtbar

## Export

1. Bilder nach `site/screenshots/` legen.
2. Diese Dateinamen verwenden:
   - `netmon-main-navigation.png`
   - `netmon-dns-guard.png`
   - `netmon-security-overview.png`
   - `netmon-radio-detached.png`
   - `netmon-support-diagnostics.png`
3. Danach Website-Slots auf echte Bilder umstellen.
